# Calibrated Counterfactual Fidelity via Null-Edit Anchoring and Human-Judgment Agreement

## Motivation

Physical counterfactual video editing benchmarks such as PhyCoVE report a raw counterfactual fidelity score whose scale is not tied to any baseline distribution or human-judgment anchor, so a higher score cannot be read as evidence of genuine physical correctness; the same self-calibration assumption underlies accuracy-based scoring in VEU-Bench. Structurally, both benchmarks define a scoring function but never establish a discrimination statistic against a null model, meaning score increases are uninterpretable as evidence and benchmark validity rests on an untested assumption.

## Key Insight

A fidelity score becomes certifiable evidence only when it is expressed as a rank-against-null separation whose decision boundary is fixed by human agreement, so that the score's magnitude is replaced by a calibrated probability of being judged physically correct.

## Method

**What it is.** CaliCoF (Calibrated Counterfactual Fidelity) takes as input a candidate counterfactual video, its source video and language edit, a set of N null edits generated by physically implausible perturbation, and a small human-judgment calibration set, and outputs a calibrated discrimination score (AUC, separation margin, and a per-video calibrated probability of physical correctness) in place of the raw fidelity scalar.

**How it works.**

```pseudocode
Input: candidate video v, source s, edit e, fidelity metric f (PhyCoVE's)
Hyperparams: N=32 null edits, K=200 human triplets, alpha=0.05,
             overlap_threshold=0.5 (Cohen's d), fallback_flag=False

Phase 0 - Exchangeability check (per material family):
  # Load-bearing assumption (stated explicitly):
  #   Null-edit fidelity distributions are stochastically dominated by
  #   correct-edit distributions within each material family after
  #   median/MAD standardization, so that z_v is a monotone proxy for
  #   physical correctness.
  #   This assumption is tested before any calibration is reported.
  For each material family m in {rigid, elastic, fluid}:
    collect human-labeled correct set C_m and incorrect set I_m (from K triplets)
    compute f on all in C_m and I_m
    compute Cohen's d between f(C_m) and f(I_m) BEFORE standardization
    compute Cohen's d between z(C_m) and z(I_m) AFTER median/MAD standardization
    if d_after < overlap_threshold:
      set fallback_flag[m] = True   # assumption violated for this material
    else:
      set fallback_flag[m] = False

Phase 1 - Null-edit distribution construction:
  for i in 1..N:
    e_null_i = perturb_edit(e)   # swap material solver, invert quantity sign,
                                 # remove/insert wrong object class
    v_null_i = render_counterfactual(s, e_null_i)
    f_null_i = f(v_null_i, s, e)
  F_null = {f_null_i}

Phase 2 - Raw fidelity of candidate:
  f_v = f(v, s, e)

Phase 3 - Null-anchored separation statistic:
  z_v = (f_v - median(F_null)) / MAD(F_null)
  margin_v = f_v - quantile(F_null, 1 - alpha)
  auc_v = P(f_v > f_null) estimated over F_null

Phase 4 - Human-judgment calibration:
  collect K human triplets (v_a, v_b, preference) on physically correct vs. incorrect pairs
  fit monotone logistic calibrator g: z_v -> p(correct)
  report p_v = g(z_v), plus reliability diagram and ECE

Output: (z_v, margin_v, auc_v, p_v, fallback_flag[m])
  # If fallback_flag[m] is True for the candidate's material family,
  # report raw f_v with an explicit 'uncalibrated' flag instead of p_v.
```

**Why this design.** We chose a null-model distribution built from physically implausible edits over a fixed absolute threshold because PhyCoVE's fidelity scale varies across materials (rigid vs. fluid solvers), so a single threshold cannot transfer; the cost is that null construction requires a renderer for each material, which we accept because PhyCoVE already supplies material-suited solvers. We chose a robust z-score (median/MAD) over mean/std because null fidelity distributions are heavy-tailed when fluid solvers fail, accepting a small loss of efficiency for stability. We chose a monotone logistic calibrator over isotonic regression because K=200 triplets is too small for isotonic to be reliable, accepting a parametric assumption of monotonicity. Unlike the retrieval-style nearest-neighbor calibration used in standard benchmark normalization (e.g., per-dataset z-scoring in Toolformer-style evaluation), our method does not compare a candidate to a library of past scores; it intervenes on the edit itself to generate a counterfactual null that shares the source video and scene state, which retrieval cannot produce because it has no access to the generative process. A domain expert would not describe this as retrieval because the null distribution is synthesized by intervening on the edit operator, not looked up. We added Phase 0 as an explicit exchangeability check because the null is generated by a different generative process than the candidate, so the load-bearing assumption of stochastic dominance after standardization must be verified per material family before any calibrated probability is reported; when the check fails, the method falls back to the raw fidelity with an 'uncalibrated' flag rather than emitting a misleading calibrated probability.

**Why it measures what we claim.** The null-anchored z-score z_v measures genuine physical correctness because the assumption is that physically implausible edits produce a fidelity distribution centered below correct edits and that this ordering is material-invariant after robust standardization; this assumption fails when a material's solver is so noisy that null and correct distributions overlap, in which case z_v reflects solver noise rather than correctness. The separation margin measures discriminability because the assumption is that the alpha-quantile of the null is a valid decision boundary under the human-labeled correctness prior; this fails when the human calibration set is biased toward easy cases, in which case the margin overstates discrimination on hard cases. The calibrated probability p_v measures human-judged correctness because the assumption is that the monotone logistic link is correctly specified between z_v and human preference; this fails when human judgments are inconsistent across annotators, in which case p_v reflects annotator agreement rather than physical fidelity. Phase 0 operationalizes the first assumption by computing Cohen's d between human-labeled correct and incorrect fidelity distributions before and after median/MAD standardization for each material family, and the fallback rule (report raw f_v with 'uncalibrated' flag when d_after < 0.5) makes the failure mode explicit rather than silent.

## Experiment

### Evaluation Setup

| Role | Choice | Rationale (≤12 words) |
| --- | --- | --- |
| Dataset | PhyCoVE (533 cases, rigid/elastic/fluid), stratified subsample of 150 cases balanced across material families | Material diversity is where raw fidelity scale fails to transfer; subsample supports power analysis |
| Primary metric | AUC of calibrated p_v vs. human correctness | Directly tests discrimination, not just scalar magnitude |
| Secondary metric | Per-material Cohen's d between correct and incorrect fidelity distributions before/after standardization (Phase 0 diagnostic) | Tests the load-bearing exchangeability assumption explicitly |
| Baseline | Raw PhyCoVE fidelity f | Tests whether null-anchoring adds anything over the scalar |
| Baseline | Per-material z-score normalization | Tests whether intervention beats retrieval-style standardization |
| Baseline | Fixed absolute fidelity threshold | Tests whether adaptive null boundary beats a global cutoff |
| Ablation-of-ours | CaliCoF without human calibration (raw z_v) | Isolates contribution of the logistic calibrator |
| Ablation-of-ours | CaliCoF without Phase 0 fallback (always report p_v) | Isolates contribution of the exchangeability check |

### Why this setup validates the claim

The central claim is that a counterfactual null distribution, synthesized by intervening on the edit, yields a material-invariant correctness signal that a raw scalar, a retrieval-style per-material z-score, and a fixed threshold cannot. PhyCoVE is the right dataset because its rigid/elastic/fluid split is exactly the axis along which the raw fidelity scale is predicted to shift, so any method that only works on one material family is exposed. The raw-fidelity baseline tests the sub-claim that scale alone is insufficient; the per-material z-score baseline tests the sub-claim that standardization without intervention cannot recover the ordering, since it normalizes but does not synthesize a null sharing the source scene state; the fixed-threshold baseline tests the sub-claim that a single cutoff cannot transfer across solvers. The ablation isolates whether the human calibrator contributes beyond the null-anchored statistic itself. The Phase 0 diagnostic directly tests the load-bearing assumption of stochastic dominance after standardization by reporting Cohen's d per material family before and after median/MAD standardization, with a pre-registered threshold of d_after < 0.5 triggering the 'uncalibrated' fallback. AUC against human correctness is the right primary metric because the claim is about discrimination between physically correct and incorrect candidates, not about the absolute value of any score; a method that merely shifts scores without reordering them would show no AUC gain, which is precisely the failure the design must be able to detect. A power analysis on the 150-case stratified subsample (50 per material family) indicates that detecting the predicted AUC gap of 0.10 at alpha=0.05 with 80% power requires approximately 44 cases per material family, so the subsample is adequately powered.

### Expected outcome and causal chain

**vs. Raw PhyCoVE fidelity f** — On a fluid-dynamics case where a solver produces a plausible-looking but physically wrong flow, the raw scalar lands in a range that overlaps correct rigid cases because the fidelity scale is material-dependent, so a single threshold misclassifies. Our method instead standardizes against a null distribution rendered with a deliberately wrong solver for the same material, so the candidate is compared only to its own material's failure mode, and we expect a clear AUC gap concentrated on the fluid and elastic subsets with near-parity on rigid cases. The Phase 0 diagnostic is expected to show d_after ≥ 0.5 for rigid and elastic (assumption holds) and may show d_after < 0.5 for fluid (assumption violated), in which case the fallback flag correctly suppresses calibrated probabilities for fluid cases rather than reporting misleading ones.

**vs. Per-material z-score normalization** — On a case where the source scene state strongly constrains the correct outcome, the retrieval-style z-score compares the candidate to past scores from other videos and cannot see that this edit's null should share this source, so a candidate that is wrong in a scene-specific way still scores acceptably. Our method intervenes on the edit itself, generating nulls from the same source video and scene state, so the comparison is scene-anchored; we expect the gain to appear specifically on cases with strong source-state dependence rather than uniformly.

**vs. Fixed absolute fidelity threshold** — On an elastic-deformation case where the solver's noise floor is high, the fixed threshold admits incorrect candidates because the absolute scale sits above the cutoff regardless of correctness. Our method sets the boundary at the alpha-quantile of the material's own null distribution, so the decision boundary tracks the noise floor; we expect the fixed threshold to show many false accepts on high-noise materials while our margin stays stable, producing a visible separation-margin advantage on the elastic subset.

**vs. CaliCoF without Phase 0 fallback** — On fluid cases where the exchangeability check fails (d_after < 0.5), the no-fallback variant reports calibrated probabilities that are not supported by the null distribution, so we expect its AUC to be inflated or unstable relative to the full method, which correctly flags those cases as uncalibrated and excludes them from the calibrated-probability AUC computation.

### What would falsify this idea

If our AUC gain over the per-material z-score baseline is uniform across rigid, elastic, and fluid subsets rather than concentrated where the predicted material-dependent scale shift occurs, the null-intervention mechanism is not doing the work we claim. Likewise, if the ablation without human calibration matches the full method, the calibrator is inert and the central claim about calibrated probability is unsupported; and if Phase 0 shows d_after ≥ 0.5 for all material families yet the calibrated AUC still fails to exceed the raw-fidelity baseline, the exchangeability check is not sufficient to rescue the null-anchored statistic.
