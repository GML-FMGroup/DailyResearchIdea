# Grounding-Conditioned Conformal Abstention for Medical Multimodal LLMs

## Motivation

Region-grounding branches across the field — MedTrinity-25M's ROI-description triplets, MedRegA's region-centric tasks, and MIMO's pixel-grounding outputs — all assume that richer region supervision monotonically improves trustworthiness, yet none couples its grounding output to a calibrated abstention signal. MediConfusion demonstrates the structural cost of this assumption: all available medical MLLMs, open-source and proprietary, fall below random guessing on visually dissimilar pairs that medical experts find trivially distinct, because the models emit confident text and boxes regardless of whether the grounded region is actually the discriminative one. The root cause is that grounding confidence is never tested against a held-out contrastive distribution, so the model has no representation of 'my grounding is unreliable here' and cannot abstain.

## Key Insight

If the grounding head's confidence is calibrated by split-conformal quantiles computed on synthetic visually-confusable pairs generated by swapping ROIs between images, then the resulting abstention threshold is distribution-free valid under the same exchangeability that MediConfusion-style pairs violate — so low-confidence abstention becomes a certificate of grounding unreliability rather than a heuristic.

## Method

**What it is.** GRACE (Grounding-Referenced Abstention via Conformal Exchangeability) wraps any region-grounding medical MLLM with a lightweight grounding-reliability head whose scalar output is converted, at test time, into a calibrated abstention decision by a split-conformal quantile estimated on a held-out calibration set of deliberately constructed visually-confusable pairs. Inputs: an image, a text query, and the model's candidate ROI set with per-ROI embeddings. Outputs: (i) a grounded answer with box, (ii) a reliability score, (iii) an abstain/answer decision.

**Load-bearing assumption (stated explicitly).** The ROI-swap intervention removes the causal visual evidence for the query's answer while preserving all other image statistics, so that the reliability head's score on swapped pairs is exchangeable with — and therefore a valid conformal proxy for — the grounding-unreliability distribution encountered on real MediConfusion-style confusable pairs. This assumption fails when the swap preserves answer-relevant signal (e.g., bilateral pathology) or when masked-paste compositing artifacts (seams, intensity/texture discontinuities, implausible anatomy) let the head separate original from swapped ROIs via artifact detection rather than grounding evidence; in that case the score reflects swap-detection, not grounding reliability, and the conformal guarantee holds for the synthetic artifact distribution rather than the real confusable-pair distribution.

**How it works.**

```pseudocode
# Phase 1: synthetic confusable-pair construction (offline)
# Pre-registered protocol (fixed before any calibration run):
#   donor selection: sample J uniformly from calibration images with pathology label disjoint from I's
#   mask-paste: replace I's top-scoring ROI bounding-box pixels with J's argmax-ROI pixels, resized to box, feathered 3-px border
#   disjoint-label criterion: J's pathology label set ∩ I's pathology label set = ∅
#   pilot: run on 200 pairs first; measure answer-flip rate (backbone answer changes orig->swap); proceed to full 2000 only if flip rate >= 0.6
for each calibration image I with ROI set R_I and query q:
    sample a donor image J with disjoint pathology label
    R_swap = R_I with the top-scoring ROI replaced by argmax_roi in R_J
    I_swap = I with ROI-region pixels replaced by J's ROI pixels (masked paste, feathered 3-px border)
    label y_swap = 0 (grounding unreliable); label y_orig = 1

# Phase 2: grounding-reliability head training (frozen MLLM backbone)
h = ROI embedding from MLLM visual encoder for the top-ranked ROI  # dim 512
z = MLP_2layer(h, query_embedding, mean_roi_embedding)   # 512->256->1, GeLU hidden, dropout 0.1
# trained with focal loss (gamma=2) on {orig=1, swap=0} pairs, 5 epochs, lr 1e-4, batch 64
# artifact-detector control head: identical 2-layer MLP (512->256->1, GeLU, dropout 0.1), same focal loss,
#   trained on {orig=1, random-pixel-paste swap=0} where the swap pastes random pixels (not donor ROI) into the top-ROI box

# Phase 3: split-conformal calibration (held-out 20% of pairs, n=2000)
for each calibration pair (x_i, y_i):
    s_i = 1 - sigmoid(z(x_i))           # nonconformity score
q_hat = Quantile(s_1..s_n, ceiling((n+1)(1-alpha)/n))   # alpha = 0.05
# Mondrian/class-conditional variant: compute q_hat separately per covariate stratum (modality x pathology laterality),
#   with a minimum of 100 calibration pairs per stratum; fall back to pooled q_hat for strata below that

# Phase 4: test-time abstention
given test (I, q):
    top_roi, z_test = grounding head output
    stratum = (modality(I), laterality(top_roi))
    q_use = q_hat[stratum] if stratum in q_hat else q_hat_pooled
    if 1 - sigmoid(z_test) > q_use:
        return ABSTAIN(reason='grounding reliability below conformal threshold')
    else:
        return grounded_answer(top_roi, z_test)
```

**Why this design.** We chose a split-conformal quantile over a learned temperature-scaling or Platt calibration because conformal prediction gives a distribution-free coverage guarantee under exchangeability, and our synthetic swap pairs are constructed precisely to be exchangeable with the MediConfusion failure distribution; the cost is that the guarantee is only as good as the swap distribution's fidelity to real confusable pairs. We chose ROI-swap synthesis over collecting human-annotated confusable pairs because MediConfusion-style pairs are rare in public data and swapping isolates the grounding decision from confounding image-level features; the cost is that swapped ROIs may be visually implausible and the head may learn an artifact detector rather than a reliability estimator. We chose a 2-layer MLP head over fine-tuning the full MLLM because the backbone's grounding behavior is exactly what we want to leave intact (so that the head measures rather than changes it), accepting that the head sees only the ROI embedding and cannot exploit cross-ROI reasoning. We chose focal loss over cross-entropy because the swap/original classes are imbalanced in hard cases (most originals are easy), accepting a slightly noisier gradient in the easy regime. This is not a variant of Platt/temperature scaling (Guo et al.) because the calibration target is a contrastive grounding-reliability label, not the model's own log-prob, and not a variant of standard conformal classification because the nonconformity score is defined on a synthesized intervention rather than on the model's natural prediction.

**Why it measures what we claim.** The nonconformity score `1 - sigmoid(z(x))` measures *grounding unreliability* because the assumption is that the ROI-swap intervention removes the causal visual evidence for the query's answer while preserving all other image statistics, so any drop in `z` is attributable to lost grounding evidence; this assumption fails when the swap happens to preserve the answer-relevant signal (e.g., bilateral pathology) or when compositing artifacts let the head detect the swap, in which case the score reflects swap-detection rather than grounding reliability. The conformal quantile `q_hat` measures the *exchangeability-calibrated abstention threshold* because the assumption is that test confusable pairs are exchangeable with calibration swap pairs; this fails when deployment shift is systematic (e.g., a new modality), in which case `q_hat` reflects the calibration distribution's difficulty, not the test distribution's. The head's input `h` (top-ROI embedding) measures *the model's internal representation of the grounded region* because the assumption is that the top-ranked ROI is the one the answer depends on; this fails when the model's ranking is itself wrong, in which case the head evaluates the wrong region and cannot detect the error.

## Experiment

### Evaluation Setup

| Role | Choice | Rationale (≤12 words) |
| --- | --- | --- |
| Dataset | MediConfusion confusable-pair benchmark | Directly probes vision-grounded failure modes we target |
| Dataset (real-shift) | Held-out MediConfusion pairs + curated bilateral-pathology set | Tests transfer to real confusable distribution, not only synthetic |
| Primary metric | Selective risk at fixed abstention rate (10%, 20%, 30%) | Measures error on answered cases, the actual claim |
| Secondary metric | Coverage gap and MMD between calibration swap scores and real confusable-pair scores | Quantifies how far exchangeability holds |
| Diagnostic metric | Answer-flip rate on swaps vs. originals (pilot n=200) | Confirms intervention removes causal evidence |
| Diagnostic metric | Spearman rank correlation between GRACE score and softmax/entropy | Tests score is not a monotone transform of known calibration |
| Baseline | Ungrounded confidence (softmax/temperature-scaled) | Tests whether grounding signal beats generic calibration |
| Baseline | MedRegA region-aware MLLM (no abstention) | Tests whether region awareness alone suffices |
| Baseline | Random/entropy abstention on Sage-Med-style model | Tests whether abstention needs grounding-specific score |
| Ablation-of-ours | GRACE with real-pair calibration instead of swap pairs | Tests whether synthetic swap distribution matters |
| Ablation-of-ours | GRACE with artifact-detector control head (random-pixel-paste swaps) | Tests whether score detects paste artifacts rather than grounding |
| Ablation-of-ours | GRACE with pooled vs. Mondrian (modality × laterality) conformal quantiles | Tests whether conditional validity matters |

### Why this setup validates the claim

The central claim is that grounding reliability is a separable, calibratable quantity, and that a conformal threshold on a swap-intervention score yields abstention that concentrates on genuinely ungrounded answers. MediConfusion is the right dataset because it is built precisely from visually confusable pairs where region-level evidence is decisive, so any method that ignores grounding should fail there. The primary metric — selective risk at a matched abstention rate — is the correct lens because it forces every method to abstain equally often, so differences reflect *where* abstention lands rather than how conservative a method is; a method that abstains indiscriminately cannot win. The three baselines isolate sub-claims: softmax confidence tests whether generic calibration already captures grounding unreliability (if it does, our head is redundant); MedRegA without abstention tests whether region-awareness alone closes the gap; entropy/random abstention tests whether the *score* rather than the *act* of abstaining carries the benefit. The ablation swaps synthetic pairs for real confusable pairs during calibration, testing whether the swap construction is doing real work or merely supplying a generic difficulty prior. The artifact-detector control head, trained on random-pixel-paste swaps, tests whether GRACE's score is merely detecting compositing artifacts: if the control head achieves comparable selective risk, the score is not measuring grounding. The real-shift evaluation on held-out MediConfusion and bilateral-pathology pairs tests whether the conformal certificate transfers to the distribution the community cares about. The answer-flip diagnostic confirms the intervention removes causal evidence, and the MMD/coverage-gap diagnostic quantifies exchangeability between calibration and test scores.

### Expected outcome and causal chain

**vs. Ungrounded confidence (softmax/temperature-scaled)** — On a case where a visually similar but pathologically distinct image pair is presented, the softmax baseline produces a confident wrong answer because its score reflects token-level likelihood, which is high whenever the language prior is fluent and the image is in-distribution, regardless of whether the cited region actually supports the answer. Our method instead scores the top-ROI embedding against a query-conditioned reliability head trained to separate original from swapped ROIs, so a region that lost its causal evidence yields a high nonconformity score and triggers abstention. We expect a clear selective-risk gap concentrated on the confusable subset, with near-parity on easy single-pathology cases where softmax confidence is already informative. We additionally report Spearman rank correlation between GRACE score and softmax/entropy; we expect low-to-moderate correlation (|ρ| < 0.5) and a case study where the two scores disagree, establishing the mechanism is not reducible to known calibration.

**vs. MedRegA region-aware MLLM (no abstention)** — On a case where the model's ROI ranking is wrong — it grounds a neighboring structure rather than the lesion — MedRegA produces a fluent grounded answer with a box on the wrong region because region-awareness improves localization quality but provides no mechanism to detect when localization has failed. Our method instead evaluates the top-ranked ROI's embedding through the reliability head, and because swapped-ROI training teaches the head what a region lacking answer-relevant evidence looks like, a mis-grounded ROI yields an elevated nonconformity score and abstention. We expect the gain to appear specifically on the mis-localization subset, with MedRegA matching us on correctly grounded cases — a subset-selective pattern rather than uniform improvement.

**vs. Random/entropy abstention on Sage-Med-style model** — On a case where the model is uncertain for the wrong reason (e.g., rare modality, unfamiliar phrasing) but grounding is actually correct, entropy-based abstention produces an unnecessary abstention because entropy tracks linguistic and distributional uncertainty, not whether the cited region supports the answer. Our method instead conditions abstention on the grounding head's score, which is near-threshold for correct grounding regardless of phrasing novelty, so it answers where entropy would abstain. We expect our method to achieve lower selective risk at the same abstention rate, with the advantage showing up as fewer false abstentions on correctly grounded but linguistically unusual cases, alongside more true abstentions on confusable pairs.

**vs. GRACE with real-pair calibration** — On a case where real confusable pairs are available for calibration, the real-pair variant replaces synthetic swap scores with scores on held-out real pairs. If the synthetic swap construction is doing real work, the real-pair variant should underperform on the synthetic-targeted confusable subset because real pairs are scarce and may not cover the same failure modes; if the two match, the swap intervention is not the source of the benefit and the conformal-exchangeability argument collapses. We expect the synthetic-swap variant to outperform real-pair calibration on the confusable subset, with the gap shrinking on the real-shift evaluation.

**vs. GRACE with artifact-detector control head** — On a case where the swap introduces compositing artifacts, the control head trained on random-pixel-paste swaps can separate original from swapped ROIs using artifacts alone. If GRACE's selective risk matches the control head's, the score is detecting paste artifacts rather than grounding unreliability. We expect GRACE to achieve lower selective risk than the control head on the confusable subset, with the gap concentrated on cases where the swap preserves answer-relevant signal (bilateral pathology) and the control head cannot rely on artifacts.

**vs. GRACE with pooled vs. Mondrian conformal quantiles** — On a case where the test modality or pathology laterality is underrepresented in calibration, the pooled quantile may be miscalibrated for that stratum. The Mondrian variant computes q_hat per stratum, so validity does not depend on synthetic-real exchangeability across strata. We expect the Mondrian variant to achieve lower selective risk on underrepresented strata, with near-parity on well-represented strata.

### What would falsify this idea

If the selective-risk gain over softmax confidence is uniform across easy and confusable subsets rather than concentrated on the confusable subset the swap construction targets, the score is acting as a generic difficulty detector and the grounding-specific claim is wrong. Equally, if the real-pair calibration ablation matches synthetic-swap calibration, or if the artifact-detector control head matches GRACE's selective risk, the swap intervention is not the source of the benefit and the conformal-exchangeability argument collapses.
