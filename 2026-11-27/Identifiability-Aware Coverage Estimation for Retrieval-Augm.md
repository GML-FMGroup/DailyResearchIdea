# Identifiability-Aware Coverage Estimation for Retrieval-Augmented Deep-Research Evaluation

## Motivation

Current RAG evaluation research has split into three disconnected branches that each measure a different surface without linking stated coverage to an agent's internal belief: SePer measures retrieval utility via semantic perplexity reduction, CalibRAG calibrates retrieval selection for decision-making, and DRBench Pro measures report coverage through knowledge-tree rubric judgments. None of these provides an estimator that tests whether the coverage score reported by DRBench Pro's rubric pipeline is identifiable from the observable judgments — i.e., whether two agents with genuinely different internal knowledge states could produce identical rubric verdicts under partial subgraph sampling. The structural root cause is that rubric coverage is treated as a direct readout of knowledge state, when in fact the rubric-scoring function can be non-injective over belief states, making coverage and stated confidence unidentifiable under the partial coverage that DRBench Pro's subgraph sampling induces.

## Key Insight

Coverage scores are identifiable from rubric judgments if and only if the rubric-scoring function is injective on the reachable belief-state space under the sampling distribution, and this injectivity can be tested empirically by probing the same knowledge-tree node with multiple rubric phrasings and checking whether the resulting judgment vector has full rank over the belief simplex.

## Method

**What it is.** We introduce KITE (Knowledge-state Identifiability Test for Evaluation), an estimator that takes as input a DRBench-Pro-style knowledge tree, a set of rubric probes per node, and an agent's binary rubric judgments, and outputs an identifiability score plus a calibrated belief estimate per node. KITE does not replace coverage; it reports whether the reported coverage is trustworthy given the probe design.

**Load-bearing assumption (stated explicitly).** KITE assumes that the agent's internal knowledge state at each knowledge-tree node is a point b_v in a d-level belief simplex (d=5 depth levels: none, shallow, partial, deep, exhaustive), and that its binary rubric verdicts are generated by a sigmoid of a linear map of that point, f(b)=sigmoid(Wb+c). Under this assumption, full rank of the fitted Jacobian Jf(b_v) is equivalent to local injectivity of the rubric-scoring function by the inverse function theorem, and hence to recoverability of coverage from judgments. This assumption is testable via the held-out-probe agreement test in Phase 3b; when it fails, the identifiability score is a lower bound on true identifiability, not a certificate.

**How it works.**

```pseudocode
INPUT: knowledge tree T (nodes V, relations E), probe set P = {p_v,k} (k=1..K per node v),
       agent A, subgraph sampling distribution S, calibration probe set C
HYPERPARAMETERS: K=5 rubric phrasings per node, alpha=0.05 rank-test threshold,
                 n_boot=200 bootstrap resamples, tau=0.7 injectivity cutoff,
                 d=5 belief-simplex levels, n_em=20 EM iterations, held-out probe fraction=0.2

PHASE 1 — Probe collection
  For each sampled subgraph G ~ S(T):
    For each node v in G, each probe p_v,k:
      j[v,k] = A.judge(v, p_v,k)   # binary rubric verdict
  Form judgment matrix J in {0,1}^{|V| x K}
  Probe generation protocol: for each node v, generate K=5 paraphrases of the node's
  DRBench Pro rubric using an LLM paraphraser (GPT-4o, temperature=0.7), then
  human-verify a random subset of 500 nodes for semantic equivalence (target: >=90%
  of paraphrases judged equivalent by two annotators; report inter-annotator kappa).

PHASE 2 — Belief-state model
  Latent belief b_v in simplex Delta^{d-1} over d=5 knowledge-depth levels per node
  Rubric-scoring function f: Delta -> [0,1]^K modeled as f(b) = sigmoid(W b + c)
  Fit W (K x d), c (K) by maximizing likelihood of J under b_v ~ Dirichlet(1) prior
  (MAP estimate via EM, 20 iterations, initialized with W = identity-padded to K x d)

PHASE 3 — Identifiability test (parametric rank test)
  Compute Jacobian Jf(b_v) at MAP estimate
  Rank test: rank(Jf) == d-1 ? (full-rank => injective locally)
  If rank < d-1: report unidentifiable direction (null space vector)
  Bootstrap: resample judgments n_boot=200 times, recompute rank;
  identifiability_score(v) = fraction of bootstrap samples with full rank
  Flag node v as unidentifiable if score < tau=0.7

PHASE 3b — Model-free held-out-probe agreement test (verification of the
           fitted-map-vs-true-map gap)
  For each node v, split its K=5 probes into a fit set (4 probes) and a held-out
  probe (1 probe), rotating the held-out probe across 5 folds.
  For each fold: fit W, c on the fit set, predict the held-out probe verdict
  from the MAP belief b_v; record agreement (0/1).
  heldout_agreement(v) = mean agreement across 5 folds.
  identifiability_score_model_free(v) = heldout_agreement(v).
  Report both scores; flag a node as unidentifiable if EITHER score < tau=0.7.
  This makes the score a property of the data (held-out predictability) rather
  than solely of the assumed sigmoid, and directly tests the load-bearing
  assumption: if the sigmoid model is misspecified, held-out agreement will be
  low even when the parametric rank test certifies full rank.

PHASE 4 — Calibration-identifiability probe
  For nodes flagged unidentifiable, run contrastive calibration probes C:
  pairs (v, v') where v' is a sibling with known-different ground-truth coverage
  Test whether A's stated confidence on v vs v' is monotone in true coverage
  (Kendall tau >= 0.7 => calibrated; else report calibration failure)

OUTPUT: per-node identifiability_score (parametric), per-node
        identifiability_score_model_free (held-out agreement), global
        identifiability rate, calibrated belief estimates b_v, and
        coverage-with-uncertainty (reported coverage +/- identifiability-weighted
        interval)
```

**Why this design.** We chose a parametric sigmoid rubric-scoring function over a nonparametric kernel because the identifiability test requires a Jacobian with a well-defined rank, and a nonparametric model would make rank estimation ill-posed under K=5 probes per node, accepting the cost that the sigmoid may miss nonlinear rubric interactions. We chose a rank test on the Jacobian over a direct injectivity check because injectivity of a nonlinear map cannot be tested pointwise without global search, while local rank is a necessary condition that is computable in closed form from the fitted W, accepting the cost that we detect only local (not global) non-identifiability. We chose contrastive calibration probes over asking the agent to state confidence directly because CalibRAG has shown that stated confidence is poorly calibrated for retrieval selection, and a contrastive pair forces a relative judgment that is monotone under a weaker assumption, accepting the cost of requiring sibling nodes with known coverage. We added the Phase 3b held-out-probe agreement test because the parametric rank test is a property of the fitted model, not of the agent, and can certify identifiability for a misspecified model; the held-out test makes the score a property of the data and directly checks the load-bearing assumption, accepting the cost of reducing the fit set to 4 probes per fold. A domain expert would not describe KITE as a variant of CalibRAG because CalibRAG calibrates the retrieval-selection step to improve downstream decisions, whereas KITE calibrates the evaluation readout itself by testing whether the rubric-scoring map is invertible — a property CalibRAG does not address. Nor is KITE a variant of DRBench Pro: DRBench Pro defines coverage as a geometric mean of breadth and depth and assumes rubric judgments directly reflect knowledge state; KITE makes that assumption testable and reports when it fails.

**Why it measures what we claim.** The identifiability score (fraction of bootstrap samples with full-rank Jacobian) measures the injectivity of the rubric-scoring function over the belief simplex because we assume the agent's belief state is a point in a d-dimensional simplex and the rubric verdicts are generated by a sigmoid of a linear map from that simplex; under this assumption, full rank of the Jacobian is equivalent to local injectivity by the inverse function theorem, so the score is a direct test of whether coverage can be recovered from judgments. This assumption fails when the agent's belief is not representable in the d-level simplex (e.g., the agent holds contradictory beliefs across sub-topics), in which case the score reflects the fit of the simplex model rather than true identifiability and should be read as a lower bound. The held-out-probe agreement score measures the same injectivity property without relying on the sigmoid assumption because it tests whether a belief fitted on 4 probes predicts the verdict on a 5th held-out probe; this assumption fails when the K rubric phrasings are semantically redundant (all probe the same surface form), in which case held-out agreement is high by redundancy rather than by identifiability, and the phrasing-redundancy audit (human-verified subset) is used to detect this. The calibrated-belief estimate b_v measures the agent's internal knowledge state because we assume the Dirichlet(1) prior is uninformative and the MAP estimate under K rubric phrasings concentrates on the true belief as K grows; this assumption fails when the K rubric phrasings are semantically redundant (all probe the same surface form), in which case b_v reflects phrasing-invariant knowledge only and the identifiability score correctly drops. The contrastive calibration test measures whether stated confidence tracks true coverage because we assume sibling nodes with known coverage provide a monotone reference; this assumption fails when siblings differ in difficulty, in which case the Kendall tau reflects difficulty confound rather than miscalibration.

## Contribution

(1) KITE, an identifiability estimator for RAG evaluation that tests whether coverage scores from a knowledge-tree rubric pipeline are identifiable from observable judgments via a rank condition on the fitted rubric-scoring Jacobian, with bootstrap uncertainty. (2) A calibration-identifiability probe protocol that uses contrastive sibling-node pairs to detect when stated confidence is decoupled from true coverage, extending calibration concerns from retrieval selection (CalibRAG) to the evaluation readout itself. (3) An identifiability-weighted coverage interval that reports coverage with an explicit trust flag per knowledge-tree node, enabling evaluators to distinguish genuine coverage differences from rubric-scoring degeneracy.

## Experiment

### Evaluation Setup

| Role | Choice | Rationale (≤12 words) |
| --- | --- | --- |
| Dataset | DRBench Pro knowledge trees (144 cases, 44 domains) | Structured nodes with ground-truth coverage per node |
| Primary metric | Identifiability-weighted coverage gap (reported minus calibrated) | Detects when coverage readout is untrustworthy |
| Baseline | DRBench Pro raw coverage | Tests whether uninverted rubric readout hides unidentifiability |
| Baseline | CalibRAG-style confidence calibration | Tests whether retrieval-step calibration transfers to readout |
| Baseline | Coverage + bootstrap SE only | Tests whether generic variance captures rank deficiency |
| Ablation-of-ours | KITE with K=1 probe per node | Tests whether multi-phrasing is what enables rank test |
| Ablation-of-ours | KITE with parametric rank test only (no Phase 3b held-out test) | Tests whether held-out agreement adds detection beyond fitted-map rank |
| Simulation | Synthetic belief states with known rubric-scoring map, sweeping K∈{1,2,3,5,10} and noise σ∈{0.1,0.3,0.5} | Establishes that bootstrap full-rank fraction tracks true injectivity (ROC/AUC) |

### Why this setup validates the claim

The central claim is that reported coverage from rubric judgments is only meaningful when the rubric-scoring map is locally injective over the belief simplex, and that KITE detects the cases where it is not. DRBench Pro is the right dataset because it supplies exactly the structure KITE consumes: a knowledge tree with per-node ground-truth coverage and evidence-grounded rubrics, so we can check identifiability flags against actual node-level coverage recoverability rather than a proxy. The primary metric is the gap between reported and calibrated coverage; this is the right detector because the predicted effect is not "lower coverage" but "coverage that cannot be trusted," which only shows up as a divergence between the naive readout and the identifiability-weighted readout. DRBench Pro raw coverage is the baseline that tests whether ignoring injectivity inflates reported coverage on unidentifiable nodes. CalibRAG-style confidence calibration tests whether calibration at the retrieval-selection step already fixes readout miscalibration, which our argument says it cannot because it never inspects the rubric-to-belief map. The bootstrap-SE baseline tests whether generic uncertainty already flags rank-deficient nodes; if it did, KITE would be redundant. The K=1 ablation isolates whether multi-phrasing is the causal ingredient that makes the Jacobian rank test informative, since with one probe per node the rank cannot exceed one and the test should collapse. The parametric-rank-only ablation isolates whether the Phase 3b held-out agreement test adds detection beyond the fitted-map rank test, directly testing the load-bearing assumption that the fitted sigmoid captures the true scoring map. The simulation study with known ground-truth belief states and a known rubric-scoring map closes the fitted-map-versus-true-map gap by empirically establishing that the bootstrap full-rank fraction tracks true injectivity at K=5, reporting ROC/AUC of the identifiability flag against ground-truth non-injectivity.

### Expected outcome and causal chain

**vs. DRBench Pro raw coverage** — On a case where an agent gives identical rubric verdicts across sibling nodes that differ in true depth, raw coverage produces a confident, undifferentiated score because it treats each rubric judgment as a direct reading of knowledge state. Our method instead fits the sigmoid belief model and finds the Jacobian rank-deficient along the depth direction, because multiple nodes collapse to the same verdict pattern under K=5 probes, so it flags those nodes unidentifiable and widens the interval. We expect a noticeable reported-versus-calibrated coverage gap concentrated on deep, multi-hop subtrees, with near-parity on shallow breadth-only nodes.

**vs. CalibRAG-style confidence calibration** — On a case where the agent is systematically overconfident on a specialized-domain subtree, retrieval-step calibration rescales stated confidence but leaves the rubric-to-belief mapping untouched, because CalibRAG calibrates document selection rather than the evaluation readout, so the inflated coverage survives. Our method instead runs contrastive sibling probes and detects that stated confidence is not monotone in true coverage, because the rank test already isolated the unidentifiable direction and the contrastive test targets exactly those nodes. We expect a calibration-failure flag rate that is higher on specialized-domain and multi-hop subsets than on open-domain subsets, where both methods should agree.

**vs. Coverage + bootstrap SE only** — On a case where the agent's belief is genuinely outside the d-level simplex (contradictory sub-topic beliefs), bootstrap standard error stays small because resampling judgments does not change the degenerate verdict pattern, so the uncertainty estimate is falsely tight. Our method instead reports a low identifiability score from the fraction of bootstrap samples with full-rank Jacobian, because the resampling is over the rank of the fitted map rather than the mean of the verdicts, so the degeneracy is visible. We expect the bootstrap-SE baseline to show narrow intervals precisely where KITE flags unidentifiable nodes, giving a clear separation on the contradictory-belief subset.

**vs. KITE with parametric rank test only (no Phase 3b)** — On a case where the agent's belief is not representable in the d-level simplex (e.g., contradictory sub-topic beliefs), the parametric rank test can certify full rank because the fitted W is full-rank even though the model is misspecified, so the parametric-only variant misses the unidentifiability. Our method instead runs the held-out-probe agreement test, which fits on 4 probes and predicts the 5th; when the sigmoid is misspecified, held-out agreement drops below tau=0.7 even though the parametric rank test passes, so the combined flag catches the case. We expect the parametric-only variant to have lower recall on the contradictory-belief subset, with the full KITE recovering it via the held-out test.

**vs. Simulation (known ground-truth injectivity)** — On synthetic data with a known rubric-scoring map, we can compute true injectivity directly. Our method's bootstrap full-rank fraction should track true injectivity, yielding ROC/AUC above 0.8 at K=5 and noise σ=0.3; at K=1 the AUC should fall to near chance, confirming that multi-phrasing is necessary. This simulation closes the fitted-map-versus-true-map gap by showing that the rank test reliably detects non-injectivity at K=5 before the coverage-trustworthiness claim can stand.

### What would falsify this idea

If KITE's identifiability flags and coverage-gap corrections are uniformly distributed across all subsets rather than concentrated on the deep, multi-hop, and specialized-domain nodes where the rank-deficiency argument predicts failure, the central claim that injectivity is the binding constraint on coverage trustworthiness is wrong. A second falsifier: if the K=1 ablation matches full KITE, then multi-phrasing is not what enables the rank test and the mechanism story collapses. A third falsifier: if the simulation shows that the bootstrap full-rank fraction does not track true injectivity at K=5 (AUC near chance), then the fitted-map rank test is not a reliable detector and the load-bearing assumption is false.
