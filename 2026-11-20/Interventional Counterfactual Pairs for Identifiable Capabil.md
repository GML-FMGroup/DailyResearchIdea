# Interventional Counterfactual Pairs for Identifiable Capability Attribution in the Mind2Act World Benchmark

## Motivation

Benchmarks in the Mind2Act World family decompose failures into reasoning (Mind) versus execution (Act) versus composition only by comparing success rates across three separately-instantiated views, so a failed episode cannot be assigned to a unique capability deficit — the attribution is post-hoc and confounded, since the views differ in task, scene, and history. This is a Forest-level problem recurring across the benchmark tree: SAM2Act's memory-bank/attention substrate (E3, E5) conflates spatial-memory retrieval with decision history, and Mind2Act World (E2, E6) builds views plus a diagnosis harness on top of that substrate without an identifiability condition, so no benchmark in the tree guarantees that a failure is attributable by construction rather than by success-rate delta.

## Key Insight

If each composed task is paired with a counterfactual variant that intervenes on exactly one capability input while holding the other fixed, then by construction the only sufficient cause of a success/failure flip is the intervened capability, making failure attribution identifiable from a paired outcome rather than inferred from aggregate success-rate differences.

## Method

## Interventional Counterfactual Attribution Suite (ICAS)

**(A) What it is.** ICAS extends the Mind2Act World benchmark with, for every composed Mind2Act task, a set of *paired counterfactual variants* generated by a single-capability intervention operator, plus an *identifiability scorer* that turns paired success/failure outcomes into a first-class benchmark metric. Inputs: a base Mind2Act task instance (observation history H, execution trajectory T, environment E). Outputs: per-task paired variants, a per-episode attribution label, and a benchmark-level identifiability score.

**(B) How it works.**

```pseudocode
# For each base composed task tau = (H, T, E) in Mind2Act World
# Step 1: capability-isolation variant construction
for tau in composed_tasks:
    # Mind-intervention: clamp the policy's observation/memory buffer to a
    #   perturbed history H' (decision-relevant cues altered) while letting
    #   the policy act closed-loop; the executed trajectory is whatever the
    #   policy produces under H'.
    tau_M = clamp_history(tau, H')      # H' sampled from history-perturbation set
    # Act-intervention: clamp the policy's action output to a perturbed
    #   trajectory T' (timing/jitter perturbation) while feeding real
    #   observations closed-loop; the observation stream is whatever the
    #   environment produces under T'.
    tau_A = clamp_action(tau, T')       # T' sampled from trajectory-perturbation set
    # Control: identity pair (H, T) to estimate stochastic success noise.
    tau_C = tau

# Step 2: run policy on each variant, record binary success s in {0,1}
s_M, s_A, s_C = run(policy, tau_M), run(policy, tau_A), run(policy, tau_C)

# Step 3: paired-difference attribution with measured coupling
# Coupling term: divergence between induced trajectory distributions under
#   history intervention vs control, and between induced observation
#   distributions under action intervention vs control.
D_M = KL( p(T | do(H')) || p(T | H) )   # estimated from 5 rollouts each
D_A = KL( p(O | do(T')) || p(O | T) )   # estimated from 5 rollouts each
# Threshold tau_c = 0.1 nats (calibrated on 20 held-out control pairs)
if s_M != s_C and s_A == s_C and D_M < tau_c:
    label = "MIND_DEFICIT"        # only history intervention flipped, low coupling
elif s_A != s_C and s_M == s_C and D_A < tau_c:
    label = "ACT_DEFICIT"         # only trajectory intervention flipped, low coupling
elif s_M != s_C and s_A != s_C:
    label = "COMPOSITION"         # both interventions flip -> non-identifiable
elif (s_M != s_C and D_M >= tau_c) or (s_A != s_C and D_A >= tau_c):
    label = "NON_IDENTIFIABLE_COUPLING"  # flip but intervention leaked across channels
else:
    label = "NO_EFFECT"           # neither intervention flips

# Step 4: identifiability score over benchmark
identifiability = (# episodes with label in {MIND_DEFICIT, ACT_DEFICIT}) / (# failed episodes)
```

Perturbation sets: history perturbation = 5 sampled counterfactual histories per task (decision-relevant cue altered, all other observations replayed exactly); trajectory perturbation = 5 sampled timing/jitter perturbations (amplitude 2-5% of trajectory range). Control pairs run 3 times to estimate stochastic success variance, used to down-weight labels whose flip is within noise. Coupling divergence D_M and D_A estimated from 5 rollouts each; threshold tau_c = 0.1 nats calibrated on 20 held-out control pairs.

**(C) Why this design.** We chose *paired single-capability interventions* over *post-hoc success-rate comparison across views* because the latter confounds task, scene, and history differences between the Mind, Act, and Mind2Act views, whereas a paired intervention holds all but one input fixed so the only structural difference is the intervened capability — accepting the cost that each task requires 11 additional rollouts (1 base + 5 history + 5 trajectory), tripling benchmark compute. We chose a *closed-form paired-difference rule* over a learned attribution classifier because the identifiability guarantee follows from the intervention design itself (a sufficient-cause condition), not from a model that could itself be miscalibrated — accepting the cost that the rule cannot attribute failures where both interventions flip (labeled COMPOSITION / non-identifiable, and reported as such). We chose *explicit perturbation sets sampled per task* over a generic noise model because the perturbation must alter the decision-relevant cue for Mind and the timing-relevant dimension for Act; a generic noise model would perturb both and destroy identifiability — accepting the cost that perturbation-set design is task-specific and requires manual curation. A domain expert would NOT describe ICAS as a variant of the Mind2Act diagnosis harness (E2, E6): the harness attributes failures *after* observing episodes from separately-instantiated views, whereas ICAS *constructs* the episodes so that attribution is a structural consequence of the intervention, not a post-hoc inference.

**(D) Why it measures what we claim.** The paired-difference label `MIND_DEFICIT` measures *reasoning-capability necessity* because the assumption that clamping the observation/memory buffer to H' while letting the policy act closed-loop isolates the decision input; this assumption fails when the policy's action depends on history in a way that also changes its execution timing (history-action coupling), in which case the label reflects a joint history-and-timing deficit rather than pure reasoning. The label `ACT_DEFICIT` measures *execution-capability necessity* because the assumption that clamping the action output to T' while feeding real observations isolates the physical-execution input; this assumption fails when the policy re-plans from the perturbed trajectory feedback, in which case the label reflects closed-loop composition rather than pure execution. The `identifiability` score measures *attributability of failures* because the assumption that the control-pair success variance bounds stochastic flip probability makes a paired flip a genuine causal effect; this assumption fails when the environment is highly stochastic and the 3-run control variance underestimates true flip probability, in which case the score reflects noise-driven flips rather than capability deficits. The coupling divergence D_M (and D_A) measures *intervention leakage* because the assumption that the induced trajectory (observation) distribution under history (action) intervention is close to the control distribution; this assumption fails when the policy is strongly closed-loop, in which case D_M (D_A) exceeds tau_c and the episode is labeled NON_IDENTIFIABLE_COUPLING rather than a capability deficit.

## Contribution

(1) A counterfactual paired-intervention benchmark extension (ICAS) for Mind2Act World that makes capability attribution identifiable by task construction rather than by post-hoc success-rate delta. (2) A closed-form paired-difference attribution rule with an explicit non-identifiable (COMPOSITION) category, yielding an identifiability score as a first-class benchmark metric alongside success rate. (3) A curated perturbation-set protocol (history-cue and trajectory-timing perturbations) with control-pair noise estimation, enabling reproducible identifiability measurement across the 30-task, 180-configuration suite.

## Experiment

### Evaluation Setup

| Role | Choice | Rationale (≤12 words) |
| --- | --- | --- |
| Dataset | Mind2Act World composed (Mind2Act) tasks, Clean + Random scenes | Base benchmark already defines composed tasks and difficulty tiers. |
| Primary metric | ICAS identifiability score (attributable-failure fraction) | Directly quantifies how often failures are causally attributable. |
| Baseline | Mind2Act diagnosis harness (post-hoc view comparison) | Tests whether structural intervention beats post-hoc attribution. |
| Baseline | Success-rate parity across Mind/Act/Mind2Act views | Tests whether raw cross-view gaps suffice for attribution. |
| Baseline | Generic-noise perturbation attribution | Tests whether curated single-capability perturbations are necessary. |
| Ablation-of-ours | ICAS with control-pair noise down-weighting disabled | Tests whether noise-bounding is what makes labels trustworthy. |
| Ablation-of-ours | ICAS with coupling threshold tau_c set to infinity (no coupling check) | Tests whether measured coupling is what prevents misattribution. |

### Why this setup validates the claim

The central claim is that constructing paired single-capability interventions yields failure attributions that are structurally valid, whereas post-hoc comparison of separately-instantiated views cannot separate reasoning, execution, and composition. The design makes this falsifiable by pitting ICAS against the Mind2Act diagnosis harness on the *same* composed tasks and scenes: if post-hoc attribution were sufficient, the harness would match ICAS on the identifiability score. The success-rate-parity baseline tests a weaker sub-claim—that cross-view gaps alone are diagnostic—so a gap between it and ICAS isolates the value of pairing. The generic-noise baseline tests the sub-claim that perturbations must be capability-targeted; if generic noise performs equally, our curation premise is wrong. The ablation (noise down-weighting off) tests whether the control-pair variance bound is what prevents noise-driven flips from masquerading as deficits. The ablation (coupling threshold tau_c = infinity) tests whether the measured coupling term is what prevents cross-channel leakage from being mislabeled as a single-capability deficit. The identifiability score is the right metric because it counts exactly the episodes where the intervention design licenses a causal label, so any gain must come from structural attribution rather than from higher raw success.

### Expected outcome and causal chain

**vs. Mind2Act diagnosis harness** — On a composed task where a policy succeeds under the Mind view but fails under Mind2Act, the harness attributes the failure by comparing separately-instantiated views, so task, scene, and history differences confound the label and it cannot decide whether the deficit is reasoning or composition. ICAS instead clamps the observation/memory buffer to a perturbed history while letting the policy act closed-loop, so a flip is licensed as MIND_DEFICIT by construction when the measured coupling D_M < tau_c. We expect ICAS to show a noticeably higher attributable-failure fraction on the composed view specifically, with near-parity on the pure Mind and Act views where the harness is already well-posed.

**vs. Success-rate parity across views** — On a task where the policy's Mind2Act success rate sits between its Mind and Act rates, the parity baseline infers a composition deficit purely from the ordering of aggregate rates, but the ordering can arise from scene stochasticity or difficulty-tier composition rather than from any composition failure. ICAS instead requires a paired flip under a single intervention with low coupling, so it declines to label such episodes and reserves COMPOSITION for cases where both interventions flip. We expect the parity baseline to over-attribute composition deficits broadly, while ICAS concentrates its labels on the subset where a single intervention demonstrably flips the outcome and D_M or D_A is below tau_c.

**vs. Generic-noise perturbation attribution** — On a memory-dependent task, generic noise perturbs both the observation history and the execution timing simultaneously, so a resulting flip cannot be assigned to either capability and the attribution collapses toward non-identifiable. ICAS samples history perturbations that alter only decision-relevant cues and trajectory perturbations that alter only timing, keeping the non-intervened input exactly replayed, and additionally measures D_M and D_A to flag leakage. We expect ICAS to convert a substantial share of the generic baseline's non-identifiable episodes into clean MIND_DEFICIT or ACT_DEFICIT labels, with the largest gap on tasks whose decision-relevant cues are spatially localized.

**vs. ICAS without noise down-weighting (ablation)** — On a highly stochastic task, a paired flip can occur by chance even with no capability change, and without the control-pair variance bound the rule labels such flips as deficits, inflating the identifiability score with noise. With down-weighting enabled, flips within control variance are suppressed. We expect the ablation to report a higher but less stable identifiability score, with its excess concentrated on the Random-scene configurations where stochastic success variance is largest, while the full method stays flat across Clean and Random.

**vs. ICAS with coupling threshold tau_c = infinity (ablation)** — On a strongly closed-loop policy, history intervention leaks into the executed trajectory and action intervention leaks into the observation stream, so without the coupling check the rule labels leaked flips as MIND_DEFICIT or ACT_DEFICIT. With the measured coupling term enabled, episodes with D_M >= tau_c or D_A >= tau_c are labeled NON_IDENTIFIABLE_COUPLING. We expect the ablation to report a higher identifiability score that is inflated by misattributed episodes, with the excess concentrated on tasks where the policy's action is most sensitive to history (high D_M) or where re-planning from perturbed feedback is strongest (high D_A), while the full method's score remains stable and its NON_IDENTIFIABLE_COUPLING fraction tracks the measured coupling.

### What would falsify this idea

If ICAS's identifiability advantage over the Mind2Act harness were uniform across Clean and Random scenes and across difficulty tiers rather than concentrated on composed tasks and on episodes where single-capability flips are structurally licensed, the claim that paired interventions—not some incidental benchmark artifact—drive attribution would be wrong. Likewise, if the generic-noise baseline matched ICAS on attributable-failure fraction, the premise that capability-targeted perturbation is necessary for identifiability would collapse.
