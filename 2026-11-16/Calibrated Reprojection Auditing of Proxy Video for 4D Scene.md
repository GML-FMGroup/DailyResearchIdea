# Calibrated Reprojection Auditing of Proxy Video for 4D Scene Generation Benchmarks

## Motivation

VibePrevisBench (arxiv:2611.15789) scores rule-based Scene Check and VLM Screen Check independently, so a spatial fact can be recognized in the proxy video while the exported 4D scene violates it geometrically — Screen Check then rewards rendering artifacts or camera staging rather than scene correctness. The same structural gap recurs across 3D scene generation work: SceneFactor (arxiv:2412.01801) and LT3SD (venue:cvpr:2025:fbf6abe32e7e) synthesize scenes without any metric tying the displayed proxy to the underlying geometry, and ArtiScene (venue:cvpr:2025:20aa64113e9c) and WonderWorld (arxiv:2406.09394) assemble or render scenes with no calibrated check that what is shown matches what was built. The root cause is that no evaluation branch projects hidden ground-truth facts through the exact camera used for the proxy render, leaving the visual evidence uncalibrated with respect to the scene it is supposed to depict.

## Key Insight

Because the proxy video is generated by a known camera with known intrinsics and extrinsics, projecting hidden ground-truth 3D facts through that same camera yields a deterministic pixel-space prediction whose agreement with VLM detections is a metrically calibrated consistency signal, not a visual plausibility judgment.

## Method

**What it is.** CalRep (Calibrated Reprojection Audit) is a post-hoc evaluation module that takes an agent's exported 4D Blender scene, the exact camera intrinsics/extrinsics used to render its proxy video, the hidden ground-truth spatial facts, and the VLM Screen Check detections, and returns a per-fact reprojection error together with a gate that decides whether each Screen Check verdict is trustworthy.

**Load-bearing assumption (stated explicitly).** CalRep assumes that the VLM Screen Check detection bbox b_d for a fact is an unbiased estimator of that fact's true image location up to a bounded per-class bias b and covariance Σ, so that comparing b_d to the projected footprint b_pred by IoU and normalized center offset is a meaningful measure of geometric consistency. This assumption fails when graybox shading or partial occlusion shifts b_d by more than the 0.05 normalized-offset tolerance, producing false CONTRADICTED verdicts. To bound this failure, CalRep includes a calibration step (Phase 0) that estimates per-class bias and covariance on held-out facts whose projected footprints are known-correct, and gates on a bias-corrected, uncertainty-normalized residual rather than raw IoU/offset alone.

**How it works.**

```pseudocode
INPUT: exported scene S (meshes, transforms, timestamps)
       camera C = (K, [R|t], frame range F) used for proxy render
       hidden facts G = {(fact_id, 3D anchor p_g, frame f_g, expected_visibility, class c_g)}
       VLM detections D = {(fact_id, pixel bbox b_d, frame f_d, confidence c_d)}
       calibration set H = held-out facts with known-correct projected footprints (|H| = 512 facts, stratified by class)

PHASE 0 — Detector calibration (per class c)
for each class c present in H:
    collect residuals delta_i = center(b_d_i) - center(b_pred_i) for i in H with class c
    fit bias b_c = mean(delta_i)                       # 2-vector
    fit covariance Sigma_c = cov(delta_i) + 1e-6 * I    # 2x2, regularized
    store (b_c, Sigma_c)

PHASE 1 — Projection prediction
for each fact g in G:
    for each frame f in F within tolerance window around f_g (tolerance = 2 frames):
        p_cam = [R|t]_f * p_g                      # world -> camera
        if depth(p_cam) <= 0: mark occluded; continue
        u,v = K * p_cam / depth(p_cam)             # perspective projection
        b_pred = footprint(u,v, fact_extent, K)    # projected 2D extent
        store (g.fact_id, f, b_pred, visibility=z_buffer_test(S, p_g, f))

PHASE 2 — Per-fact reprojection error (bias-corrected)
for each fact g with a detection d in D:
    f* = argmin_f || center(b_pred(f)) - center(b_d) ||_2   # best matching frame
    e_g = IoU(b_pred(f*), b_d)                              # 2D overlap (raw, reported)
    delta = center(b_d) - center(b_pred(f*))                # 2-vector residual
    delta_corr = delta - b_{c_g}                            # bias-corrected residual
    r_g = || delta_corr ||_{Sigma_{c_g}^{-1}}               # Mahalanobis distance under class covariance
    tau_g = visibility_flag(f*)                             # 1 if predicted visible

PHASE 3 — Gate and aggregate
for each fact g:
    if tau_g == 0 and d exists:  verdict = SPURIOUS   # VLM saw what geometry hides
    elif e_g >= 0.5 and r_g <= 2.0: verdict = TRUSTED   # r_g threshold = 2.0 (≈95% chi-square with 2 dof)
    elif e_g <  0.2 or r_g >  4.0: verdict = CONTRADICTED
    else: verdict = UNCERTAIN

OUTPUT: per-fact (e_g, r_g, tau_g, verdict)
        scene-level TrustedScreenRate = |TRUSTED| / |G_visible|
        scene-level ContradictionRate = |CONTRADICTED| / |G_visible|
        gated Screen Check score = mean over TRUSTED facts only
```

**Why this design.** We chose full perspective projection with the exact render camera over a learned or approximate screen-space alignment because the camera is known exactly and any learned alignment would reintroduce the very artifact we are auditing, accepting the cost that the audit is only valid when camera parameters are logged. We chose a per-fact best-frame match with a ±2-frame tolerance over a strict single-frame comparison because agents may satisfy a fact at a slightly different timestamp than the ground-truth anchor, accepting the cost that a fact satisfied at the wrong time can still pass; we mitigate this by reporting the matched frame offset alongside the error. We chose a z-buffer visibility flag over relying on VLM confidence because a VLM cannot know whether a fact is occluded in the exported geometry, accepting the cost that the z-buffer test is only as accurate as the exported mesh; this is precisely why we report SPURIOUS separately rather than folding it into the error. We chose explicit IoU and normalized-offset thresholds over a fitted scoring function because the audit must be interpretable and reproducible without training data, accepting the cost that the thresholds are not adapted per scene; to bound detector bias we add a per-class calibration step (Phase 0) that estimates bias and covariance on 512 held-out facts, and we gate on the bias-corrected Mahalanobis residual r_g rather than raw offset. A domain expert would not describe CalRep as a variant of VLM-as-judge evaluation (the closest prior method, instantiated in VibePrevisBench's Screen Check) because CalRep does not ask a model whether a fact is visible — it computes where the fact must appear and checks whether the VLM looked there.

**Why it measures what we claim.** The per-fact reprojection error e_g measures metric scene-to-render consistency because the projection K[R|t]p_g is, by the pinhole camera model, the unique pixel where a visible 3D point must appear in the proxy frame; this assumption fails when the exported mesh is correct but the render used a different camera than the logged one, in which case e_g reflects camera-logging error rather than geometry error. The visibility flag tau_g measures whether a fact is geometrically observable because the z-buffer test on the exported scene determines occlusion independently of rendering style; this assumption fails when the exported mesh is coarser than the render mesh, in which case tau_g reflects mesh-resolution mismatch rather than true occlusion. The bias-corrected Mahalanobis residual r_g measures geometric consistency after accounting for VLM localization bias because it subtracts the per-class mean bias b_c and normalizes by the per-class covariance Sigma_c estimated on held-out known-correct facts; this assumption fails when the VLM bias is not stationary across scenes (e.g., varies with graybox shading), in which case r_g reflects residual detector bias rather than scene correctness. The TrustedScreenRate measures the fraction of Screen Check verdicts that are metrically supported because a verdict is counted only when the VLM detection overlaps the projected footprint and passes the bias-corrected residual gate; this assumption fails when the VLM detection bbox is systematically biased beyond the calibrated covariance (e.g., by graybox shading), in which case the rate reflects VLM localization bias rather than scene correctness.

## Experiment

### Evaluation Setup

| Role | Choice | Rationale |
| --- | --- | --- |
| Dataset | VibePrevisBench 242 tasks + hidden facts, logged cameras | Only source with ground-truth facts, exported scenes, and render cameras |
| Calibration set | 512 held-out facts from VibePrevisBench, stratified by class, disjoint from test tasks | Estimates per-class bias b_c and covariance Sigma_c for Phase 0 |
| Primary metric | Gated Screen Check score vs. ungated | Directly isolates whether gating removes unsupported verdicts |
| Baseline | Ungated VLM Screen Check (VibePrevisBench) | The prior method CalRep audits |
| Baseline | VLM-confidence thresholding | Tests whether confidence alone explains trust |
| Baseline | Rule-based Scene Check only | Tests whether geometry facts alone suffice without screen verification |
| Ablation-of-ours | CalRep without z-buffer visibility flag | Isolates the SPURIOUS-detection contribution |
| Ablation-of-ours | CalRep without Phase 0 calibration (raw IoU/offset thresholds) | Isolates the bias-correction contribution |
| Sensitivity sweep | IoU threshold in {0.3, 0.4, 0.5, 0.6, 0.7}; Mahalanobis r_g threshold in {1.0, 2.0, 3.0, 4.0} | Grounds the operating point empirically |

### Why this setup validates the claim

The central claim is that a VLM Screen Check verdict is only meaningful when the fact it names is metrically consistent with where the exported geometry and logged camera say that fact must appear. VibePrevisBench is the right dataset because it is the only source that jointly supplies hidden 3D facts, executable exported scenes, and the exact cameras used for proxy rendering — the three inputs CalRep requires, so the audit is well-posed rather than approximated. The 512-fact calibration set is held out from test tasks and stratified by class to estimate per-class bias and covariance without leaking test facts. The ungated Screen Check baseline tests whether the raw VLM judge is already trustworthy; if it were, CalRep would buy nothing. The confidence-thresholding baseline tests the competing explanation that VLM confidence is a sufficient trust signal, which would collapse our mechanism into a simpler filter. The rule-based-only baseline tests whether screen-level auditing is even necessary given geometric facts. The visibility ablation isolates the SPURIOUS branch: if removing it does not change the gated score, the z-buffer machinery is decorative. The calibration ablation isolates the bias-correction branch: if removing Phase 0 does not change the gated score, the detector-bias assumption is not load-bearing. The threshold sweep grounds the operating point rather than stipulating it. The gated score is the right primary metric because it is computed only over verdicts CalRep certifies, so any improvement must come from correctly separating supported from unsupported verdicts — exactly the effect claimed — rather than from changing the underlying scene quality.

### Expected outcome and causal chain

**vs. Ungated VLM Screen Check** — On a case where the agent places a fact behind another object yet the graybox proxy still renders a suggestive silhouette, the ungated judge credits the fact because it reasons from appearance, not occlusion geometry. Our method instead runs the z-buffer test on the exported scene, finds the anchor hidden, and flags the detection SPURIOUS, excluding it from the gated score. We expect the ungated score to sit noticeably above the gated score on occluded-fact subsets while the two agree closely on unoccluded subsets — the gap concentrated exactly where visibility, not appearance, decides.

**vs. VLM-confidence thresholding** — On a case where the VLM is confidently wrong because the proxy shading makes a misplaced object look correctly staged, confidence thresholding keeps the bad verdict since confidence is high. Our method instead compares the bias-corrected projected footprint to the detected bbox and finds low IoU or large Mahalanobis residual, marking it CONTRADICTED regardless of confidence. We expect confidence thresholding to show near-parity with the ungated baseline on high-confidence-but-misplaced facts, while CalRep shows a clear drop in contradiction rate on that same subset.

**vs. Rule-based Scene Check only** — On a case where the exported scene contains the fact at the right 3D location but the proxy render never actually shows it (wrong camera framing or a timing mismatch), the rule-based check passes the fact because it never inspects the render. Our method instead finds no detection overlapping the projected footprint and marks it CONTRADICTED or UNCERTAIN. We expect rule-based-only to overstate correctness on framing-mismatch tasks, while CalRep's gated score tracks the visible-fact subset more tightly.

**vs. CalRep without Phase 0 calibration** — On a case where the VLM has a systematic per-class localization bias (e.g., consistently shifting boxes for small objects), the uncalibrated gate produces false CONTRADICTED verdicts because the raw offset exceeds 0.05. Our method instead subtracts the estimated bias b_c and normalizes by Sigma_c, so the same detection passes the Mahalanobis gate. We expect the calibrated version to show a lower false-contradiction rate on classes with high measured bias, with the gap shrinking on classes where bias is near zero.

### What would falsify this idea

If the gated score's improvement over the ungated Screen Check were uniform across occluded, misplaced, and well-placed fact subsets rather than concentrated on the occluded and misplaced subsets where the mechanism predicts failure, the claim that CalRep audits geometric consistency would be unsupported. Equivalently, if removing the z-buffer visibility flag or the Phase 0 calibration left the gated score unchanged, the corresponding mechanism would be doing no work.
