# Rollout-Time Causal Sensitivity Certification for Script-to-Video Generation

## Motivation

Across paper-trees, script-to-video generation specifies semantics at authoring time (captions in Foundational Interactive Video Generation, scripted requests in StreamEval) and never re-grounds them against the generated frames. The specification and the verification are structurally decoupled: satisfaction is asserted by construction rather than measured from the rollout. This means a generator can satisfy a caption or scripted request by exploiting spurious correlations (e.g., a 'running' caption satisfied by a static running-pose frame with no motion) while the frozen verifier reports success, because no intervention on the generated content is ever performed to test whether the asserted semantics are load-bearing.

## Key Insight

A frame's content is causally responsible for a verifier's satisfaction decision if and only if counterfactual edits that alter the asserted semantic attribute produce sign-consistent, non-zero changes in the frozen verifier's decision margin across the rollout — a property that correlation-based verification cannot establish because it never intervenes on the generated stream.

## Method

# RTCSC: Rollout-Time Causal Sensitivity Certification
# Input: video generator G, frozen verifier V (returns scalar margin m = V(frame, assertion)), assertion a, rollout length T, edit budget K, sensitivity threshold tau, consistency window W
# Output: per-assertion groundedness certificate (accepted / rejected) with causal-sensitivity trace

# Edit operator library: one deterministic operator per assertion type, with parameters
# - action (e.g., 'running'): mask bounding box of motion region (from optical flow threshold 0.5 px/frame) and inpaint with static pose from nearest keyframe; k controls mask dilation radius (k=1..K: radius = 2k pixels)
# - object presence: mask object bounding box (from off-the-shelf detector) and inpaint with background patch from same frame; k controls inpaint patch size (k=1..K: size = 16k pixels)
# - state change (e.g., 'opening'): mask region between initial and final object positions and inpaint with initial state; k controls temporal interpolation window (k=1..K: window = k frames)
# - spatial relation: mask one object and inpaint with object from mirrored position; k controls mirror offset (k=1..K: offset = 8k pixels)
# - count: mask one instance of the counted object and inpaint with background; k controls which instance (k=1..K: instance index)

# Matched control edit: artifact-equivalent but semantics-preserving
# For each attribute-removing edit f_t^(k) = Edit(f_t, a, k), generate control edit f_t^(k,ctrl) = Edit(f_t, a_ctrl, k) where a_ctrl is a randomly chosen attribute of the same type (e.g., another action) not asserted by a, using the same operator and parameters (same mask size, same inpaint method). This control is artifact-equivalent (same edit magnitude and type) but does not remove the asserted attribute.

for each frame f_t generated by G at step t = 1..T:
    m_t = V(f_t, a)                          # baseline verifier margin
    for k = 1..K:
        # attribute-removing edit
        f_t^(k) = Edit(f_t, a, k)            # deterministic edit operator, k indexes edit strength
        m_t^(k) = V(f_t^(k), a)              # verifier margin under intervention
        # matched control edit (artifact-equivalent, semantics-preserving)
        f_t^(k,ctrl) = Edit(f_t, a_ctrl, k)  # a_ctrl is a different attribute of same type
        m_t^(k,ctrl) = V(f_t^(k,ctrl), a)    # verifier margin under control
        # difference-in-differences: attribute-specific margin change
        delta_t^(k) = (m_t - m_t^(k)) - (m_t - m_t^(k,ctrl)) = m_t^(k,ctrl) - m_t^(k)
    # causal-sensitivity score: mean attribute-specific margin change across edits
    s_t = (1/K) * sum_k delta_t^(k)
    # sign-consistency: fraction of edits with delta_t^(k) > 0
    c_t = (1/K) * sum_k 1[delta_t^(k) > 0]
    # assertion is grounded at frame t if sensitivity is non-zero and sign-consistent
    grounded_t = (s_t > tau) and (c_t >= 0.8)

# rollout-level certificate: assertion accepted iff grounded across a consistency window
accept = (1/W) * sum_{t in last W frames} grounded_t >= 0.9
return accept, {s_t, c_t}_{t=1..T}

**What it is.** RTCSC takes a generated video rollout and a semantic assertion (caption or scripted request), and outputs a per-assertion groundedness certificate: a causal-sensitivity score s_t and sign-consistency c_t at each frame, plus a rollout-level accept/reject decision. It requires no retraining of the generator or verifier; it instruments the frozen verifier as a causal probe via counterfactual frame edits. The load-bearing assumption is that the deterministic attribute-targeted edit operator Edit(f_t, a, k) isolates the asserted semantic attribute, so that any change in the frozen verifier's margin m_t - m_t^(k) is attributable to removal of that attribute rather than to edit artifacts or correlated attributes the verifier actually relies on. To make this assumption explicit and testable, we add a matched control edit that is artifact-equivalent but semantics-preserving, and define s_t as the difference-in-differences between the attribute-removing edit and this control. Groundedness is certified only when the attribute edit's margin change exceeds the control edit's margin change.

**Why this design.** We chose deterministic, attribute-targeted counterfactual edits (mask-and-inpaint the motion region for action assertions) over random noise perturbations because random perturbations change many attributes at once, making the induced margin change unattributable to the asserted semantics; the cost is that the edit operator must be specified per assertion type. We chose a sign-consistency requirement (c_t >= 0.8) over a simple mean-sensitivity threshold because a frame could yield a large positive mean from one outlier edit while most edits do not change the verifier decision, which would indicate correlation rather than causal responsibility; the cost is that some genuinely grounded frames with high-variance edits may be rejected. We chose a rollout-level consistency window (last W frames) over per-frame acceptance because a single frame's sensitivity can be noisy, and requiring sustained groundedness over W frames filters transient artifacts; the cost is a latency of W frames before an assertion can be certified. These decisions distinguish RTCSC from retrieval-based verification (e.g., CLIP-score thresholding) and from learned disentanglement heads: RTCSC does not learn a representation but performs an intervention on the generated stream, so a domain expert would not describe it as a variant of Toolformer-style retrieval or a learned independence head.

**Why it measures what we claim.** The computational quantity s_t (mean attribute-specific margin change across counterfactual edits, computed as difference-in-differences against a matched control edit) measures causal responsibility of the frame's content for the verifier's satisfaction decision because the edit operator is assumed to isolate the asserted semantic attribute — i.e., Edit(f_t, a, k) changes only the attribute named by a and leaves all other content distributionally invariant; this assumption fails when the edit operator inadvertently alters correlated attributes (e.g., masking a running region also removes background context the verifier uses), in which case s_t reflects the verifier's sensitivity to the edit artifact rather than to the asserted semantics. The matched control edit is designed to be artifact-equivalent but semantics-preserving, so the difference-in-differences removes the artifact-driven component of the margin change. The sign-consistency c_t measures the robustness of causal responsibility across edit strengths because it assumes that a genuinely load-bearing attribute yields monotone margin decreases as the attribute is progressively removed; this assumption fails when the verifier's decision boundary is non-monotone in the attribute strength (e.g., a verifier that rewards any motion, even residual), in which case c_t reflects edit-strength sensitivity rather than causal grounding. The rollout-level accept decision measures sustained groundedness because it assumes that a truly satisfied assertion remains causally load-bearing across the consistency window; this assumption fails when the generator alternates between grounded and ungrounded frames (e.g., flicker), in which case the certificate reflects temporal stability rather than semantic satisfaction.

## Experiment

### Evaluation Setup

| Role | Choice | Rationale (≤12 words) |
| --- | --- | --- |
| Dataset | StreamEval 300-case interactive suite | Incremental scripted requests with per-frame assertions |
| Primary metric | Assertion-groundedness AUC vs human labels | Separates grounded from ungrounded assertions, not just fluency |
| Baseline | CLIP-score thresholding | Retrieval-style similarity, no intervention on frame content |
| Baseline | MLLM verifier majority vote | Correlational scoring, no counterfactual probing |
| Baseline | Random-noise perturbation sensitivity | Perturbs all attributes, unattributable margin change |
| Baseline | Learned counterfactual edit model (diffusion-based attribute-removal editor) | Tests whether intervention framing or specific edit heuristic matters |
| Ablation-of-ours | RTCSC minus sign-consistency (mean-only) | Tests whether c_t filters outlier-driven false grounding |
| Ablation-of-ours | RTCSC minus matched control edit (no difference-in-differences) | Tests whether control edit removes artifact-driven margin change |
| Ablation-of-ours | RTCSC with random control edit (not artifact-matched) | Tests whether artifact-equivalence of control is necessary |

### Why this setup validates the claim

The central claim is that causal responsibility of a frame's content for a verifier's satisfaction decision is what distinguishes genuinely grounded assertions from merely correlated ones, and that intervention-based sensitivity detects this where correlational scoring cannot. StreamEval's incremental scripted requests are the right substrate because each request carries a concrete assertion (an action, an object, a state) whose presence or absence in a frame is checkable, and its 300 cases span the five task types where grounding and correlation diverge most. The primary metric — AUC of the certificate against human groundedness labels — directly measures the discrimination the claim predicts, rather than rewarding fluency or aggregate similarity. CLIP-score thresholding tests whether a strong correlational baseline already captures groundedness; the MLLM majority vote tests whether an expensive semantic scorer without intervention suffices; random-noise sensitivity tests whether *any* perturbation works or whether attribute-targeted edits are necessary. The learned counterfactual edit model baseline tests whether the intervention-based framing, not the specific deterministic edit heuristic, is the novel contribution. The mean-only ablation is the sharpest test: if sign-consistency is doing no work, removing it should not change AUC, which would falsify our stated mechanism. The no-control ablation tests whether the matched control edit is necessary to remove artifact-driven margin change, directly validating the load-bearing assumption. The random-control ablation tests whether the control must be artifact-equivalent. Together these form a falsifiable grid: the claim survives only if RTCSC beats correlational baselines *and* the targeted-edit, sign-consistency, and matched-control components each contribute.

### Expected outcome and causal chain

**vs. CLIP-score thresholding** — On a case where a scripted request asks for "a person running" but the generator emits a mostly static figure with a blurred background suggesting motion, CLIP-score thresholding produces a high similarity score because the frame's global embedding matches the prompt's lexical content. Our method instead masks the motion region and inpaints a static pose, so the verifier margin collapses under the targeted edit, yielding a low s_t and a rejection. We expect a noticeable AUC gap concentrated on the action and state-change task subsets, with near-parity on static object-presence subsets where correlation and causation coincide.

**vs. MLLM verifier majority vote** — On a case where a frame contains the asserted object but it is causally irrelevant to the verifier's satisfaction (e.g., a cup present but not being manipulated as the script requires), an MLLM majority vote produces a confident "satisfied" verdict because the object is visibly present and semantically salient. Our method edits the manipulation region and observes no margin change, so s_t is near zero and the assertion is rejected despite the object's presence. We expect our gain to concentrate on the manipulation and interaction subsets, with the MLLM baseline competitive on simple presence assertions.

**vs. Random-noise perturbation sensitivity** — On a case where the asserted attribute is grounded, random Gaussian noise perturbations change many attributes simultaneously, so the induced margin change is large but unattributable, and the baseline cannot distinguish this from a frame where noise happens to shift an unrelated attribute the verifier weights. Our method's attribute-targeted edit isolates the asserted semantics, so the margin change is attributable and sign-consistent. We expect the random-noise baseline to show high sensitivity on both grounded and ungrounded frames (poor separation), while RTCSC separates them, yielding a clear AUC gap that widens on the multi-attribute task subsets.

**vs. Learned counterfactual edit model** — On a case where the asserted attribute is subtle (e.g., a slight pose change), a diffusion-based attribute-removal editor may produce a more realistic edit than deterministic mask-and-inpaint, but it may also inadvertently alter correlated attributes. Our method's matched control edit and difference-in-differences formulation should make RTCSC robust to such leakage, while the learned editor baseline without control may show inflated sensitivity on ungrounded frames. We expect RTCSC to outperform the learned editor baseline on the manipulation and state-change subsets, and to be competitive on action subsets where the deterministic edit is sufficient.

### What would falsify this idea

If RTCSC's AUC gain over CLIP-score thresholding is uniform across all task subsets rather than concentrated on the action, manipulation, and state-change subsets where correlation and causation are predicted to diverge, the causal-sensitivity mechanism is not doing what we claim. Likewise, if the mean-only ablation matches full RTCSC, sign-consistency is not load-bearing and the central mechanism claim fails. Additionally, if the no-control ablation matches full RTCSC, the matched control edit is not necessary and the load-bearing assumption of attribute isolation is not validated.
