# Structure-as-Variable Prompt Optimization for Multi-Agent Systems

## Motivation

CEPO fixes the coordinator/executor decomposition a priori and only optimizes prompt content inside that imposed schema, so it can never distinguish a structure that is genuinely optimal for a task from one that is merely assumed. The deeper meta-level problem is structural-prior identifiability: whenever prompt content and agent-role decomposition are co-adapted, content optimization will happily specialize to whatever role schema it is handed, making the schema's contribution unmeasurable and its optimality untestable. This recurs across prompt-optimization work that inherits an architecture without a test for whether that architecture is warranted.

## Key Insight

Because role decomposition and prompt content are co-adapted, the only way to make a structure's fitness contribution identifiable is to hold the content-optimization budget and fitness signal fixed while varying the structure itself, so the marginal fitness of a schema is measured against the same content-search operator that would otherwise absorb the schema's effect.

## Method

**What it is.** SVPO (Structure-as-Variable Prompt Optimization) jointly searches over agent-role decomposition and prompt content. Inputs: a task with a scalar fitness signal, a set of primitive operations an agent can perform, and a content optimizer (any of the four optimizers CEPO was evaluated with). Output: a role-decomposition graph plus per-role prompts, and a per-structure fitness record that makes the schema's marginal contribution measurable.

**How it works.**

```pseudocode
# Phase 1: structure genotype
# A structure S is a DAG over roles; each role has a prompt p_r.
# Primitive ops O = {retrieve, extract, verify, aggregate, transform, route}
# A structure is generated by: partition O into role-bundles, then wire bundles.

# Phase 2: outer loop = Bayesian structure search over genotypes
Initialize population P of N=8 structures sampled from a structural prior
  (uniform over 1..K roles, K=6; random bundle assignment of O; random DAG wiring)
For generation g in 1..G (G=12):
  For each structure S in P:
    # Phase 3: inner content optimization, budget-matched with learning-curve estimator
    # For each structure, run content optimization at two budget levels: B1=20 and B2=40 evaluations.
    # Use R=3 random restarts per budget level to estimate optimizer variance.
    # Fit a learning curve f_S(b) = a - c * exp(-d * b) to the mean fitness at B1 and B2 (and any intermediate checkpoints at b=10,30 if available).
    # Extrapolated asymptote: f_S(∞) = a.
    # Structure fitness estimate: f(S) = f_S(∞) (or area under curve if extrapolation unstable; see below).
    # Record variance components: between-structure variance (from f(S) across S) and within-structure variance (from restarts).
    p_S = ContentOptimizer(S, task, budget=B2)  # final prompts from the highest-budget run
    f(S) = f_S(∞)  # or AUC if extrapolation fails (see stability check)
    record (S, f(S), p_S, learning_curve_params, variance_components) in archive
  # Phase 4: Bayesian proposal of next structures
  Fit a Gaussian-process surrogate over structure features
    (num_roles, DAG depth, op-bundle entropy, has_verify_role, has_route_role)
  Propose 8 candidate structures by expected-improvement acquisition
  Select top-4 by acquisition, mutate them (add/remove role, re-bundle op, rewire edge)
  Keep top-4 by f(S) from archive as parents; P = parents + mutations
Return argmax_S f(S) and its p_S
```

**Why this design.** We chose a Bayesian outer loop over an evolutionary one because the structure space is small (tens of genotypes) and the GP surrogate lets us spend the scarce content-optimization budget on promising structures rather than on random mutations, accepting the cost that the surrogate's feature vector must be hand-specified and may miss structure-relevant dimensions. We chose budget-matched inner content optimization with a learning-curve estimator (two budget levels, multiple restarts) over a single fixed budget B=20 because a single point estimate confounds structure fitness with optimizer convergence speed and noise; the two-level curve with restarts lets us separate structure variance from optimizer variance and rank by extrapolated asymptote, accepting the cost that each structure requires more content-optimization evaluations (2 budget levels × 3 restarts = 6 runs per structure instead of 1) and that the extrapolation model may be misspecified. We chose to reuse the same content optimizer CEPO was evaluated with rather than a bespoke content optimizer because it isolates the structure variable and makes the comparison to CEPO a controlled one, accepting the cost that SVPO inherits that optimizer's content-search limitations. A domain expert would not describe SVPO as a variant of Bayesian optimization or of CEPO: CEPO imposes the coordinator/executor schema and optimizes content inside it, whereas SVPO treats the schema itself as the search variable and reports its marginal fitness, so the two differ in what is being optimized, not in how the optimizer works.

**Why it measures what we claim.** The per-structure fitness f(S) measures the marginal contribution of structure S because the content-optimization budget and the fitness signal are held fixed across structures, and f(S) is estimated as the extrapolated asymptote of a learning curve fitted over two budget levels with multiple restarts, so any fitness difference cannot be attributed to content-search effort or optimizer noise; this assumption fails when the content optimizer's performance is non-monotone in budget or when the learning-curve model is misspecified (e.g., a structure's curve has a different functional form), in which case f(S) reflects the structure's fitness under an under-optimized or mispredicted content policy rather than its intrinsic fitness. The GP surrogate's structure features measure structural similarity because they are the dimensions along which genotypes differ; this assumption fails when two genotypes share features but differ in wiring, in which case the surrogate treats them as equivalent and the acquisition function may miss a promising structure. The archive's argmax measures the discovered optimum because the search is exhaustive over the sampled population and mutations; this assumption fails when the mutation operator cannot reach a structure outside the initial population's neighborhood, in which case the reported optimum reflects the reachable set rather than the global one.

## Contribution

(1) A structure-as-variable prompt-optimization framework (SVPO) that makes agent-role decomposition a searchable genotype jointly optimized with prompt content under a budget-matched inner loop. (2) A design principle: budget-matched content optimization is necessary for structural fitness to be identifiable, and unequal budgets confound structure comparison with optimization effort. (3) A per-structure fitness archive that enables post-hoc analysis of which structural features (role count, verify roles, routing) predict fitness across tasks.

## Experiment

### Evaluation Setup

| Role | Choice | Rationale |
| --- | --- | --- |
| Dataset | Multi-domain MAS benchmark suite (CEPO's 11 tasks) plus one external MAS benchmark (e.g., HotpotQA multi-hop or GSM8K multi-step) | Same suite as CEPO for controlled comparison; external benchmark tests generalization beyond CEPO's family |
| Primary metric | Held-out task fitness at matched content budget, using learning-curve extrapolated asymptote f(S) | Directly measures marginal structure contribution under fixed effort and separates optimizer noise |
| Baseline | CEPO (fixed coordinator/executor schema) | Tests whether schema is a real search variable |
| Baseline | Best-of-N random structures, budget-matched (same B1/B2 and restarts) | Tests whether Bayesian proposal beats random structure search |
| Baseline | Content-only optimizer, single-role prompt | Tests whether decomposition adds anything over flat prompting |
| Baseline | Generic NAS-over-prompts (same genotype and budget, random search with surrogate) | Tests whether SVPO's mechanism is reducible to standard NAS |
| Ablation-of-ours | SVPO with uniform random structure proposals | Isolates the surrogate/acquisition contribution |
| Ablation-of-ours | SVPO with single-budget B=20 (no learning curve) | Tests the budget-matching assumption: if rankings are stable, single-budget matches two-level |
| Ablation-of-ours | SVPO with GP feature ablation (drop each feature) | Tests surrogate predictive accuracy (held-out rank correlation) |

### Why this setup validates the claim

The central claim is that treating agent-role decomposition as a search variable yields fitness gains that content-only optimization cannot reach, and that these gains are attributable to structure rather than to extra optimization effort. Each baseline isolates one sub-claim. CEPO holds the schema fixed and optimizes content; if SVPO beats CEPO at matched content budget (using the learning-curve estimator), the schema itself carries marginal fitness, which is exactly what CEPO's design forbids it from exploiting. The best-of-N random-structure baseline holds the structure space and budget fixed but removes the Bayesian proposal; if SVPO beats it, the surrogate is doing real work rather than the search being trivially easy. The content-only single-role baseline tests whether decomposition adds anything at all over a flat prompt. The generic NAS-over-prompts baseline tests whether SVPO's genotype and surrogate are just standard NAS in disguise. The random-proposal ablation is the sharpest test: it shares SVPO's genotype, budget, and content optimizer, differing only in how structures are proposed, so any gap is attributable to the acquisition mechanism. The single-budget ablation directly tests the load-bearing assumption: if rankings from B=20 alone match those from the two-level estimator, the budget-matching equivalence holds; if not, the two-level estimator is necessary. The held-out fitness metric at matched budget is the right detector because it is precisely the quantity the method's argument says should differ: if structure matters, fitness variance across structures at fixed budget should exceed the variance content optimization can explain, and the argmax over structures should beat the argmax over content-only runs. We report per-subset effect sizes with 95% confidence intervals (bootstrap over tasks) to avoid tying significance to a single benchmark family.

### Expected outcome and causal chain

**vs. CEPO (fixed schema)** — On a task requiring a verify-then-aggregate step (e.g., multi-hop document QA where extracted facts must be checked before aggregation), CEPO's fixed coordinator/executor schema forces verification and aggregation into the same role, so the content optimizer must encode both behaviors in one prompt and typically drops the verify step under budget pressure, producing confident but unverified aggregates. SVPO instead searches a genotype with a dedicated verify role wired between extract and aggregate, so the content optimizer only has to learn one behavior per role, and we expect a noticeable gap on the verify-sensitive subset with near-parity on single-hop tasks where the schema is irrelevant. The gap should be larger when using the learning-curve estimator because CEPO's fixed schema may also suffer from slow convergence, but the structural advantage remains.

**vs. best-of-N random structures** — On a task where the useful structure has depth 3 (route → retrieve → aggregate) but the prior favors shallow 1-2 role graphs, random structure sampling spends most of its budget on shallow genotypes whose fitness ceiling is low, and with only a handful of draws it rarely lands on the deep genotype, so its best fitness plateaus below the attainable optimum. SVPO's GP surrogate, having seen that depth correlates with fitness on earlier generations, proposes deep candidates via expected improvement, concentrating budget where the ceiling is higher. We expect SVPO to exceed random search by a modest but consistent margin, with the gap widening as the number of roles needed grows.

**vs. content-only single-role optimizer** — On a task with heterogeneous sub-steps (retrieve, transform, route), a single-role prompt must juggle all operations in one context, and the content optimizer's edits trade off one sub-step against another, so gains on retrieval cost accuracy on routing and the fitness curve is flat or noisy. SVPO's op-bundling assigns each operation to its own role, so content edits are local and do not interfere across sub-steps, and we expect a clear gap on heterogeneous tasks with parity on homogeneous ones.

**vs. generic NAS-over-prompts** — If SVPO's genotype and surrogate are equivalent to standard NAS, this baseline should match SVPO. We expect SVPO to outperform because its genotype explicitly encodes role bundles and wiring, while generic NAS may use a less structured search space. A tie would indicate that the structure-as-variable idea is not novel relative to NAS.

**vs. SVPO with single-budget B=20** — This ablation tests the budget-matching assumption. If rankings from single-budget B=20 are highly correlated (Spearman ρ > 0.8) with the two-level estimator, the simpler approach suffices; if not, the learning-curve estimator is necessary to avoid rank inversion. We expect moderate correlation but some rank inversions, justifying the two-level approach.

**vs. SVPO with GP feature ablation** — Dropping each feature (num_roles, DAG depth, op-bundle entropy, has_verify_role, has_route_role) tests the surrogate's predictive accuracy. We expect depth and has_verify_role to be most predictive, and dropping them to reduce held-out rank correlation.

### What would falsify this idea

If SVPO's gain over CEPO is uniform across task subsets rather than concentrated on the subsets where the fixed schema provably cannot express the needed decomposition (verify-sensitive, heterogeneous-op, deep-structure tasks), then structure is not the causal variable and the gain is just extra search effort. Equivalently, if the random-proposal ablation matches SVPO, the Bayesian surrogate contributes nothing and the claim reduces to "more structures sampled is better." Additionally, if the single-budget B=20 rankings are highly rank-correlated with the two-level estimator, the load-bearing assumption holds and the simpler budget suffices; if not, the method's identifiability claim requires the learning-curve estimator.
