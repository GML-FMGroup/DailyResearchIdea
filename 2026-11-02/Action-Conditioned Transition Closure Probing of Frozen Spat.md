# Action-Conditioned Transition Closure Probing of Frozen Spatial Representations

## Motivation

Frozen-feature probes for spatial state, as in the Probing Spatial State Representations paper, measure recoverable information (readout accuracy, persistence, predictive update) but never test whether the latent state itself forms a Markov state under action-conditioned transitions. This is a structural gap: a representation can score high on all readout probes while its transition kernel remains history-dependent, so downstream planning with that latent is not guaranteed to be sound. The field's probe suite replaced the transition-kernel test with frozen-feature readout, leaving open whether the learned latent is closed under action.

## Key Insight

If the latent is a sufficient statistic for the navigation dynamics, then the conditional distribution of the next latent given the current latent and action must be invariant to the observation history that produced the current latent, and this invariance is testable as conditional-independence of the latent delta on history given the current latent and action.

## Method

**What it is.** We introduce TCLOSE (Transition Closure probe), a probe that takes a frozen model's latent state z_t, a known discrete navigation action a_t, and the next latent z_{t+1} from a streaming egocentric trajectory, and outputs a closure score C in [0,1] that estimates the degree to which the latent update is a function of (z_t, a_t) alone rather than of the observation history h_{t-1} that produced z_t. TCLOSE is trained only on held-out trajectories of the same frozen model and does not modify the model.

**Load-bearing assumption (stated explicitly).** The paired-head contrast C is a valid estimator of history-independence of the true conditional transition kernel only if (i) both heads attain their population-optimal risks under matched effective capacity and optimization, and (ii) the closure head's extra inputs do not confer a finite-sample advantage when h_{t-1} is conditionally independent of z_{t+1} given (z_t, a_t). We enforce (i) by giving the base head a same-dimensional nuisance input (a fixed random projection of h_{t-1} of equal width, with the projection matrix frozen and not trained) so both heads have identical input dimensionality and parameter count, and by sharing a single hyperparameter search budget across both heads (see step 3c). We enforce (ii) by calibrating C against a shuffled-history capacity floor (step 4). If either condition fails, C reflects capacity or overfitting rather than closure; we bound this failure mode with the train/val gap check and capacity sweep in step 7.

**How it works.**

```pseudocode
Input: frozen encoder f, trajectories {(o_1, a_1, ..., o_T)} with known actions
Hyperparams: history length H=8, probe width 256, dropout 0.1, epochs 30, lr 1e-3, batch 64, lambda 1.0, nuisance projection width d_nuis = dim(h_{t-1}) (fixed random Gaussian, seed 0, not trained)

1. For each trajectory, compute z_t = f(o_t) for all t (frozen, no gradients).
2. Build transition tuples (z_t, a_t, z_{t+1}, h_{t-1}) where h_{t-1} = (o_{t-H}, ..., o_{t-1}) is the raw history prefix (or its frozen features).
3. Train three probe heads on a held-out split, all sharing the same 2-layer MLP trunk (width 256, GeLU activation, dropout 0.1):
   a. Base head g(z_t, a_t, u_t) -> z_{t+1}, minimizing MSE, where u_t = W_nuis h_{t-1} is a fixed random projection of h_{t-1} to the same width as h_{t-1} (W_nuis frozen, seed 0).
   b. Closure head q(z_t, a_t, h_{t-1}) -> z_{t+1}, minimizing MSE.
   c. Capacity-matched control: train a second closure head q_shuf on tuples where h_{t-1} is shuffled across the training set (permutation fixed, seed 1), minimizing MSE; this head has identical architecture and input dimensionality to q but sees history that is conditionally independent of z_{t+1} given (z_t, a_t) by construction.
   All heads use Adam, lr 1e-3, batch 64, 30 epochs, early stopping on a 10% validation split with patience 5. A single hyperparameter search over {width in [128, 256, 512], dropout in [0.0, 0.1, 0.2], lr in [5e-4, 1e-3]} is run once on the base head and the selected configuration is applied to all three heads (shared budget).
4. Closure score: C = 1 - (MSE_base - MSE_closure) / (MSE_base - MSE_shuf), clipped to [0,1], where MSE_base, MSE_closure, MSE_shuf are held-out MSEs of g, q, q_shuf respectively. If MSE_base - MSE_shuf <= 0 (capacity floor not below base), report C as undefined and flag the representation as failing the capacity calibration. Also report the raw contrast C_raw = 1 - (MSE_base - MSE_closure) / MSE_base clipped to [0,1] for transparency.
5. Significance: permutation test with 1000 shuffles of h_{t-1} across held-out tuples; for each shuffle, recompute MSE_closure with the trained q (no retraining) and report the p-value as the fraction of shuffles whose MSE_closure is <= the observed MSE_closure. This tests whether the trained closure head's advantage exceeds the shuffle null of the same over-parameterized head.
6. Report C per layer, per prefix length, and per action class for each of the ten representations.
7. Capacity and overfitting checks: (a) capacity sweep: repeat step 3 with probe width in {64, 128, 256, 512} and report C for each width; (b) overfitting check: report train/val MSE gap for each head; if the gap for q exceeds 0.1 * MSE_val_base, flag the result as capacity-confounded.
```

**Why this design.** We chose a paired-head contrast (base head vs. closure head) over a single head with an auxiliary history-prediction loss because the paired design directly operationalizes the Markov closure property as a difference in conditional predictive power, accepting the cost that two heads must be trained and matched in capacity. We chose to hold out raw history prefixes h_{t-1} rather than full latent histories because raw observations are the confound that the frozen encoder compresses, accepting that some history information may be recoverable from z_t itself (which is precisely what closure predicts). We chose a permutation test over a parametric F-test because the residual distributions of frozen features are unknown and likely heavy-tailed, accepting lower power for validity. We chose discrete navigation actions rather than continuous controls because the discrete action set makes the conditional-independence test well-posed and matches the navigation environments used in the Probing Spatial State Representations paper. Unlike Toolformer-style retrieval or Gorilla-style tool selection, TCLOSE does not retrieve a matching transition from a library; it estimates a conditional-independence contrast that retrieval cannot express, because retrieval conditions on the full history by construction. The capacity-matched control head q_shuf and the nuisance input u_t are included to enforce the load-bearing assumption that the MSE gap isolates history contribution rather than capacity; this is a specification of the existing paired-head contrast, not a new mechanism.

**Why it measures what we claim.** The closure score C measures Markov closure of the latent transition because the assumption is that if z_t is a sufficient statistic for the dynamics, then the conditional distribution of z_{t+1} given (z_t, a_t) is invariant to h_{t-1}, so the closure head q cannot outperform the base head g beyond the capacity floor established by q_shuf; this assumption fails when the frozen encoder leaks history information into z_t (in which case C overestimates closure because h_{t-1} is partially redundant with z_t) or when the navigation dynamics are history-dependent in a way the encoder cannot compress (in which case C underestimates closure and the probe reflects irreducible dynamics rather than representation quality). The permutation p-value measures the statistical significance of the history contribution because the null hypothesis of exchangeability of h_{t-1} across tuples is exactly the null of no history dependence; this assumption fails when trajectories are autocorrelated, in which case the permutation test is anti-conservative and we report a block-permutation variant. The per-layer and per-prefix-length profiles measure the layer-wise emergence of closure because the assumption is that deeper layers compress more history, which fails when the encoder's receptive field is shorter than H, in which case the profile reflects receptive field rather than closure. The capacity-matched control q_shuf measures the finite-sample capacity floor because the assumption is that a head with identical architecture and input dimensionality but shuffled history provides an upper bound on the MSE reduction attributable to capacity alone; this assumption fails when the shuffled history is not truly independent of z_{t+1} given (z_t, a_t) due to residual autocorrelation, in which case C is biased downward and we report the block-shuffle variant.

## Contribution

(1) TCLOSE, a paired-head conditional-independence probe that estimates action-conditioned transition closure of frozen spatial latents without modifying the encoder. (2) A design principle: closure is testable as a difference in conditional predictive power between a history-free and a history-conditioned transition head, with a permutation-based significance test. (3) A layer-wise and prefix-length closure profile across ten frozen representations on streaming egocentric navigation trajectories.

## Experiment

### Evaluation Setup

| Role | Choice | Rationale |
| --- | --- | --- |
| Dataset | Streaming egocentric navigation trajectories, held-out split | Matches known discrete actions and history prefixes |
| Primary metric | Closure score C (capacity-calibrated) with permutation p-value | Directly quantifies history-independent transition beyond capacity floor |
| Baseline | Retrieval nearest-neighbor transition | Conditions on full history by construction |
| Baseline | Single-head auxiliary history-prediction probe | Tests whether paired contrast is necessary |
| Baseline | Base head only (no history) | Lower bound: pure Markov predictor |
| Baseline | Capacity-matched control head q_shuf (shuffled history) | Establishes finite-sample capacity floor for C |
| Ablation-of-ours | Block-permutation closure variant | Controls for trajectory autocorrelation confound |
| Ablation-of-ours | Capacity sweep (probe width in {64, 128, 256, 512}) | Tests stability of C to head capacity |
| Ablation-of-ours | Overfitting check (train/val MSE gap per head) | Bounds capacity-confound failure mode |

### Why this setup validates the claim

The central claim is that TCLOSE distinguishes representations whose latent transitions are Markov-closed from those that leak history, and that this distinction tracks spatial capability. The base-head-only baseline establishes the floor: whatever predictability exists without history. The retrieval baseline tests the specific sub-claim that closure is not expressible as library lookup, since retrieval conditions on full history and should therefore show inflated predictability precisely where history matters. The single-head auxiliary-loss baseline tests whether the paired-head contrast is doing real work or whether any history-aware probe would score similarly. The capacity-matched control head q_shuf establishes the finite-sample capacity floor: if the closure head's advantage over the base head is due to capacity rather than history, then q_shuf should show a similar advantage, and C will be near zero. The ablation tests the confound that trajectories are autocorrelated, which would make the naive permutation test anti-conservative; if the block-permutation variant preserves the ranking, the effect is not an autocorrelation artifact. The capacity sweep and overfitting check bound the load-bearing assumption that both heads attain population-optimal risks under matched capacity. The closure score is the right metric because it is a conditional-independence contrast calibrated against a capacity floor, not a raw error, so it is comparable across layers and representations with different absolute scales. Together these form a falsifiable test: the claim predicts a specific ordering of representations by C that covaries with capability level and that survives the autocorrelation and capacity controls.

### Expected outcome and causal chain

**vs. Retrieval nearest-neighbor transition** — On a case where the trajectory enters a previously seen corridor after a long detour, the retrieval baseline matches on the full observation history and pulls a transition from the detour context, producing a next-latent prediction that is systematically off in the turning direction because its mechanism conditions on h_{t-1} by construction and cannot isolate the (z_t, a_t) signal. Our method instead trains the base head on (z_t, a_t, u_t) with a nuisance projection and the closure head on (z_t, a_t, h_{t-1}), so the difference isolates exactly the history contribution beyond the capacity floor; on this instance the closure head should not beat the base head beyond the q_shuf floor, so C stays near 1. We expect a noticeable gap between retrieval error and base-head error concentrated on long-detour subsets, with parity on short-history subsets.

**vs. Single-head auxiliary history-prediction probe** — On a case where the representation leaks a small amount of history into z_t, the single-head probe folds the history-prediction auxiliary loss into one objective, so its error is a confounded mixture and it reports low error even when history is redundant with z_t, because its mechanism cannot separate the redundant from the non-redundant history signal. Our method instead computes the contrast between two matched heads differing only in whether h_{t-1} is concatenated, calibrated against the shuffled-history capacity floor, so redundancy with z_t shows up as a near-zero contrast rather than as low absolute error. We expect the single-head probe to show uniformly low error across representations while our C separates them, with the largest divergence on representations where z_t is a strong but imperfect sufficient statistic.

**vs. Base head only (no history)** — On a case where the true dynamics are genuinely history-dependent and the encoder cannot compress that dependence, the base head is misspecified and produces high MSE everywhere because its mechanism assumes Markov closure it cannot verify. Our method instead detects this through the closure head outperforming the base head beyond the q_shuf capacity floor, which drives C below 1 and flags the representation as under-compressing rather than as a dynamics failure. We expect C to drop specifically for shallow layers and short prefix lengths where the receptive field is shorter than H, producing a monotone layer-wise profile that the base-head-only baseline cannot express at all.

**vs. Capacity-matched control head q_shuf (shuffled history)** — On a case where the closure head's extra inputs confer a finite-sample advantage even when history is independent, q_shuf should show a similar MSE reduction to q, driving C toward zero. Our method uses q_shuf as the denominator in C, so any advantage q has over g that is also achievable by q_shuf is subtracted out. We expect q_shuf to have MSE close to g on representations where history is truly independent, and C to be stable across the capacity sweep; if q_shuf outperforms g substantially, C becomes undefined and the representation is flagged as failing capacity calibration.

### What would falsify this idea

If the closure score C is uniform across all ten representations and all layers rather than tracking the predicted capability ordering and layer-wise profile, or if the block-permutation variant reverses the ranking that the naive permutation test produces, or if the capacity sweep shows C changing by more than 0.1 across probe widths, then the contrast is measuring autocorrelation, capacity, and finite-sample noise rather than Markov closure, and the central claim is wrong.
