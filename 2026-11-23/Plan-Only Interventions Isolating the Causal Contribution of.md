# Plan-Only Interventions: Isolating the Causal Contribution of Natural-Language Plans in LLM Machine-Learning Agents

## Motivation

Across the LLM-agent-for-AutoML literature, the reported advantage of an agent is always a bundle: a retrieved or authored plan, the code it generates, and the search operators that refine it, and no work separates these factors. MLE-STAR (2025) reports 64% Kaggle medal rate but attributes it to a mix of web-retrieved models, ablation-guided refinement, and a novel ensembling step, so the contribution of the retrieved plan text itself is never isolated; AutoML-Agent (2025) similarly couples retrieval-augmented planning with parallel sub-task agents and multi-stage verification. The PHM benchmark work on Moving Generality from Model to Modeler (2025) offers the suggestive but uncontrolled observation that a few-hundred-word plan carries most of the gap between two frontier agents — an observation, not an intervention, leaving plan-level and code-level causal contributions confounded across the whole field.

## Key Insight

Because plan text and code-generation trajectory are both free variables of the same agent, the only way to make the plan a well-posed causal carrier is to hold the code-generator, search operator, and evaluation harness byte-identical across arms and swap only the plan string, so that any performance delta is attributable to plan content by construction rather than by statistical adjustment.

## Method

**What it is.** PLAN-SWAP is a controlled-intervention harness for LLM ML-engineering agents. It takes as input a task specification, a fixed code-generation backbone (a single frozen LLM with fixed decoding), a fixed search operator (greedy refinement with a fixed number of iterations), a fixed evaluation harness (the MLE-bench-lite split), and a set of K candidate plan strings drawn from three provenance families — retrieved-solution plans, decomposed sub-task plans, and few-hundred-word design plans. It outputs, per (task, plan) pair, the agent's final executable solution and its score, plus a per-task decomposition of score variance into plan-content, code-sampling, and interaction components.

**Named assumption A (the load-bearing equivalence).** V_plan measures the causal contribution of plan *content* because we assume that, conditional on the frozen backbone, fixed decoding temperature, and fixed greedy operator, the only remaining input that varies across the plan arms is the plan string itself, and that plan arms are exchangeable with respect to surface features (length, formatting, retrieval artifacts). This assumption fails when the backbone's behavior is sensitive to surface features of the plan rather than its semantic content, in which case V_plan reflects a surface confound rather than a content effect. We test A directly with two falsification arms inside the same harness: (i) a length-matched random-plan arm (random token strings matched to the real plan's token length within ±5%) and (ii) a paraphrase-invariance arm (content-preserving paraphrases of each real plan, generated by a separate frozen paraphraser LLM at temperature 0, verified by a human spot-check of 20 paraphrases to confirm no design decision is added or removed). If the paraphrase arm's V_plan share is statistically indistinguishable from the real-plan arm's, A holds; if the length-matched random arm matches the real-plan arm, A fails.

**How it works.**

```pseudocode
# Fixed harness (identical across all arms)
BACKBONE   = frozen LLM, temperature=0, max_tokens fixed
OPERATOR   = greedy_refine(iters=5)
EVAL       = mle_bench_lite.evaluate
SEEDS      = [0,1,2,3]   # code-sampling replication

# Plan provenance families (the ONLY varied factor)
P_retrieved  = MLE_STAR-style web-retrieved solution plans
P_decomposed = AutoML-Agent-style sub-task decomposition plans
P_design     = PHM-style few-hundred-word design plans

# Falsification arms for assumption A (same harness, same backbone)
P_length_random = random token strings, length-matched to each real plan within ±5% tokens
P_paraphrase    = content-preserving paraphrase of each real plan, generated by a separate
                  frozen paraphraser LLM at temperature 0; 20 paraphrases human-verified
                  to add/remove no design decision

for task in MLE_BENCH_LITE:
  for family in [P_retrieved, P_decomposed, P_design]:
    for plan in family.sample(task, n=3):          # 3 plans per family
      for seed in SEEDS:
        code = BACKBONE.generate(task, plan, seed)
        sol  = OPERATOR(code, EVAL.feedback)
        score[task, family, plan, seed] = EVAL(sol)
  # Falsification arms (run on the same tasks, same seeds)
  for plan in P_length_random.sample(task, n=3):
    for seed in SEEDS:
      score_length_random[task, plan, seed] = EVAL(OPERATOR(BACKBONE.generate(task, plan, seed)))
  for plan in P_paraphrase.sample(task, n=3):
    for seed in SEEDS:
      score_paraphrase[task, plan, seed] = EVAL(OPERATOR(BACKBONE.generate(task, plan, seed)))

# Causal decomposition
for task in MLE_BENCH_LITE:
  # plan-content effect: variance across plans, holding seed fixed
  V_plan[task]  = Var_over_plans( mean_over_seeds(score) )
  # code-sampling effect: variance across seeds, holding plan fixed
  V_code[task]  = Var_over_seeds( mean_over_plans(score) )
  # interaction: residual after additive fit
  V_int[task]   = Var( score - mu - a_plan - b_seed )
  # assumption-A checks
  V_plan_length_random[task] = Var_over_plans( mean_over_seeds(score_length_random) )
  V_plan_paraphrase[task]    = Var_over_plans( mean_over_seeds(score_paraphrase) )

# Cross-agent plan transfer (the PHM observation, now as intervention)
for task in MLE_BENCH_LITE:
  plan_A = agent_A.produce_plan(task)   # e.g. strong agent
  plan_B = agent_B.produce_plan(task)   # e.g. weak agent
  for seed in SEEDS:
    s_AA = EVAL(OPERATOR(BACKBONE.generate(task, plan_A, seed)))
    s_AB = EVAL(OPERATOR(BACKBONE.generate(task, plan_B, seed)))
  delta_transfer[task] = mean(s_AA) - mean(s_AB)

return score, V_plan, V_code, V_int, V_plan_length_random, V_plan_paraphrase, delta_transfer
```

**Why this design.** We chose a frozen backbone with temperature 0 and a single greedy operator over a multi-operator search (MCTS/evolutionary) because MLE-STAR and the NeurIPS AI-Research-Agents paper both show that operator choice materially changes scores, which would reintroduce the very confound we are trying to remove; the cost we accept is that our absolute scores will be lower than the best reported MLE-bench numbers, and we will not be able to claim state-of-the-art. We chose three plan-provenance families sampled from the literature rather than a single plan per task because a single plan cannot separate plan-content variance from code-sampling noise; the cost is a larger experimental grid (3 families × 3 plans × 4 seeds × tasks) and correspondingly longer wall-clock. We chose to replicate each (task, plan) pair over four code-sampling seeds rather than one, because without replication the plan effect and the LLM's own sampling variance are not identifiable; the cost is 4× the inference budget, which we mitigate by fixing temperature to 0 for the main sweep and using seeds only for the variance decomposition. We chose an explicit additive decomposition (plan main effect, seed main effect, residual interaction) over a learned attribution model because the decomposition is transparent and does not require training a separate estimator that could itself absorb the effect we are trying to measure; the cost is that a strong nonlinear interaction between plan and code-sampling will be lumped into the residual, which we therefore report explicitly rather than dismiss. We added the length-matched random-plan and paraphrase-invariance arms inside the same harness because assumption A is load-bearing and must be tested by construction, not asserted; the cost is two extra plan arms per task (2 × 3 plans × 4 seeds), which we bound by pre-registering a pilot subset (see experiment). A domain expert would not describe PLAN-SWAP as a variant of MLE-STAR or AutoML-Agent: those are agent architectures whose contribution is a new plan-generation or refinement mechanism, whereas PLAN-SWAP contributes no new plan generator and instead is a measurement protocol that treats the plan as a treatment variable.

**Why it measures what we claim.** The quantity V_plan[task] measures the causal contribution of plan content to agent performance because we assume (assumption A, stated above) that, conditional on the frozen backbone, fixed decoding temperature, and fixed greedy operator, the only remaining input that varies across the plan arms is the plan string itself and that plan arms are exchangeable on surface features; this assumption fails when the backbone's behavior is sensitive to surface features of the plan (e.g., plan length rather than plan content), in which case V_plan reflects a length confound rather than a content effect, and we report the length-matched random-plan arm and the paraphrase-invariance arm as the explicit falsification tests for A. The quantity delta_transfer[task] measures the plan's share of the cross-agent gap because we assume that the plan text is a sufficient statistic for the design decisions an agent would otherwise make in code; this assumption fails when a plan omits a decision that the backbone cannot infer (e.g., a specific preprocessing step), in which case delta_transfer under-estimates the plan's true share and the residual reflects unstated design knowledge. The quantity V_int[task] measures plan–code interaction because we assume the additive model is the correct null; this assumption fails when the plan and the backbone's sampling interact multiplicatively, in which case V_int absorbs that interaction and we report it as a separate finding rather than attributing it to either factor.

## Contribution

['(1) PLAN-SWAP, a controlled-intervention harness that holds the code-generation backbone, search operator, and evaluation harness fixed while swapping only the natural-language plan across three provenance families, making the plan a well-posed treatment variable rather than a confounded component of an agent bundle.', '(2) A per-task variance decomposition that separates plan-content effects, code-sampling effects, and their interaction, providing a reusable measurement protocol for any LLM ML-engineering agent.', "(3) A cross-agent plan-transfer intervention that converts the suggestive PHM observation about few-hundred-word plans into a controlled estimate of the plan's share of the cross-agent performance gap."]

## Experiment

### Evaluation Setup

| Role | Choice | Rationale |
| --- | --- | --- |
| Dataset | MLE-bench-lite split, pre-registered subset of 12 tasks selected by a pilot power analysis (seed variance estimated on 5 pilot tasks; task count chosen for 80% power to detect a V_plan share of 0.20 at α=0.05) | Real Kaggle tasks with graded medals; bounded budget |
| Primary metric | Plan-content variance share (V_plan / total) | Directly quantifies the causal claim |
| Baseline | No-plan ablation (empty plan) | Tests whether plan content matters at all |
| Baseline | Single-plan-per-task protocol | Tests whether replication is needed to identify plan effect |
| Baseline | Length-matched random plans (random token strings, length matched to each real plan within ±5% tokens) | Falsification test for assumption A: rules out plan-length confound |
| Baseline | Paraphrase-invariance arm (content-preserving paraphrases of each real plan, generated by a separate frozen paraphraser LLM at temperature 0; 20 paraphrases human-verified to add/remove no design decision) | Falsification test for assumption A: rules out surface-form confound by construction |
| Ablation-of-ours | Shuffled-plan transfer (plan_A to task of plan_B) | Isolates plan-content vs task-match effect |

### Why this setup validates the claim

The central claim is that plan content is a measurable, separable causal contributor to LLM ML-engineering agent performance, distinct from code-sampling noise and from agent architecture. The no-plan ablation tests the coarse sub-claim: if plan content contributes nothing, an empty plan should score identically to any plan arm, so a nonzero V_plan against this floor is the first falsifiable gate. The single-plan-per-task baseline tests the identifiability sub-claim directly: if the plan effect is indistinguishable from seed variance when only one plan is sampled, then the field's current single-plan protocols are measuring noise, which is the paper's motivating gap. The length-matched random-plan baseline and the paraphrase-invariance arm are the two explicit falsification tests for assumption A (the named load-bearing equivalence in the method): the length-matched arm tests whether V_plan is a surface-length artifact, and the paraphrase arm tests whether V_plan survives a content-preserving surface change — if the paraphrase arm's V_plan share is statistically indistinguishable from the real-plan arm's, A holds; if the length-matched random arm matches the real-plan arm, A fails. The shuffled-plan transfer ablation tests whether delta_transfer reflects plan-task alignment rather than generic plan quality. The metric V_plan/total variance is the right one because it is a ratio of causally-attributed variance components under a fixed harness, so it is invariant to absolute score scale and directly answers the question of how much of the agent's performance is attributable to the plan treatment rather than to the backbone or the operator.

### Expected outcome and causal chain

**vs. No-plan ablation (empty plan)** — On a task where the backbone's default prior is weak (e.g., a tabular task with unusual feature distributions), the empty-plan baseline produces a generic pipeline because the frozen LLM defaults to its most common training-time pattern with no task-specific steering. Our method instead supplies a plan that names task-specific design decisions, so the same frozen backbone and greedy operator converge on a different, better-matched solution. We expect a clear positive V_plan against this floor, concentrated on tasks where the default prior is a poor match and near-zero on tasks where the prior is already strong.

**vs. Single-plan-per-task protocol** — On a task with high code-sampling variance (e.g., a task where the LLM's temperature-0 output is still sensitive to prompt ordering), the single-plan protocol produces a score that reflects one draw of the code-sampling distribution and attributes all of it to the plan, because it has no replication to separate the two sources. Our method instead replicates each plan across seeds and subtracts the seed main effect, so the plan effect is estimated net of sampling noise. We expect the single-plan protocol to overstate plan effects on high-variance tasks and to understate them on low-variance tasks, producing a characteristic variance-share discrepancy that our decomposition removes.

**vs. Length-matched random plans** — On a task where plan length correlates with plan specificity (longer retrieved plans tend to be more detailed), a naive plan-content measurement would show a large V_plan because length and content are confounded. The length-matched random-plan baseline produces plans of matched length but random content, and if V_plan is a length artifact, this baseline will show the same variance share as the real plans. Our method instead compares real plans against length-matched random plans and expects real plans to show a substantially larger V_plan share, isolating content from surface length.

**vs. Paraphrase-invariance arm** — On a task where the real plan's surface form (ordering, lexical cues) drives the backbone's behavior rather than its design decisions, a content-preserving paraphrase should produce a different score distribution if surface form matters. Our method generates paraphrases with a separate frozen paraphraser LLM at temperature 0, human-verifies 20 of them to confirm no design decision is added or removed, and compares V_plan_paraphrase to V_plan. We expect the two shares to be statistically indistinguishable (overlapping 95% bootstrap CIs), which is the positive test that assumption A holds; a significant divergence would indicate that V_plan is surface-driven and would falsify the content interpretation.

### What would falsify this idea

If the length-matched random-plan baseline produces a V_plan share statistically indistinguishable from the real-plan arms, then the measured plan effect is a surface-length artifact and the central claim that plan content is a separable causal contributor is wrong. Likewise, if the paraphrase-invariance arm's V_plan share diverges significantly from the real-plan arm's, assumption A fails and V_plan cannot be interpreted as a content effect; and if delta_transfer is near zero on every task even when plan_A and plan_B differ substantially in quality, then the plan text is not a sufficient statistic for design decisions and the transfer intervention fails to capture the cross-agent gap.
