# Correctness-Constrained Critics via Verifier-Reparameterized Rewards for Style-Conditioned Reasoning Distillation

## Motivation

Existing style-conditioned trace distillation methods like TraceForge train a critic with a binary realism loss that is blind to reasoning correctness, so the generator can produce traces that are stylistically convincing but logically flawed. Concurrently, DPO-style objectives discard the closed-form reward identifiability that makes preference optimization stable, because the critic's reward is not tied to any verifiable signal. Thus no single branch resolves the joint gap: the critic lacks a correctness constraint, and the reward lacks identifiability, causing the generator to optimize realism without verified step correctness.

## Key Insight

Reparameterizing the critic's reward as an explicit closed-form function of a process reward model score and the reference model's log-probability ratio restores reward identifiability while making the critic's binary realism judgment causally constrained by step-level correctness, because the reparameterization enforces an invariant that the critic's output equals the verifier's score up to a monotone transformation of the reference policy's likelihood ratio.

## Method

```pseudocode
# Input: context c, teacher answer a, student family's reference model π_ref, process reward model PRM, execution oracle O
# Output: generator G that produces a reasoning trace τ in the family's style, optimized for realism and verified step correctness

# Load-bearing assumption (explicit): The frozen PRM's step-level score, when averaged over steps (not summed), is a calibrated, monotone proxy for true step correctness, and the reference log-ratio r_ref is on a commensurate scale after standardization, so that the reparameterized reward R_φ is dominated by verified correctness rather than by PRM's own biases or trace length.

1. Supervised warm-start:
   Train G on the student family's own reasoning traces (c, τ_real, a) with cross-entropy loss L_SFT = -log G(τ_real | c, a).

2. Critic initialization:
   Initialize critic C_φ as a binary classifier over traces; pre-train with binary cross-entropy on real vs. generated traces from G.

3. Reward calibration (fixed before adversarial training):
   a. Collect a calibration set of 512 traces (256 real family traces, 256 generated by the warm-started G) with oracle step-level correctness labels.
   b. Fit a logistic regression (or isotonic regression) to map the raw PRM step scores to calibrated correctness probabilities; use this to compute a length-normalized PRM score: PRM_norm(τ) = (1/|τ|) Σ_t PRM_calib(step_t), where PRM_calib is the calibrated step score.
   c. Standardize r_ref(τ) = log π_ref(τ | c, a) - log G(τ | c, a) by subtracting its mean and dividing by its standard deviation on the calibration set, yielding r_ref_std(τ).
   d. Fit weights α, β, γ by logistic regression on the calibration set to predict oracle trace-level correctness from [PRM_norm(τ), r_ref_std(τ), C_φ(τ)], with C_φ frozen from step 2. Use the fitted weights (initialized at α=1.0, β=0.5, γ=0.5) as fixed hyperparameters for the reparameterized reward.

4. Adversarial training with verifier-reparameterized reward:
   For each iteration:
     a. Sample a batch of contexts c and teacher answers a.
     b. Generate candidate traces τ ~ G(· | c, a).
     c. For each trace, compute the length-normalized calibrated process reward score: PRM_norm(τ) = (1/|τ|) Σ_t PRM_calib(step_t), where each step_t is scored against the execution oracle O (for math/code, O checks intermediate results; for general reasoning, PRM is trained on step-level correctness labels).
     d. Compute the standardized reference log-probability ratio: r_ref_std(τ) = (log π_ref(τ | c, a) - log G(τ | c, a) - μ_ref) / σ_ref, where μ_ref and σ_ref are the mean and standard deviation computed on the calibration set.
     e. Reparameterize the critic's reward as:
        R_φ(τ) = σ( α · PRM_norm(τ) + β · r_ref_std(τ) + γ · C_φ(τ) )
        where σ is the sigmoid, C_φ(τ) is the raw critic logit, and α, β, γ are the calibrated weights from step 3d (initialized at α=1.0, β=0.5, γ=0.5). This closed-form ties the critic's output to the verifier score and the reference ratio.
     f. Update critic C_φ to minimize the binary realism loss:
        L_C = -[ y · log R_φ(τ) + (1-y) · log(1 - R_φ(τ)) ]
        where y=1 for real traces from the family and y=0 for generated traces. The gradient flows through C_φ but also through PRM_norm and r_ref_std as fixed components, so the critic learns to calibrate its logit to correct for the verifier and reference signals.
     g. Update generator G with a DPO-style objective using the reparameterized critic reward:
        L_G = - E_{τ~G} [ log σ( R_φ(τ) - R_φ(τ_ref) ) ]
        where τ_ref is a real trace from the family. This encourages generated traces to have higher reparameterized reward than real traces, i.e., to be both realistic and correct.

5. Return G.
```

**Why this design**
We chose a closed-form reparameterization of the critic's reward over a separate learned reward head because it restores the identifiability property that DPO relies on: by making the critic's output an explicit function of the PRM score and the reference log-probability ratio, the reward is anchored to a verifiable signal and a fixed reference policy, so the generator's optimization target is uniquely determined rather than drifting with the critic's arbitrary scaling. We chose to keep the critic's logit as an additive term rather than replacing it entirely, because the critic still captures stylistic realism that the PRM and reference ratio do not, accepting the cost that the critic can still inject noise if its logit is poorly calibrated. We chose a DPO-style objective for the generator over PPO because it avoids training a separate value network and leverages the closed-form reward directly, accepting the cost that the generator is constrained to preference pairs rather than full reward maximization. We chose to freeze the PRM and reference model during adversarial training so that the reparameterization remains a stable anchor, accepting the cost that the PRM's errors are not corrected by the critic. Unlike TraceForge, which uses a critic with a binary realism loss and no correctness constraint, and unlike standard DPO which drops identifiability when the reward is learned, our method couples the critic's judgment to a verifier score through a closed-form expression that a domain expert would not describe as a variant of either: it is a reparameterized critic, not a new loss or a new data source.

**Why this measures what we claim**
The computational quantity PRM_norm(τ) measures step-level reasoning correctness because the PRM is trained on step-level labels from an execution oracle (or human labels for non-executable domains) and calibrated to output probabilities, under the assumption that the oracle's step judgments are causally necessary for final-answer correctness and that the calibrated, length-normalized score is monotone in true step correctness; this assumption fails when the oracle cannot evaluate intermediate steps (e.g., in open-ended reasoning) or when the calibration set is unrepresentative, in which case PRM_norm(τ) reflects surface plausibility or calibration bias rather than correctness. The reference log-probability ratio r_ref_std(τ) measures the generator's deviation from the family's style because it is the standardized log-ratio of the reference model's likelihood to the generator's likelihood, under the assumption that the reference model captures the family's stylistic distribution and that standardization removes scale differences; this assumption fails when the reference model is undertrained, in which case r_ref_std reflects general language modeling quality rather than style. The critic logit C_φ(τ) measures residual realism not captured by PRM_norm and r_ref_std because it is trained adversarially against real traces, under the assumption that the critic's binary classification isolates style; this assumption fails when the critic overfits to spurious features, in which case C_φ reflects dataset artifacts. The reparameterized reward R_φ(τ) measures the joint objective of realism and correctness because it is a monotone combination of these three quantities with calibrated weights, under the assumption that the calibration procedure correctly balances their contributions and that the sigmoid is monotone; this assumption fails when the calibration set is small or the signals are collinear, in which case R_φ is dominated by one signal. The DPO-style loss on R_φ measures the generator's improvement in both realism and correctness because it directly optimizes the reparameterized reward difference between generated and real traces, under the assumption that real traces are both realistic and correct; this assumption fails when real traces contain errors, in which case the generator is pushed toward incorrect traces.

## Experiment

### Evaluation Setup

| Role | Choice | Rationale (≤12 words) |
| --- | --- | --- |
| Dataset | MATH + GSM8K student-family traces | Step-checkable correctness with executable oracle |
| Primary metric | Step-correctness rate under independent judge | Detects correctness, not just final-answer match |
| Baseline | TraceForge (critic, no verifier) | Tests value of verifier-anchored reward |
| Baseline | Standard DPO with learned reward | Tests identifiability claim vs. drifting reward |
| Baseline | Outcome-supervised distillation | Tests value of step-level process signal |
| Ablation-of-ours | Ours minus PRM term (α=0) | Isolates the verifier anchor's contribution |
| Ablation-of-ours | Ours with τ_ref filtered to oracle-verified-correct traces | Tests dependence on assumption that real traces are correct |

### Why this setup validates the claim

The central claim is that anchoring the critic's reward to a verifiable PRM score and a frozen reference ratio yields generator traces that are both stylistically realistic and step-correct, and that this anchoring is what prevents reward drift. Each baseline isolates one sub-claim. TraceForge, which trains a critic with a binary realism loss and no correctness constraint, tests whether the verifier term actually buys correctness rather than mere realism. Standard DPO with a learned reward head tests the identifiability claim: if our closed-form reparameterization matters, DPO should drift toward high-reward-but-incorrect traces while ours does not. Outcome-supervised distillation tests whether step-level process signal matters at all versus final-answer feedback. The ablation (α=0, dropping the PRM term) is the sharpest test: if the verifier anchor is doing the causal work, removing it should reproduce TraceForge-like realism-without-correctness. The τ_ref-filtering ablation tests the assumption that real family traces are step-correct: if the gain disappears when τ_ref is filtered to oracle-verified-correct traces, then the method's benefit depends on that assumption. Step-correctness rate under an independent judge is the right metric because it directly measures the quantity the PRM is supposed to track and because final-answer accuracy would mask the mechanism — a generator can reach correct answers via plausible-but-wrong intermediate steps, which is exactly the failure our method claims to fix.

### Expected outcome and causal chain

**vs. TraceForge** — On a multi-step algebra problem where the student family's style favors terse intermediate steps, TraceForge's critic rewards traces that look like the family but freely invents a wrong intermediate simplification, because its binary realism loss has no signal distinguishing a stylistically plausible wrong step from a right one. Our method instead scores each step against the execution oracle through the PRM term, so a trace with a fabricated simplification receives a lower reparameterized reward and the DPO-style update suppresses it. We expect a noticeable step-correctness gap concentrated on multi-step problems requiring intermediate verification, with near-parity on single-step problems where realism and correctness coincide.

**vs. Standard DPO with learned reward** — On a case where the critic's logit scale drifts during adversarial training, plain DPO's learned reward can be gamed: the generator discovers traces the critic scores highly but that the oracle would reject, because the reward has no fixed anchor and its scale is free. Our method instead ties the critic's output to the frozen PRM and reference ratio, so the optimization target is pinned and the generator cannot inflate reward without raising verified step correctness. We expect plain DPO to show high critic reward but flat or declining step-correctness over training, while ours shows critic reward and step-correctness rising together — a divergence pattern rather than a uniform gap.

**vs. Outcome-supervised distillation** — On a case where the teacher's final answer is correct but the student family's natural trace style would reach it through a different, valid route, outcome supervision rewards any trace ending in the right answer, so it reinforces traces with lucky or unverified intermediate steps. Our method instead requires each step to pass the oracle check, so it selects the trace that is both stylistically native and step-verified. We expect our gain over outcome supervision to be largest on problems with many plausible wrong paths to the correct answer, and near-zero on short problems where the correct path is forced.

**vs. Ours minus PRM term (α=0)** — On a multi-step problem where the PRM term is the only signal distinguishing correct from incorrect intermediate steps, removing it (α=0) leaves the reward dependent solely on the reference ratio and critic logit, which are blind to step correctness. We expect the α=0 ablation to show step-correctness dropping to TraceForge-like levels, confirming that the verifier anchor is causally responsible for the gain.

**vs. Ours with τ_ref filtered to oracle-verified-correct traces** — On a dataset where some real family traces contain errors, the unfiltered method may push the generator toward incorrect traces because the DPO-style loss compares against τ_ref. Filtering τ_ref to only oracle-verified-correct traces should improve step-correctness if the assumption that real traces are correct is load-bearing. We expect the filtered version to show higher step-correctness than the unfiltered version, with the gap proportional to the error rate in the real traces.

### What would falsify this idea

If our step-correctness gain over TraceForge were uniform across single-step and multi-step subsets rather than concentrated where intermediate verification is required, the verifier-anchor mechanism would not be doing the causal work and the central claim would be wrong. Likewise, if removing the PRM term (α=0) left step-correctness unchanged, or if filtering τ_ref to oracle-verified-correct traces did not affect step-correctness, the reparameterization would be decorative rather than load-bearing.
