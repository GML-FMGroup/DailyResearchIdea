# Grammar-Attributed Credit Decomposition for Financial Agent Evaluation

## Motivation

Existing financial agent benchmarks such as FINCOSMOS grade a run as a monolithic accept/reject over the hidden strategy and 15 veto checks, so a run that acquires correct data but elicits the wrong strategy is indistinguishable from one that elicits correctly but backtests on future data. This is not a local scoring defect but a meta-level structural gap: because the task is generated by a compositional grammar, the grammar itself provides a canonical decomposition surface, yet no prior evaluation paradigm exposes per-production credit — DeepResearch Bench, τ2-Bench, and Finance Agent Benchmark share the same residual. FINCOSMOS makes the gap concrete: its programmatic grader verifies point-in-time correctness and recomputes metrics, but it collapses data acquisition, strategy elicitation, and final answer into a single veto-gated verdict, so the credit for each stage cannot be attributed.

## Key Insight

Because the hidden investment strategy is sampled from a known compositional grammar, each grammar production carries an independent ground-truth specification, so a counterfactual re-execution that substitutes the agent's elicited subtree with the reference subtree while holding all other productions fixed yields a causally identified marginal contribution for that production — a quantity that a monolithic veto-gated score structurally cannot expose.

## Method

**What it is.** GACD (Grammar-Attributed Credit Decomposition) is an evaluation-time scoring procedure. Its inputs are (i) the task grammar G that generated the hidden strategy, (ii) the agent's full interaction trace T (user utterances, web fetches, backtest code, reported metrics), and (iii) the reference strategy s* sampled from G. Its output is a vector of per-production scores plus an aggregate weighted score, with an explicit attribution table showing which trace spans are charged to which production.

**Load-bearing assumption (stated explicitly).** GACD's per-production score is a valid, orderable measure of production p's causal credit only under the assumption that the satisfaction predicate and metric vector decompose additively over grammar productions, so that substituting one production against the reference while holding all others at s* yields that production's marginal contribution. This is a main-effect-at-a-reference-point assumption: it holds exactly when productions are causally independent given s*, and it fails when productions interact (e.g., a risk-limit production that only binds conditional on a leverage production). Under interaction, `score_p` reflects the main effect at the reference point s*, not the total causal effect. We therefore (a) make the assumption measurable via an interaction term (Phase 2b below) and (b) report per-production scores alongside that interaction term so that interaction-heavy productions are flagged rather than silently miscredited.

**How it works.**

```pseudocode
Input: grammar G, reference strategy s* in L(G), agent trace T, weights w (sum to 1)
Output: score vector {score_p} for p in productions(G), interaction terms {I_pq},
        aggregate S, attribution table A

# Phase 1: Parse the agent's delivered strategy into a grammar derivation
s_hat = parse(T.delivered_strategy, G)          # may be partial; missing productions marked BOT

# Phase 2: Per-production counterfactual substitution (main effect at s*)
for each production p in G (in topological order):
    s_p = s* with subtree at p replaced by s_hat[p]   # all other productions held at s*
    # Re-execute the backtest under the agent's data cutoff using s_p
    metrics_p = backtest(s_p, T.acquired_data, cutoff=T.cutoff)
    # Recompute the reference metrics for the same substitution
    metrics_ref_p = backtest(s* with subtree at p = s*[p], T.acquired_data, cutoff=T.cutoff)
    # Marginal contribution: does substituting the agent's subtree at p change the
    # user-satisfaction predicate and the metric vector relative to reference?
    delta_p = distance(metrics_p, metrics_ref_p)
    satisf_p = user_satisfaction(s_p, s*) restricted to production p
    score_p = alpha * satisf_p + (1 - alpha) * exp(-lambda * delta_p)

# Phase 2b: Interaction term for grammar-declared coupled pairs (operationalizes
# the load-bearing assumption as a measurable quantity)
for each pair (p, q) in G.coupling_graph:        # declared by grammar author
    s_pq = s* with subtrees at p and q both replaced by s_hat[p], s_hat[q]
    metrics_pq = backtest(s_pq, T.acquired_data, cutoff=T.cutoff)
    delta_pq = distance(metrics_pq, metrics_ref_pq)
    # Interaction = joint effect minus sum of main effects (in metric-distance units)
    I_pq = delta_pq - (delta_p + delta_q)
    # Flag: |I_pq| > tau_int (default tau_int = 0.1) marks (p,q) as interaction-heavy

# Phase 3: Data-acquisition sub-score (production-independent)
score_data = point_in_time_coverage(T.acquired_data, s*.required_fields, T.cutoff)

# Phase 4: Strategy-elicitation sub-score (interaction-only)
score_elicit = elicitation_precision_recall(T.user_utterances, s*)

# Phase 5: Final-answer sub-score (reported metrics vs recomputed)
score_answer = 1 - normalized_error(T.reported_metrics, backtest(s_hat, T.acquired_data, T.cutoff))

# Phase 6: Aggregate with explicit weights
S = w_data * score_data + w_elicit * score_elicit + w_answer * score_answer
    + sum_p w_p * score_p

# Phase 7: Attribution table
for each production p:
    A[p] = {trace_spans: spans(T) that produced s_hat[p],
            vetoes_triggered: vetoes(T) attributable to p,
            score: score_p,
            interaction_flags: [(q, I_pq) for q in coupled(p) if |I_pq| > tau_int]}
return {score_p}, {I_pq}, S, A
```

Hyperparameters: alpha = 0.5 (balance between satisfaction and metric distance), lambda = 1.0 (metric-distance decay), tau_int = 0.1 (interaction-flag threshold on |I_pq|), weights w set by the benchmark designer (default w_data = 0.2, w_elicit = 0.3, w_answer = 0.2, sum_p w_p = 0.3 distributed uniformly over productions). The coupling graph G.coupling_graph is declared by the grammar author; if undeclared, Phase 2b is skipped and the attribution table reports `interaction_flags: []` for all productions, making the main-effect-only status of the scores explicit.

**Why this design.** We chose counterfactual subtree substitution over a learned credit-assignment head because the grammar gives us an exact intervention surface: substituting one production while holding others fixed is a do-operation on the generative process, not a statistical approximation, accepting the cost that we must re-execute the backtest once per production (linear in grammar size) and, for declared coupled pairs, once per pair (linear in the number of declared edges). We chose to keep data-acquisition and elicitation as production-independent sub-scores rather than folding them into the per-production scores because those two stages are shared across all productions and folding them in would double-count, accepting the cost that the attribution table must carry a separate row for shared stages. We chose explicit designer-set weights over weights learned from human preference data because the benchmark must be reproducible across agent versions and a learned weight would drift with the reference distribution, accepting the cost that the weights encode a value judgment about which stage matters most. We added the Phase 2b interaction term rather than a full Shapley decomposition because the grammar author already knows which productions are coupled, so a pairwise term over the declared coupling graph is sufficient to flag where the main-effect assumption is violated, accepting the cost that undeclared interactions remain unflagged. A domain expert would not describe GACD as a variant of process reward models (Lightman 2023) or VinePPO (Kazemnejad et al.) because those methods learn a step-level value function from Monte-Carlo rollouts, whereas GACD performs exact counterfactual re-execution on a known grammar and never trains a value model — the credit is computed, not learned.

**Why it measures what we claim.** The computational quantity `score_p` measures the causal marginal contribution of production p to user satisfaction because the assumption that the grammar productions are causally independent given the reference substitution holds — i.e., the satisfaction predicate decomposes over productions; this assumption fails when two productions interact (e.g., a risk-limit production only matters conditional on a leverage production), in which case `score_p` reflects the main effect at the reference point rather than the full interaction effect, and the Phase 2b term `I_pq` quantifies the size of that discrepancy for declared coupled pairs. The quantity `score_data` measures data-acquisition credit because the assumption that point-in-time coverage of the required fields is a sufficient statistic for whether the agent acquired the right data holds; this assumption fails when the agent acquires the right fields but from a non-authoritative source, in which case `score_data` reflects field coverage rather than data validity. The quantity `score_elicit` measures strategy-elicitation credit because the assumption that the set of productions mentioned in user utterances is the ground-truth elicitation target holds; this assumption fails when the user volunteers a production without being asked, in which case `score_elicit` reflects utterance overlap rather than elicitation skill. The quantity `score_answer` measures final-answer credit because the assumption that recomputing the backtest from the delivered strategy and acquired data is the correct reference holds; this assumption fails when the delivered strategy is ambiguous (parses to multiple derivations), in which case `score_answer` reflects the parse chosen by the deterministic parser rather than the agent's intent.

## Contribution

(1) GACD, a grammar-attributed credit decomposition procedure that uses counterfactual subtree substitution over the task grammar to produce per-production scores and an attribution table, with explicit weights separating data acquisition, strategy elicitation, and final answer. (2) A design principle for financial agent evaluation: because the task grammar is the generative process, per-production credit is identified by intervention rather than learned, and shared stages must be scored outside the per-production sum to avoid double-counting. (3) An attribution table format that maps each production's score to the trace spans and veto checks responsible, enabling failure diagnosis that a monolithic veto-gated verdict cannot provide.

## Experiment

### Evaluation Setup

| Role | Choice | Rationale (≤12 words) |
| --- | --- | --- |
| Dataset | FINCOSMOS hidden-strategy tasks with task grammars, restricted to a reduced grammar of 6 productions and 150 annotated traces | Grammar is the exact intervention surface GACD requires; reduced scope bounds re-execution cost |
| Primary metric | Spearman rank correlation of per-production scores with human credit annotations on matched trace spans | Directly tests whether credit decomposes correctly |
| Secondary metric | Interaction-flag precision: fraction of productions flagged by |I_pq| > 0.1 that human annotators also mark as interaction-dependent | Tests whether the load-bearing assumption is measurable |
| Baseline | FINCOSMOS programmatic grader (aggregate-only) | Tests whether decomposition beats scalar grading |
| Baseline | Process reward model (Lightman 2023) | Tests computed credit versus learned step values |
| Baseline | Uniform-credit attribution | Tests whether grammar structure carries real signal |
| Baseline | Grammar-agnostic leave-one-trace-span-out re-execution | Tests whether grammar decomposition, not generic ablation, produces the signal |
| Ablation-of-ours | GACD with learned (preference-fit) weights | Tests the designer-set-weight design choice |
| Ablation-of-ours | GACD with Phase 2b disabled (main-effect only) | Tests whether the interaction term is load-bearing |
| Feasibility metric | Parser-failure rate and backtest re-execution wall-clock per production | Reports explicit cost of the intervention surface |

### Why this setup validates the claim

The central claim is that GACD's per-production scores recover the causal marginal contribution of each grammar production, and that this decomposition beats aggregate grading and learned step-value attribution. FINCOSMOS is the right dataset because each task ships a task grammar and a hidden reference strategy, which is exactly the intervention surface GACD needs; without a grammar there is no do-operation to perform. We restrict to a 6-production grammar and 150 traces with a pre-registered annotation protocol so that the exponential cost of the Phase 2b interaction term over declared coupled pairs remains tractable and so that human credit annotations are collected under a fixed rubric. The primary metric — Spearman rank correlation between GACD's per-production scores and human credit annotations on matched trace spans — is chosen because it directly measures whether the credit vector is ordered correctly, not merely whether the aggregate correlates with outcome. The secondary interaction-flag precision metric directly tests the load-bearing assumption: if productions flagged by |I_pq| > 0.1 are not the ones human annotators mark as interaction-dependent, the main-effect-at-s* assumption is not being correctly operationalized. The aggregate-only grader tests the sub-claim that decomposition adds information beyond a scalar score: if GACD's per-production ordering correlates with human credit while the grader's single score cannot even be formed into an ordering, the decomposition claim survives. The process reward model tests the sub-claim that exact counterfactual re-execution beats learned step values, especially on interaction-heavy productions where Monte-Carlo rollouts are noisy. Uniform-credit attribution is the null that grammar structure must beat: if uniform credit achieves the same rank correlation, the grammar is not doing work. The grammar-agnostic leave-one-trace-span-out baseline tests whether the grammar decomposition itself, rather than generic ablation over trace spans, is what produces the credit signal; if it matches GACD, the grammar is not the load-bearing structure. The learned-weight ablation tests whether the designer-set-weight choice is load-bearing or whether the explicit weights are what produce the alignment; if the learned-weight variant does equally well, the reproducibility argument for designer weights weakens. The Phase 2b-disabled ablation tests whether the interaction term is load-bearing: if disabling it does not reduce rank correlation on interaction-heavy productions, the term is not doing work.

### Expected outcome and causal chain

**vs. FINCOSMOS programmatic grader (aggregate-only)** — On a case where the agent delivers a correct final metric but acquires data from a non-authoritative source, the aggregate grader passes the run because its 15 veto checks are satisfied and the reported metric matches, collapsing all credit into a single pass. Our method instead charges the data-acquisition shortfall to `score_data` via point-in-time coverage and leaves the strategy productions scored independently, because the counterfactual substitution isolates the data stage from the strategy stage. We expect a noticeable gap in rank correlation on the subset of traces where final metrics are correct but acquisition is flawed, with parity on clean traces.

**vs. Process reward model (Lightman 2023)** — On a case where a leverage production and a risk-limit production interact (the risk limit only binds conditional on leverage), the learned step-value model assigns credit by Monte-Carlo rollout averaging, so its step scores smear the interaction across both productions and misrank them. Our method instead substitutes each production against the reference while holding the other at s*, so the main effect at the reference point is attributed to the production that actually changed the satisfaction predicate, and the Phase 2b term `I_pq` explicitly flags the pair as interaction-heavy so the main-effect score is not read as a total effect. We expect a concentrated gap on interaction-heavy productions, with parity on independent productions where main effects and total effects coincide.

**vs. Uniform-credit attribution** — On a case where the agent nails the data acquisition and elicitation but botches one strategy production, uniform credit spreads the failure evenly across all productions, so the per-production ordering is uncorrelated with the human annotation of which production failed. Our method instead concentrates the penalty on the substituted production whose metrics diverge from the reference, because `delta_p` is computed only for the changed subtree. We expect the rank correlation gap to be large on single-production-failure traces and to shrink toward zero on traces where all productions are correct or all are wrong.

**vs. Grammar-agnostic leave-one-trace-span-out re-execution** — On a case where the agent's failure is localized to one grammar production but spread across several trace spans, the grammar-agnostic baseline ablates whole trace spans and therefore cannot isolate the production-level credit, so its per-span scores do not align with the human production-level annotation. Our method instead substitutes the parsed subtree at the production level, so the credit is charged to the production regardless of how many spans produced it. We expect a rank correlation gap on traces where production boundaries and span boundaries diverge, with parity on traces where each production maps to a single span.

**vs. GACD with learned (preference-fit) weights** — On a held-out trace set, the learned-weight variant fits weights to human preference data and therefore drifts with the reference distribution, so its per-production ordering is stable only on traces resembling the fitting set. Our method uses designer-set weights and therefore produces the same ordering across agent versions. We expect parity in rank correlation on in-distribution traces and a gap on out-of-distribution traces where the learned weights overfit the reference distribution.

**vs. GACD with Phase 2b disabled (main-effect only)** — On interaction-heavy traces where a leverage production and a risk-limit production are coupled, the main-effect-only variant assigns credit to each production as if the other were held at s*, so the per-production ordering misranks the coupled pair relative to human annotation. Our method computes `I_pq` for the declared pair and flags it, so the attribution table signals that the main-effect scores are not total effects. We expect a rank correlation gap on interaction-heavy traces, with parity on independent-production traces.

### What would falsify this idea

If GACD's rank correlation with human credit is uniform across interaction-heavy and independent productions rather than concentrated on the interaction-heavy subset where the counterfactual mechanism should dominate, or if the Phase 2b interaction-flag precision is at chance, the causal-attribution claim is wrong and the grammar is not providing the intervention surface we claim. Likewise, if the learned-weight ablation matches designer-set weights on rank correlation, the reproducibility argument for explicit weights does not hold.
