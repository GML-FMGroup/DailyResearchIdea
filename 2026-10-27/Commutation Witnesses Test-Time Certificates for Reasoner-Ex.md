# Commutation Witnesses: Test-Time Certificates for Reasoner-Executor Decomposition in Vision-Language Agents

## Motivation

Both HexaShell and LightZeroNav inherit the assumption that a frozen executor composes with a reasoner's abstractions, but neither can distinguish 'the executor happened to work on seed layouts' from 'the executor is invariant to the nuisance factors the reasoner abstracts away.' HexaShell freezes its tool library after ten seed layouts and reports success on ten new layouts, yet success on new layouts is consistent with the executor silently relying on layout-specific cues that happen to persist; there is no test that isolates which scene factors the reasoner claimed were irrelevant. The structural gap — across both paper-trees — is that the abstraction boundary of the decomposition is never made explicit or falsifiable, so compositional generalization is assumed rather than certified.

## Key Insight

If the reasoner emits, alongside each program, a symbolic precondition/postcondition pair over a shared latent scene signature, then invariance of the frozen executor under witness-preserving scene interventions and its sensitivity under witness-violating interventions jointly certify the abstraction boundary at test time without retraining or a learned independence head.

## Method

**What it is.** COMMWIT (Commutation Witness) is a test-time certification protocol for a reasoner+executor VLM agent. Input: a reasoner program (tool call or waypoint sequence) plus a symbolic witness W = (pre, post) over a shared latent scene signature σ; a frozen executor policy π_e; a scene simulator with a controllable state. Output: a per-program certificate (PASS/FAIL) stating whether π_e's output distribution commutes with every scene transformation that preserves W.

**Load-bearing assumption (stated explicitly).** The certificate is valid only if a scene transformation that preserves the reasoner's symbolic witness predicates over σ is a valid intervention on exactly the nuisance factors the reasoner abstracted away. This requires σ to be a sufficient statistic for the executor's input. Because π_e observes raw pixels while σ is a hand-calibrated extraction (ray-plane object centers, visibility mask, instruction slot), any executor dependence on pixel-level cues outside σ (texture, lighting, shading, rendering artifacts) is invisible to the predicate evaluator. A transformation can therefore be 'witness-preserving' by construction yet still change the executor's input distribution. The method tests invariance against the executor's actual input distribution, not merely against the reasoner's symbolic signature, by adding an adversarial pixel-edit search (Phase 2b) that is validated to be witness-preserving by the executor's own observation channel.

**How it works.**

```pseudocode
# Phase 1: witness emission (reasoner side, no training)
for each program p_i emitted by reasoner R:
    W_i = (pre_i, post_i)   # typed predicates over sigma: object ids, plane params,
                            # relative poses, occlusion flags, instruction slots
    sigma = extract_signature(scene)   # calibrated: object centers via ray-plane,
                                       # gripper pose, visibility mask, instruction embedding slot
    assert pre_i(sigma)                # reasoner commits to what it believes is relevant

# Phase 2: witness-preserving intervention set (test-time, on scene only)
T_pres_i  = { t : pre_i(t(scene)) == pre_i(scene)  and  post_i(t(scene)) == post_i(scene) }
    # generated by a typed perturbation grammar: retexture, relight, translate nuisance
    # objects, swap distractor instances, re-render background, paraphrase instruction
    # slots not named in W_i.  N_pres = 32 interventions per program.
T_viol_i  = { t : pre_i(t(scene)) != pre_i(scene) }   # e.g. move a named object, occlude it,
                                                       # flip a plane normal.  N_viol = 32.

# Phase 2b: adversarial pixel-edit search (validated witness-preserving)
# Search for pixel edits that leave sigma unchanged but maximize KL.
# Use 200-step projected gradient descent (PGD) in pixel space with L_inf budget eps=8/255,
# initialized from each t in T_pres_i.  After each step, project the edit back onto the
# set { x : pre_i(extract_signature(x)) == pre_i(scene) and post_i(extract_signature(x)) == post_i(scene) }
# by clipping any pixel change that alters a predicate value on sigma (checked via the same
# extract_signature).  Keep the top-8 edits by KL as T_adv_i.
T_adv_i = { t_adv : pre_i(t_adv(scene)) == pre_i(scene) and post_i(t_adv(scene)) == post_i(scene),
            t_adv found by PGD above, N_adv = 8 }

# Phase 3: commutation probe (executor side, frozen)
for t in T_pres_i union T_viol_i union T_adv_i:
    a_t = pi_e(observe(t(scene)), p_i)          # frozen executor, no gradient
    D_pres += KL( pi_e(observe(scene), p_i) || a_t )   for t in T_pres_i
    D_viol += KL( pi_e(observe(scene), p_i) || a_t )   for t in T_viol_i
    D_adv  += KL( pi_e(observe(scene), p_i) || a_t )   for t in T_adv_i

# Phase 4: certificate decision (closed-form rule, no learned head)
cert_i = PASS  iff  max_{t in T_pres} KL_t < tau_pres  AND  min_{t in T_viol} KL_t > tau_viol
                    AND  max_{t in T_adv} KL_t < tau_pres
    # tau_pres = 0.05 nats, tau_viol = 0.20 nats, fixed from a held-out calibration scene
    # (calibrated once per executor, never per program; monotone by construction because
    #  the intervention set is defined symbolically, not statistically)

# Phase 5: failure attribution
if FAIL: report which witness predicate was violated (the argmin/argmax t), giving the
         reasoner a concrete repair signal: widen W_i (move predicate from pre to free)
         or narrow it (add a predicate the executor actually depends on).
```

The shared latent scene signature σ is the coupling surface: it is the same object the reasoner reads to emit W_i and the same object the intervention grammar perturbs, so the witness and the probe live on one representation rather than two loosely coupled modules. Phase 2b closes the gap between σ and the executor's raw-pixel input by searching for pixel edits that are witness-preserving by construction yet change the executor's output, and requiring the certificate to PASS only if no such edit exceeds tau_pres.

**Why this design.** We chose a symbolic precondition/postcondition witness over a learned independence head because a learned head cannot manufacture independence the data does not contain — the reasoner's abstraction and the executor's reliance are operationally coupled in the seed layouts (Anti-Pattern 1), whereas a symbolic predicate is a falsifiable claim that a scene intervention can directly contradict. We chose scene-side interventions over policy-side statistical tests (e.g., probing hidden states) because the claim under test is about the *scene factors* the reasoner abstracts away, not about the executor's internal representation; intervening on the scene makes the test causal with respect to the abstraction, accepting the cost that we need a controllable simulator or reset-capable real rig (the AutoEval reset machinery is the natural host). We chose a closed-form two-threshold decision rule over a learned router (Anti-Pattern 4) because the thresholds are calibrated once per executor on held-out scenes and the intervention sets are defined symbolically, so the decision does not require a controller to be trained; the cost is that the thresholds must be re-calibrated if the executor is swapped, which is a one-time offline step. We chose a typed perturbation grammar over free-form image edits because typed edits make 'witness-preserving' and 'witness-violating' decidable by evaluating pre/post on σ, accepting the cost that the grammar bounds the space of nuisances we can test; Phase 2b adds an adversarial pixel-edit search that is validated to be witness-preserving by the same predicate evaluator, so the invariance claim is tested against the executor's actual input distribution rather than against the reasoner's symbolic signature alone.

**Why it measures what we claim.** The quantity `max_{t in T_pres} KL_t` measures *executor invariance to reasoner-declared nuisance factors* because the assumption that a scene transformation preserving the symbolic witness is a valid intervention on exactly the factors the reasoner abstracted away makes low KL under such transformations equivalent to the executor ignoring those factors; this assumption fails when the perturbation grammar is incomplete (a nuisance factor the executor depends on is never perturbed), in which case the metric reflects invariance only to the tested nuisance subspace, not to all declared nuisances. The quantity `min_{t in T_viol} KL_t` measures *executor sensitivity to witness-relevant factors* because the assumption that a witness-violating transformation changes a factor the program's correctness depends on makes high KL under such transformations equivalent to the executor actually using the declared relevant factors; this assumption fails when a violating transformation is out-of-distribution for the executor (e.g., an extreme occlusion), in which case high KL reflects OOD surprise rather than genuine dependence on the named factor. The quantity `max_{t in T_adv} KL_t` measures *executor invariance to pixel-level cues outside σ* because the assumption that the adversarial search finds the worst-case witness-preserving pixel edit within the L_inf budget makes low KL under such edits equivalent to the executor not relying on any pixel cue that σ fails to capture; this assumption fails when the PGD search is trapped in a local optimum or the L_inf budget is too small to reach a cue the executor uses, in which case low KL reflects failure to find the adversarial edit rather than genuine invariance. The certificate rule `PASS iff max_pres < tau_pres and min_viol > tau_viol and max_adv < tau_pres` measures *compositional generalization of the decomposition* because the assumption that a program whose executor commutes with the witness will compose with new reasoner programs sharing that witness makes PASS equivalent to the abstraction boundary holding beyond the seed distribution; this assumption fails when a new program uses a witness predicate that was never exercised during calibration, in which case PASS reflects commutation on the calibrated predicate vocabulary only, not on the full witness language.

## Contribution

(1) A test-time certification protocol, COMMWIT, that pairs each reasoner program with a symbolic commutation witness over a shared latent scene signature and decides PASS/FAIL via a closed-form two-threshold rule over scene interventions, requiring no retraining and no learned independence head. (2) A typed perturbation grammar that makes 'witness-preserving' and 'witness-violating' decidable by evaluating pre/post predicates on the scene signature, yielding a causal rather than statistical test of the abstraction boundary. (3) A failure-attribution mechanism that maps a FAIL certificate to the specific witness predicate the executor actually depends on, producing a concrete repair signal (widen or narrow the witness) for the reasoner.

## Experiment

### Evaluation Setup

| Role | Choice | Rationale |
| --- | --- | --- |
| Dataset | HexaShell held-out layouts + AutoEval reset scenes | Provides controllable simulator and reset for interventions |
| Primary metric | Cert-PASS precision/recall vs. compositional rollout success | Directly tests whether certificate predicts generalization |
| Baseline | HexaShell frozen-tool success | Tests whether success alone implies invariance |
| Baseline | Learned independence head (probing) | Tests whether learned coupling detection suffices |
| Baseline | Retrieval-based tool selector | Tests whether retrieval captures scene-factor reliance |
| Ablation-of-ours | COMMWIT w/o witness (random predicates) | Isolates whether symbolic witness drives signal |
| Ablation-of-ours | COMMWIT w/o adversarial pixel-edit search (Phase 2b removed) | Isolates whether the adversarial search closes the σ-to-pixel gap |
| Stratification | Precision/recall stratified by whether the new program's witness predicates were seen during calibration | Tests whether PASS reflects commutation on the calibrated predicate vocabulary only |

### Why this setup validates the claim

The central claim is that a symbolic witness plus scene-side commutation probing certifies whether an executor's output respects exactly the scene factors the reasoner declared relevant, and that this certification predicts compositional generalization to new reasoner programs sharing that witness. The dataset choice (HexaShell held-out layouts and AutoEval reset scenes) is essential because the method requires a controllable simulator or reset-capable rig to generate witness-preserving and witness-violating interventions; success-rate evaluation on static layouts cannot establish commutation. Each baseline targets a different sub-claim. HexaShell frozen-tool success tests whether task success alone is sufficient evidence of invariance: if success and certificate disagree on scenes where nuisances change, then success is not a proxy for commutation. The learned independence head tests whether a statistical coupling detector can recover the same boundary without symbolic commitments; if it fails precisely where the witness is narrow, that supports the symbolic design. The retrieval-based selector tests whether retrieval captures scene-factor reliance rather than instruction similarity. The ablation with random predicates isolates the causal role of the witness: if COMMWIT with random witnesses performs like the baselines, the gain is not from the witness but from probing per se. The ablation without the adversarial pixel-edit search isolates whether the σ-to-pixel gap matters: if removing Phase 2b does not change precision/recall, the adversarial search is not needed; if it does, the certificate depends on testing against the executor's actual input distribution. The stratified precision/recall analysis by witness-predicate novelty tests the assumption that new programs reuse only calibrated witness predicates: if precision/recall is uniform across seen and unseen predicates, the certificate transfers beyond the calibrated vocabulary; if it degrades on unseen predicates, PASS reflects commutation on the calibrated vocabulary only. The primary metric, certificate precision/recall against compositional rollout success on new programs, is the right one because the certificate is a binary prediction of whether a program will generalize; precision and recall directly measure whether PASS means generalization and FAIL means breakdown, which is the operational claim.

### Expected outcome and causal chain

**vs. HexaShell frozen-tool success** — On a case where a held-out layout changes a nuisance factor (e.g., retextured distractor objects) that the reasoner's program does not name, the baseline produces high success because the tools happen to be robust to that nuisance, but it cannot distinguish this from a program that silently relies on the distractor's color. Our method instead runs witness-preserving interventions and observes near-zero KL for the robust program, issuing PASS, and large KL for the color-reliant program, issuing FAIL. Thus we expect a noticeable gap in precision/recall on the subset of programs whose success is coincidence, with parity on programs where success reflects genuine invariance.

**vs. Learned independence head** — On a case where the witness is narrow (names only one object) but the executor also depends on a second object not named, the baseline produces a low independence score because the training data rarely contains interventions on the second object, so the head cannot manufacture independence it has not seen. Our method instead uses the symbolic witness to generate violating interventions on the named object and preserving interventions on nuisances, and the KL pattern reveals the executor's reliance on the unnamed object through the preserving set. We expect the learned head to show high false-PASS rates concentrated on programs with narrow witnesses, while our method's false-PASS rate stays low on that same subset.

**vs. Retrieval-based tool selector** — On a case where two programs have similar instructions but different scene-factor reliance (one depends on a plane normal, one does not), the baseline produces the same tool selection because retrieval keys on instruction similarity, missing the scene-factor difference. Our method instead evaluates the witness predicates on the scene signature and probes commutation, so the two programs receive different certificates. We expect a clear separation in certificate outcomes on instruction-matched but witness-different program pairs, where the retrieval baseline shows no separation.

**vs. COMMWIT w/o adversarial pixel-edit search** — On a case where the executor relies on a pixel-level cue outside σ (e.g., a shading artifact correlated with a named object's position), the ablated method issues PASS because the typed grammar never perturbs that cue, while the full method's Phase 2b finds a witness-preserving pixel edit that changes the executor's output and issues FAIL. We expect the ablated method to show higher false-PASS rates concentrated on programs whose scenes contain pixel cues outside σ, with parity on programs where σ captures all relevant cues.

**vs. COMMWIT w/o witness (random predicates)** — On a case where the reasoner's witness correctly names the relevant object, the random-witness ablation generates preserving and violating interventions that do not align with the program's actual dependencies, so the KL pattern is uninformative and the certificate approaches chance. We expect the random-witness ablation to show precision/recall near the base rate of compositional success, while the full method shows a clear gap, isolating the symbolic witness as the driver of the signal.

**Stratified by witness-predicate novelty** — On new programs whose witness predicates were all seen during calibration, we expect high precision/recall for the full method. On new programs containing at least one predicate never exercised during calibration, we expect precision/recall to degrade, with false-PASS concentrated on programs whose novel predicate is one the executor actually depends on. This stratification tests the assumption that PASS reflects commutation on the calibrated predicate vocabulary only.

### What would falsify this idea

If COMMWIT's certificate precision/recall is uniform across subsets rather than concentrated on programs where the predicted failure mode (witness incompleteness, executor OOD sensitivity, or pixel cues outside σ) occurs, then the symbolic witness is not driving the signal and the central claim that the witness is the coupling surface is wrong. Additionally, if the random-witness ablation matches COMMWIT's performance, or if removing the adversarial pixel-edit search does not change precision/recall, the witness or the pixel-gap closure adds nothing beyond probing.
