# Counterfactual BEV Witnessing for Zero-Shot Vision-Language Navigation

## Motivation

Across the current VLN tree (LightZeroNav, Open-Nav, NaVid, NavGPT), the VLM semantic stream and the geometric/BEV stream are fused as parallel evidence but never required to agree on a counterfactual consequence before action commitment; LightZeroNav in particular emits continuous actions from a frozen lightweight VLM with no structural check that its landmark grounding or progress estimate is spatially consistent with the observable BEV, so semantic errors propagate silently until task failure. The root cause is that existing methods verify semantics by the VLM's own confidence or by retrieval against memory (anti-patterns 2 and 3), both of which are coupled to the same semantic stream they are supposed to check, leaving no independent adjudicator at the point of action emission.

## Key Insight

A frozen VLM can be made self-auditing without retraining by forcing each semantic assertion to commit to a falsifiable BEV occupancy change under a counterfactual ego-motion probe, so that the physical BEV delta measured after a short lookahead serves as an adjudicator whose outcome is statistically independent of the VLM's own confidence.

## Method

# WITNESS-VLN: Counterfactual BEV Witnessing for VLN-CE
# Inputs: instruction I, RGB stream, BEV occupancy grid O_t (from VLN-AVP-style mapper)
# Frozen VLM M (Qwen3-VL-8B), no training, no learned consistency head
# Hyperparams: probe displacement d=0.5m, lookahead k=3 control steps,
#              cell tolerance tau=1, max recovery rounds R=2,
#              witness-triviality variance threshold sigma_min^2=0.05 (occupancy prob. variance),
#              witness set size cap |W_x| <= 8, witness cells restricted to within d of probe swept volume

for t in navigation steps:
    # 1. VLM emits semantic assertions + candidate action
    A_t = M(I, RGB_t, O_t_context)          # list of assertions: landmark_grounded(l),
                                            # subinstruction_completed(s), progress_increment(p)
    a_t = A_t.action                        # continuous (v, omega)

    # 2. External witness selection (decoupled from VLM under test)
    for each assertion x in A_t:
        # Witness cells are generated by the mapper's own uncertainty model, NOT by M.
        # Procedure: sample candidate cells along the swept volume of probe(a_t, d)
        # and at the BEV boundary of the asserted landmark's projected region (if any).
        # For each candidate cell c, compute occupancy probability p_c and its variance
        # sigma_c^2 under the mapper's noise model (ray-casting uncertainty).
        # Select up to 8 cells with highest sigma_c^2 that lie within d of the probe.
        W_x = select_witness_cells(O_t, a_t, d, x, max_cells=8, sigma_min^2=0.05)
        # Reject trivial witness sets: if max_{c in W_x} sigma_c^2 < sigma_min^2, mark x as
        # 'witness_trivial' and skip adjudication for x (count as rejected probe).

    # 3. Geometric forward model predicts counterfactual delta (NOT the VLM)
    for each assertion x with non-trivial W_x:
        # Delta_hat_x is computed by the mapper's ray-casting/occupancy prediction
        # given a_t and d, using the current O_t. This is a deterministic geometric
        # forward model, independent of M's semantic stream.
        Delta_hat_x = mapper.forward_predict(O_t, a_t, d, W_x)   # binary occupancy change per cell

    # 4. Commit a short probe and measure the actual BEV delta
    execute probe(a_t, d)                   # short lookahead, k steps
    O_probe = mapper.observe()
    Delta_meas = O_probe[W] - O_t[W]        # restricted to union of witness cells W

    # 5. Adjudicate: commit iff predicted and measured deltas agree
    agree = all_x [ Hamming(Delta_hat_x, Delta_meas[W_x]) <= tau ]
    if agree:
        commit(a_t); O_t = O_probe
    else:
        # 6. Recovery: re-ground instruction against BEV, NOT re-sample VLM
        I_regrounded = reground(I, O_probe, W_failed)   # replace failed landmark/
                                                         # subgoal with BEV-anchored referent
        re-issue A_t = M(I_regrounded, RGB_t, O_probe)  # same frozen VLM, new context
        if recovery_rounds >= R: fallback_to_conservative_stop()

# Load-bearing assumption (explicit):
# The adjudicator is valid only if witness cells are selected independently of the VLM
# under test and if the predicted delta is computed by a geometric forward model, not by
# the VLM. Under this design, Hamming agreement measures assertion truth because the
# hypothesis (witness set and predicted delta) is formed by the mapper's uncertainty and
# ray-casting model, which is conditionally independent of M's grounding error given the
# assertion. This assumption fails when the mapper itself is biased or when witness cells
# are trivially stable (sigma_c^2 < sigma_min^2); in that case agreement reflects mapper
# noise or witness triviality, not assertion truth. We therefore reject trivial witness
# sets and report the fraction of rejected probes as a diagnostic.

**Why this design.** We chose a *counterfactual BEV probe* over a learned consistency head because a head trained on the same coupled VLM-BEV data would inherit the coupling it is meant to detect (anti-pattern 1), accepting the cost that the probe adds a short physical lookahead (k=3 steps) and can occasionally commit to a wrong action if the BEV mapper itself is noisy. We chose *falsifiable witness cells* over free-form VLM self-explanation because free-form text cannot be adjudicated by a physical sensor, accepting the cost that the witness set is restricted to ≤8 cells and may miss global inconsistencies. We chose *BEV-anchored re-grounding* over re-sampling the VLM because re-sampling draws from the same distribution that produced the failed assertion (anti-pattern 3), accepting the cost that recovery is limited to the referents the BEV can express. A domain expert would not describe this as a variant of LightZeroNav or Open-Nav: those methods *fuse* semantic and geometric evidence, whereas WITNESS-VLN requires the two streams to *agree on a counterfactual consequence* that the VLM must commit to before the BEV adjudicates it — a coupling invariant absent from any prior VLN tree. Crucially, the witness set and the predicted delta are produced by the mapper's geometric model, not by the VLM under test, so the adjudicator is independent of the semantic stream at the hypothesis-formation step, not only at the measurement step.

**Why this measures what we claim.** The witness-set Hamming agreement `Hamming(Delta_hat_x, Delta_meas[W_x]) <= tau` measures *semantic-spatial consistency of assertion x* because the witness cells are chosen by the mapper's uncertainty model as the cells whose occupancy would flip if x were false, and the predicted delta is computed by the mapper's ray-casting forward model, so under the assumption that the mapper's uncertainty model is faithful to x, agreement is equivalent to x being true in the BEV; this assumption fails when the mapper selects witness cells that are trivially stable (e.g., far-away walls) or when the mapper's forward model is biased, in which case the metric reflects *witness triviality* or *mapper bias* rather than assertion truth, which is why we cap |W_x| ≤ 8, require the witness to lie within d of the ego-motion probe, and reject witness sets with max sigma_c^2 < sigma_min^2. The *probe displacement d* measures *counterfactual sensitivity* because a probe of length d forces the BEV to change in a way that only a spatially grounded assertion can predict; this fails when d is too small to produce measurable BEV change, in which case the metric reflects *mapper noise* rather than assertion falsifiability. The *recovery re-grounding against O_probe* measures *failure detection closure* because it uses the measured BEV delta as the intervention that repairs the instruction context; this fails when the BEV itself is corrupted, in which case recovery reflects *mapper error* rather than semantic error.

## Contribution

['A counterfactual BEV witness protocol for frozen-VLM VLN in which every semantic assertion is accompanied by a small falsifiable BEV cell set and a predicted occupancy delta, and action commitment requires measured-vs-predicted delta agreement after a short ego-motion probe.', 'A BEV-anchored recovery procedure that re-grounds the instruction against the measured BEV delta instead of re-sampling the VLM, closing the semantic-spatial consistency loop without any learned consistency head or VLM fine-tuning.', 'An analysis of the witness-triviality and probe-sensitivity failure modes that bound when counterfactual BEV witnessing is informative, expressed as concrete caps on witness-set size and probe displacement.']

## Experiment

### Evaluation Setup

| Role | Choice | Rationale (≤12 words) |
| --- | --- | --- |
| Dataset | VLN-CE (R2R-CE val-unseen) | Continuous, unseen scenes stress zero-shot grounding |
| Primary metric | Success Rate (SR) on landmark-critical subset | Directly reflects spatial grounding correctness |
| Secondary metric | Probe rejection rate (fraction of witness sets with max sigma_c^2 < 0.05) | Diagnostic for witness triviality |
| Secondary metric | Known-false-assertion detection rate (inject 100 false assertions, measure probe disagreement) | Tests adjudicator sensitivity |
| Baseline | LightZeroNav | Lightweight zero-shot VLN-CE reference point |
| Baseline | Fast-SmartWay | Zero-shot panoramic-free pipeline without probing |
| Baseline | GPT-4o zero-shot agent | Strong VLM, no BEV adjudication |
| Baseline | Post-hoc consistency check (VLM confidence vs BEV occupancy agreement threshold) | Tests whether simple agreement check suffices |
| Baseline | Self-consistency re-sampling (sample VLM 5 times, majority action) | Tests whether re-sampling substitutes for probe |
| Ablation-of-ours | WITNESS-VLN w/o counterfactual probe (commit always) | Isolates probe-adjudication contribution |
| Ablation-of-ours | WITNESS-VLN w/ VLM-selected witnesses and VLM-predicted deltas (original coupling) | Tests independence of witness selection |
| Ablation-of-ours | WITNESS-VLN w/o witness-triviality rejection (sigma_min^2=0) | Tests triviality guard contribution |
| Ablation-of-ours | Probe-free fallback (skip lookahead when mapper confidence < threshold) | Tests latency-accuracy trade-off |

### Why this setup validates the claim

The central claim is that requiring a frozen VLM's semantic assertions to agree with a physically measured BEV counterfactual delta improves grounding of landmark-critical subinstructions without training. VLN-CE val-unseen is the right testbed because it forces zero-shot generalization to unseen continuous layouts where the coupling between language referents and geometry cannot be memorized. Success Rate is the correct primary metric because it is the end-to-end consequence of exactly the failure mode we target: a wrong landmark commit produces a trajectory that terminates off-goal, whereas a correct adjudication keeps the agent on the instruction-consistent path. The two zero-shot baselines test different sub-claims: LightZeroNav tests whether a lightweight VLM without probing suffices (if it matches us, the probe is unnecessary), while Fast-SmartWay tests whether a two-stage waypoint pipeline without BEV witnessing closes the gap (if it matches us, the invariant is redundant). The GPT-4o agent tests whether raw VLM scale substitutes for adjudication. The post-hoc consistency check and self-consistency re-sampling baselines test whether the counterfactual-probe structure—not merely 'checking agreement'—is what produces the gain. The ablation-of-ours w/ VLM-selected witnesses and VLM-predicted deltas tests the load-bearing assumption: if the gain disappears when witnesses and deltas come from the VLM, the independence of witness selection is necessary. The witness-triviality rejection ablation tests whether the sigma_min^2 guard prevents degenerate agreement. The probe-free fallback tests feasibility under mapper uncertainty. If our gain appears over all baselines and over the always-commit ablation specifically on the landmark-critical subset, and if the known-false-assertion detection rate is high (>80%) while the probe rejection rate is low (<20%), the causal story holds; if the always-commit ablation closes the gap, the probe is inert.

### Expected outcome and causal chain

**vs. LightZeroNav** — On a case where the instruction says "turn left at the red door and stop by the bench," the baseline's lightweight VLM commits to a plausible-looking left turn from RGB alone because it has no mechanism to check whether the door is actually where the instruction places it; it fuses semantic and geometric cues but never requires them to agree on a consequence. Our method instead has the mapper select witness cells near the door (high occupancy variance under the probe), computes the predicted delta via ray-casting, and only commits if the measured BEV delta matches; when the door is mislocalized, the witness delta disagrees and the instruction is re-grounded against the observed BEV before re-issue. We expect a noticeable SR gap concentrated on landmark-critical instructions, with near-parity on open-corridor instructions where no landmark adjudication is triggered.

**vs. Fast-SmartWay** — On a case where a two-stage pipeline predicts a waypoint toward a subgoal the instruction has already completed (e.g., "after the stairs, enter the kitchen"), the baseline re-predicts waypoints from the same coupled context and drifts back toward the stairs because its waypoint predictor has no intervention that repairs the subgoal state. Our method instead detects the mismatch between the mapper's predicted BEV delta and the measured probe delta at the witness cells for `subinstruction_completed`, and re-grounds the instruction against the post-probe BEV, so the completed subgoal is removed from context rather than re-sampled. We expect the gap to concentrate on multi-subgoal instructions and to be small on single-landmark ones.

**vs. GPT-4o zero-shot agent** — On a case where the instruction references a small object (a fire extinguisher) that the VLM grounds confidently but incorrectly due to visual ambiguity, the baseline commits the action because a larger VLM still has no physical adjudicator and its confidence is not calibrated to BEV geometry. Our method instead forces the mapper to select a falsifiable witness set around the claimed object and checks the measured delta; the ambiguous grounding yields a witness set whose predicted delta fails to match, triggering BEV-anchored re-grounding. We expect our method to beat the GPT-4o agent on the small-object subset despite using a smaller VLM, with parity or a slight deficit on coarse landmark instructions where raw VLM capacity helps.

**vs. Post-hoc consistency check** — On a case where the VLM is confidently wrong about a landmark, the post-hoc check compares VLM confidence to BEV occupancy agreement at the claimed location; if the VLM's confidence is high and the BEV occupancy at the claimed cell is non-zero (e.g., a wall), the check may pass despite misgrounding. Our method instead requires agreement on a counterfactual delta under a probe, which is sensitive to spatial misplacement even when occupancy is non-zero. We expect our method to outperform the post-hoc check on landmark-critical instructions, with the gap largest when the claimed landmark is near other occupied cells.

**vs. Self-consistency re-sampling** — On a case where the VLM's grounding error is systematic (e.g., consistently misidentifying a door), re-sampling yields the same wrong action with high probability. Our method detects the error via the probe and re-grounds against the BEV, breaking the systematic error. We expect our method to outperform re-sampling on instructions with systematic grounding errors, with parity on random errors.

**vs. WITNESS-VLN w/ VLM-selected witnesses and VLM-predicted deltas** — This ablation tests the load-bearing assumption. If the VLM selects trivially stable witness cells and predicts deltas that match regardless of assertion truth, the probe agreement will be near-ceiling and uninformative, leading to SR similar to the always-commit ablation. We expect our method (mapper-selected witnesses, mapper-predicted deltas) to significantly outperform this ablation on landmark-critical instructions, confirming that independence of witness selection is necessary.

**vs. WITNESS-VLN w/o witness-triviality rejection** — Without the sigma_min^2 guard, trivial witness sets (e.g., far-away walls) will produce agreement regardless of assertion truth, inflating false positives. We expect the guard to improve SR on landmark-critical instructions by rejecting trivial probes and forcing re-grounding when the witness is uninformative.

**vs. Probe-free fallback** — When mapper confidence is low, skipping the probe reduces latency but may commit to wrong actions. We expect the fallback to trade a small SR drop for a large latency reduction, demonstrating feasibility.

### What would falsify this idea

If the gain over the always-commit ablation is uniform across landmark-critical and open-corridor subsets rather than concentrated where witness adjudication is actually triggered, the improvement cannot be attributed to counterfactual agreement and the central claim fails. Equivalently, if the probe-agreement rate is near-ceiling on instructions we independently label as misgrounded, or if the known-false-assertion detection rate is near-chance, the witness sets are trivially stable or the adjudicator is insensitive, and the metric measures witness triviality rather than assertion truth.
