# Identifiable Causal Grounding for Embodied Task Planning

## Motivation

CausGround distills action preconditions and effects into a factorized world-state, but its latent causal factors are not identifiable under partial observation: different observation histories can yield different factorizations that are observationally equivalent yet support different plans. This failure is structural because the factorization is learned as a heuristic distillation without a constraint that ties latent factors to invariant causal mechanisms across histories; consequently, cross-history consistency of grounded preconditions and effects is assumed rather than enforced.

## Key Insight

Imposing a history-invariance constraint on the factorized world-state—requiring that the same causal factor assignment be recovered from any observation history that shares the same underlying object-relation structure—renders the factorization identifiable up to a known equivalence class, converting heuristic causal grounding into a principled estimator with cross-history consistency.

## Method

**Identifiable Causal Grounding (ICG)**

(A) **What it is.** ICG augments CausGround's factorized world-state with an identifiability constraint over latent causal factors. Given a set of observation histories $\{h_i\}$ that are generated by the same underlying object-relation structure (e.g., the same scene observed from different viewpoints or action prefixes), ICG produces a factor assignment $z$ over object attributes and inter-object relations that is consistent across histories, and uses this assignment to ground action preconditions and effects for planning. **Load-bearing assumption (explicit):** the per-history factor encodings $z_i = \text{FactorEncoder}(h_i)$ must lie in a shared, aligned coordinate frame, so that the Euclidean discrepancy $\|z_i - z_j\|_2^2$ measures identifiability violation rather than arbitrary per-history parameterization or rotation. Without this alignment, averaging or projecting $z_i$ yields a meaningless centroid, and the stability filter selects factors that are invariant only because the encoder happens to output them consistently (e.g., constants). To satisfy this assumption, ICG uses a shared, jointly-trained encoder with an explicit anchoring scheme (see Phase 1).

(B) **How it works.**

```pseudocode
Input: observation histories H = {h_1,...,h_n} from the same scene,
       distilled causal knowledge K (preconditions/effects per action),
       invariance weight lambda = 0.5, identifiability tolerance eps = 1e-3,
       non-degeneracy threshold tau = 0.1
Output: consistent factor assignment z*, grounded preconditions/effects

Phase 1: Factor extraction with shared anchored encoder
  # Shared encoder: 2-layer MLP, hidden=256, GeLU activation, output dim d=32.
  # Trained jointly on all histories with an auxiliary anchoring loss:
  #   L_anchor = sum_i || z_i - A(h_i) ||_2^2, where A(h_i) is a fixed
  #   auxiliary label vector (e.g., object-relation triple annotations
  #   available in VirtualHome) that breaks permutation/rotation symmetry.
  #   (Time-contrastive or auxiliary-label nonlinear-ICA objective.)
  # Non-degeneracy term: L_deg = sum_f max(0, tau - std_i(z_i^f))^2,
  #   penalizing factors with cross-history standard deviation below tau.
  # Total loss: L = L_anchor + 0.1 * L_deg.  (No reconstruction loss needed.)
  For each history h_i:
    z_i = FactorEncoder(h_i)   # object attributes + inter-object relations,
                               # now in shared anchored frame

Phase 2: History-invariance constraint
  Define pairwise factor discrepancy in the anchored frame:
    d_ij = || z_i - z_j ||_2^2
  Enforce invariance by solving:
    z* = argmin_z sum_i || z_i - z ||_2^2
         s.t.  for all i,j: d_ij <= eps
  # Closed-form solution when constraint inactive: z* = mean(z_i)
  # When constraint active, project z_i onto the epsilon-ball intersection
  # using alternating projections (POCS) with lambda scaling.

Phase 3: Causal grounding with identifiability
  For each action a in K:
    pre_a = { (factor, value) in z* : factor is precondition of a }
    eff_a = { (factor, delta) in z* : factor is effect of a }
  # Ground preconditions/effects only on factors that are stable
  # across histories (i.e., those with d_ij <= eps for all i,j)
  # AND non-degenerate (std_i(z_i^f) >= tau).

Phase 4: Planning
  Backward reasoning: check pre_a against z*
  Forward reasoning: apply eff_a to predict next z*
  Multi-step planning via standard regression over grounded effects
```

(C) **Why this design.** We chose a hard invariance constraint over a soft regularizer because the identifiability claim requires exact cross-history consistency, accepting the cost that the constraint may be infeasible under noisy observations (handled by the tolerance $\epsilon$). We chose a closed-form projection (POCS) over gradient-based optimization because the factor space is low-dimensional and the constraint set is convex, accepting the cost that the projection may not find the global optimum if the constraint set is empty. We chose to ground preconditions/effects only on stable factors over using all factors because stable factors are the identifiable ones, accepting the cost that some action-relevant factors may be discarded when histories are too few. We chose a shared, jointly-trained encoder with an auxiliary anchoring loss over a fixed per-history encoder because without a shared frame the Euclidean discrepancy $d_{ij}$ measures encoder parameterization differences rather than identifiability violation, accepting the cost that the encoder requires auxiliary labels (object-relation triples) which may not be available in all domains. We added a non-degeneracy term to prevent the stability filter from selecting trivially constant factors, accepting the cost of an extra hyperparameter $\tau$. This design is not a variant of CausGround: CausGround's factorization is a heuristic distillation with no invariance constraint, whereas ICG's core mechanism is an identifiability estimator that enforces cross-history consistency—a structural property CausGround does not produce.

(D) **Why it measures what we claim.** The pairwise factor discrepancy $d_{ij}$ measures cross-history consistency because the assumption that histories sharing the same underlying object-relation structure should yield the same factor assignment (in the shared anchored frame) makes $d_{ij}$ equivalent to the violation of identifiability; this assumption fails when histories are generated by different scenes (e.g., different object sets) or when the encoder is not anchored, in which case $d_{ij}$ reflects scene difference or encoder parameterization rather than identifiability violation. The projection $z^*$ measures the identifiable factor assignment because the assumption that the true factor assignment lies in the intersection of $\epsilon$-balls around each $z_i$ makes the projection equivalent to the maximum-consistency estimator; this assumption fails when the factor encoder is biased, in which case $z^*$ reflects the encoder's bias rather than the true factors. The stability filter (factors with $d_{ij} \le \epsilon$ for all $i,j$ and std $\ge \tau$) measures which factors are identifiable because the assumption that identifiable factors are exactly those invariant across histories and non-degenerate makes the filter equivalent to an identifiability test; this assumption fails when a factor is invariant by coincidence (e.g., constant across histories), in which case the filter reflects trivial invariance rather than causal identifiability—the non-degeneracy term $\tau$ guards against this failure mode.

## Experiment

### Evaluation Setup

| Role | Choice | Rationale (≤12 words) |
| --- | --- | --- |
| Dataset | VirtualHome multi-viewpoint scenes | Provides same-scene histories for invariance testing |
| Dataset | ALFRED action-prefix histories | Second domain with different history-generation process |
| Primary metric | Planning success rate on held-out goals | Directly measures grounded precondition/effect correctness |
| Secondary metric | Cross-history factor discrepancy $d_{ij}$ | Measures invariance violation directly |
| Baseline | CausGround | Tests whether identifiability adds beyond heuristic distillation |
| Baseline | MLLM planner (no grounding) | Tests whether grounding matters at all |
| Baseline | Soft-regularizer variant | Tests whether hard invariance constraint is necessary |
| Ablation-of-ours | ICG w/o stability filter | Tests whether filtering to stable factors is essential |
| Ablation-of-ours | ICG w/o non-degeneracy term | Tests whether $\tau$ prevents trivial invariance |
| Ablation-of-ours | ICG with constant nuisance factor injected | Tests false-positive rate of stability filter |

### Why this setup validates the claim

The central claim is that enforcing cross-history identifiability on latent causal factors yields grounded preconditions and effects that support more reliable multi-step planning than heuristic distillation. VirtualHome's multi-viewpoint scenes are the right testbed because they supply the same underlying object-relation structure observed through different histories, which is exactly the condition under which the invariance constraint is meaningful; if histories came from different scenes, the discrepancy $d_{ij}$ would reflect scene difference rather than identifiability violation, so the design would not test the claim. ALFRED action-prefix histories provide a second domain where histories are generated by different action prefixes rather than rendering viewpoints, testing that the identifiability benefit is not tied to multi-viewpoint artifacts. Planning success rate on held-out goals is the right metric because it is the downstream consequence of correct grounding: a planner succeeds only if preconditions are checked against the right factors and effects are applied to the right factors. CausGround tests the sub-claim that identifiability adds something beyond heuristic factorization; the MLLM planner tests that grounding itself is necessary; the soft-regularizer variant tests that the hard constraint, not just any consistency pressure, drives the gain; the no-stability-filter ablation tests that selecting identifiable factors, rather than averaging all factors, is the operative mechanism; the no-non-degeneracy ablation tests that the $\tau$ term is necessary to avoid trivial invariance; and the constant-nuisance-factor injection tests the filter's false-positive rate. Together these form a falsifiable test: the gain must concentrate where the predicted failure mode occurs.

### Expected outcome and causal chain

**vs. CausGround** — On a case where two viewpoints of the same scene yield slightly different factor assignments, CausGround produces preconditions grounded on whichever history it distilled from, because its factorization has no cross-history invariance constraint, so it cannot distinguish stable factors from view-dependent ones. Our method instead projects the per-history factors onto the intersection of epsilon-balls, because the true factor assignment is assumed to lie in that intersection, so only factors consistent across histories survive the stability filter. We expect a noticeable success-rate gap on goals whose preconditions involve relations that vary across viewpoints, but near-parity on goals whose preconditions involve only clearly stable object attributes.

**vs. MLLM planner (no grounding)** — On a case requiring a multi-step plan where an early action changes an object relation that a later action depends on, the MLLM planner produces a plan that ignores the relational change because it reasons over surface observations without an explicit factor-level effect model. Our method instead applies grounded effects to predict the next factor assignment and checks later preconditions against it, because its effects are expressed as deltas on identifiable factors. We expect a large gap on multi-step goals with relational dependencies and a smaller gap on single-step goals, where the lack of grounding matters less.

**vs. Soft-regularizer variant** — On a case where one history is noisy, the soft-regularizer variant produces a factor assignment pulled toward the noisy history because its penalty is traded off against the data term, so a genuinely stable factor can be shifted off its true value. Our method instead enforces the constraint as a hard feasibility condition with tolerance epsilon, because exact cross-history consistency is what the identifiability claim requires, so the noisy history is projected rather than allowed to drag the estimate. We expect the soft variant to close most of the gap on clean subsets but to lose noticeably on the noisy-history subset, while our method holds.

**vs. ICG w/o stability filter** — On a case where some factors are view-dependent, the no-filter variant averages all factors including unstable ones, because it uses the mean $z^*$ without filtering, so preconditions may be grounded on factors that vary across histories. Our method instead grounds only on factors with $d_{ij} \le \epsilon$ and std $\ge \tau$, because those are the identifiable ones. We expect the no-filter variant to perform worse on goals involving view-varying relations, with near-parity on goals using only stable attributes.

**vs. ICG w/o non-degeneracy term** — On a case where a factor is constant across histories (e.g., a nuisance factor), the no-$\tau$ variant includes it as stable because it has $d_{ij}=0$, so the stability filter selects a trivially invariant factor. Our method instead requires std $\ge \tau$, excluding constant factors. We expect the no-$\tau$ variant to show a higher false-positive rate in the constant-nuisance-factor injection test and slightly lower planning success on goals where the nuisance factor is irrelevant.

**vs. ICG with constant nuisance factor injected** — On a controlled synthetic scene where we inject a deliberately constant nuisance factor, the stability filter should reject it if the non-degeneracy term is active. We measure the false-positive rate (fraction of runs where the nuisance factor is selected as stable) and expect it to be near zero with $\tau=0.1$, but high without $\tau$.

### What would falsify this idea

If our gain over CausGround is uniform across subsets rather than concentrated on goals whose preconditions involve view-varying relations, the identifiability mechanism is not what produces the improvement and the central claim is wrong. Likewise, if the no-stability-filter ablation matches our full method, then filtering to stable factors is not the operative mechanism; and if the constant-nuisance-factor injection yields a high false-positive rate even with $\tau$, the stability filter fails to exclude trivial invariance.
