# Certified Compositional Consolidation for Code Video Captioning

## Motivation

Existing video captioning methods that build structured representations—scene graphs, code modules, or transition boundaries—implicitly assume that local decisions compose globally without verification. For instance, CodeCap-Bench (Idea Cards) generates executable code captions by composing per-segment graphical primitives and layout rules but provides no mechanism to check whether the composed program preserves the spatial and temporal relations present in the local segments; similarly, transition-based dense captioning (SBS) assumes detected boundaries compose into a coherent global event structure. This structural gap—treating local merge or boundary decisions as globally structure-preserving without a compositionality invariant—is the meta-level bottleneck we address.

## Key Insight

A partial monoidal functor from local transition-boundary segments to a global relational structure yields a checkable relation-preservation certificate, because the functor's composition law enforces that every pairwise spatial and temporal relation in the local segments is exactly preserved in the consolidated output, making global consistency a structural invariant rather than a learned likelihood.

## Method

**What it is** — We introduce C3 (Certified Compositional Consolidation), an operator that takes a video's local transition-boundary segments (each with a scene graph and a code-caption module) and produces a consolidated global scene graph and code program, together with a relation-preservation certificate: a checkable invariant that all pairwise temporal and spatial relations from the local segments are preserved. The caption generator is trained to emit only consolidations that carry this certificate.

**How it works** — The core operation is a partial monoidal functor F from the category of local segments (objects: segments; morphisms: temporal adjacency and spatial overlap relations) to the category of global relational structures (objects: consolidated graphs/programs; morphisms: relation-preserving embeddings). F is defined segment-wise and extended by monoidal composition along the video timeline. The certificate is a set of pairwise relation constraints (e.g., 'segment i precedes segment j', 'object A is left of object B') that must hold in the consolidated output. We implement F as a differentiable graph-merging module with a hard certificate layer: during training, we sample local segments, apply F, and compute a certificate violation loss (sum of hinge penalties for violated constraints). The caption generator is an encoder-decoder that takes the consolidated graph and emits code; its output is projected onto the certificate-satisfying subspace by a constrained decoding step that rejects tokens violating any active constraint. Hyperparameters: segment length 2s, stride 1s, certificate tolerance ε=0.01 for spatial relations, violation loss weight λ=0.5.

**Load-bearing assumption (stated explicitly)** — The pairwise temporal and spatial relation constraints enumerated from local transition-boundary segments form a complete and correct specification of the global relational structure, so that satisfying them via a monoidal functor plus constrained decoding is equivalent to preserving all relations in the consolidated output. This assumption is false in general: relational structure in video is not pairwise-decomposable (RCC-8 and Allen's interval algebra are not closed under pairwise composition without path-consistency, and path-consistency is provably insufficient for full consistency in RCC-8), and constrained decoding that rejects locally violating tokens cannot enforce constraints whose satisfaction depends on tokens not yet emitted. We therefore make the assumption explicit and add a concrete calibration/verification story: (i) we define the certificate over the full consolidated structure via a path-consistency check on the merged scene graph and a program-level type/relational check on the emitted code; (ii) we make constrained decoding operate over complete candidate programs (generate-then-verify with rejection sampling or a repair pass) rather than token-by-token rejection, so the certificate is verified on the finished output rather than assumed to compose from local checks; (iii) we report the fraction of segments whose relations fall outside the pairwise algebra as an explicit coverage statistic, and we add a metric that directly measures global (non-pairwise) relation fidelity to test the load-bearing assumption.

**Why this design** — We chose a partial monoidal functor over a learned graph-merging network because the functor's composition law provides a structural guarantee (relation preservation) that a purely learned merger cannot, accepting the cost that F must be defined segment-wise and may fail on segments with ambiguous boundaries. We chose a hard certificate layer over a soft penalty alone because soft penalties do not guarantee certificate satisfaction at inference, accepting the cost of constrained decoding overhead. We chose to train the caption generator with a structural violation loss rather than maximum likelihood because likelihood does not penalize relation violations, accepting the cost that the model may produce less fluent code. A domain expert would not describe this as a variant of CodeCap-Bench because CodeCap-Bench generates code captions without any compositionality invariant; our method's core is the certificate, which is absent in that prior work.

**Why it measures what we claim** — The certificate violation loss measures relation preservation because we assume that the pairwise constraints enumerated from local segments are a complete and correct specification of the relations that must hold globally; this assumption fails when local segments contain relations that are not pairwise (e.g., three-way spatial arrangements), in which case the loss reflects only pairwise consistency, not full relational fidelity. The constrained decoding step measures certificate satisfaction because we assume that rejecting tokens that violate active constraints is sufficient to guarantee the final output satisfies all constraints; this assumption fails when constraints interact non-locally (e.g., a later token could fix an earlier violation), in which case the decoding reflects local certificate satisfaction, not global. The functor F measures compositional structure because we assume that the category of local segments with adjacency morphisms captures all relevant compositional structure; this assumption fails when segments have overlapping content not captured by adjacency, in which case F reflects only adjacency-based composition.

## Experiment

### Evaluation Setup

| Role | Choice | Rationale (≤12 words) |
| --- | --- | --- |
| Dataset | ActivityNet Captions | Long videos with dense, boundary-rich transitions |
| Primary metric | Certificate violation rate | Directly measures the claimed relation-preservation invariant |
| Secondary metric | Global relation fidelity (non-pairwise) | Tests load-bearing assumption: pairwise constraints complete for global relations |
| Baseline | CodeCap-Bench code captions | Tests whether certificate adds value over code-only captions |
| Baseline | Soft-penalty graph merger | Tests whether hard certificate layer is necessary |
| Baseline | Natural language captions | Tests whether code structure itself drives gains |
| Ablation-of-ours | C3 without constrained decoding | Isolates the hard certificate layer's contribution |
| Ablation-of-ours | C3 with pairwise-only certificate (no path-consistency) | Isolates the effect of global certificate verification |

### Why this setup validates the claim

The central claim is that a checkable relation-preservation certificate, enforced by a functorial consolidation and hard constrained decoding, yields globally consistent compositional captions that prior code-captioning and soft-penalty approaches cannot guarantee. ActivityNet Captions is the right substrate because its videos contain many adjacent and overlapping segments whose pairwise temporal and spatial relations are exactly what the certificate enumerates, so violations are detectable and attributable. The primary metric, certificate violation rate, is the right detector because it directly operationalizes the invariant the method claims to guarantee; a method that merely produces fluent code would not move this number. The secondary metric, global relation fidelity, directly tests the load-bearing assumption that pairwise constraints are a complete basis for global relations: it measures non-pairwise (e.g., three-way) relation satisfaction on the consolidated output, so if the assumption fails, this metric will reveal a gap between pairwise certificate satisfaction and true global fidelity. CodeCap-Bench code captions test the sub-claim that code structure alone is insufficient without an invariant. The soft-penalty merger tests the sub-claim that a hard certificate layer, not just a training loss, is necessary for inference-time satisfaction. Natural language captions test whether any gain is merely from code format. The ablation without constrained decoding isolates whether the hard layer, rather than the functor or the loss, produces the predicted effect. The ablation with pairwise-only certificate isolates whether global verification (path-consistency + program-level check) is necessary beyond pairwise checks. Together these form a falsifiable test: if the certificate is doing the claimed work, violation rate should drop specifically on relation-dense segments while fluency parity holds elsewhere, and global relation fidelity should track certificate violation rate only when the load-bearing assumption holds.

### Expected outcome and causal chain

**vs. CodeCap-Bench code captions** — On a case where a video has three adjacent segments sharing a moving object across boundaries, the baseline produces fluent code that describes each segment locally but silently drops or contradicts the cross-boundary "precedes" and "left-of" relations because it has no compositionality invariant. Our method instead consolidates segments through the functor and rejects tokens violating active pairwise constraints, so we expect a noticeable gap in violation rate concentrated on multi-segment, relation-dense videos but parity on single-segment clips.

**vs. Soft-penalty graph merger** — On a case where two segments have an ambiguous boundary and the soft penalty is under-weighted at inference, the baseline produces a consolidated graph that satisfies the loss on average but violates a specific spatial constraint at test time because the penalty does not guarantee satisfaction. Our method instead applies the hard certificate layer during decoding, so violations are rejected regardless of loss weighting; we expect the soft baseline to show moderate violation rates that grow with segment count, while ours stays flat and low.

**vs. Natural language captions** — On a case where a video's segments are individually well-described, the baseline produces readable prose that loses explicit relational structure and cannot be checked, so relation violations are neither detected nor penalized. Our method instead emits code with checkable constraints and a certificate, so we expect a large gap in violation rate but comparable fluency or human-preference scores, isolating the gain to structural fidelity rather than surface quality.

**vs. C3 without constrained decoding** — On a case where the violation loss is nonzero at convergence, the ablation produces code that satisfies most constraints but leaks a few non-local violations because the soft projection does not enforce them at inference. Our method instead rejects violating tokens during decoding, so we expect the ablation to show a residual violation rate that scales with constraint interaction depth, while ours remains near the tolerance floor.

**vs. C3 with pairwise-only certificate (no path-consistency)** — On a case where three segments form a cyclic spatial arrangement (e.g., A left-of B, B left-of C, C left-of A), the pairwise-only ablation satisfies each pairwise constraint locally but produces a globally unrealizable configuration because path-consistency is not enforced. Our method instead verifies the full consolidated structure via path-consistency and program-level checks, so we expect the pairwise-only ablation to show a higher global relation fidelity gap (certificate violation rate low but global fidelity poor) while ours keeps both low, directly testing the load-bearing assumption.

### What would falsify this idea

If our gain in certificate violation rate is uniform across relation-dense and relation-sparse subsets rather than concentrated where pairwise relations actually occur, or if the ablation without constrained decoding matches our method, or if the pairwise-only certificate ablation matches our full method on global relation fidelity, then the certificate is not the causal mechanism and the central claim is wrong.
