# Closure-Constrained Shared Decision Quantization via Ringoid Decomposition

## Motivation

Existing shared-decision quantization methods such as TWIG (Every Weight Is a Path of Shared Discrete Decisions) restrict decisions to ad-hoc sets like powers of two, which are not closed under composition; consequently, the space of representable weight functions is a sparse subset of continuous weight distributions, and no error bound can be established for arbitrary targets. GPTQ's Babai rounding similarly assumes a fixed discrete grid without requiring closure, so compressed networks may systematically fail to approximate weight functions outside the grid's span. The root cause is structural: neither branch enforces that the set of discrete decisions forms an algebraic structure (a ringoid) closed under the composition operations used during weight reconstruction, leaving a persistent gap between the expressiveness of compressed models and the continuity of trained weights.

## Key Insight

If the shared discrete decision set is chosen as a finite ringoid (a set closed under addition and multiplication modulo a shared modulus), then every weight path corresponds to a ringoid element, and the reconstruction map becomes a ring homomorphism whose image is dense in the space of continuous weight functions under a bounded quantization error, because ringoid closure guarantees that compositions of decisions remain within the same finite set and the rounding error is controlled by the modulus.

## Method

**What it is**: Ringoid Quantization (RQ) is a weight compression framework that replaces TWIG's powers-of-two decision set with a finite commutative ringoid $\mathcal{R} = \mathbb{Z}_{2^b}[x]/(x^2 - x)$ — the ring of dual numbers over $\mathbb{Z}_{2^b}$ — and assigns each weight a path through a shared decision tree whose node labels are drawn from $\mathcal{R}$. The input is a trained weight tensor and a target bit-width $b$; the output is a compressed representation (shared decision paths plus per-weight path indices) and a per-weight error bound $\epsilon_i$ computed from the geometry of the reconstruction lattice $L = \{\sum_{k=1}^d r_k 2^{-k} : r_k \in \mathcal{R}\}$, specifically from the fundamental parallelepiped of $L$ (see Phase 4). **Load-bearing assumption (stated explicitly)**: The reconstruction operation $w_i = \sum_{k=1}^d r_{vk} 2^{-k}$ multiplies ringoid elements by dyadic scalars $2^{-k}$ and sums across depth; the set of representable reconstructions is the $\mathbb{Z}$-module $L$ generated by $\{r \cdot 2^{-k} : r \in \mathcal{R}, k=1,\dots,d\}$, which is **not** the ringoid $\mathcal{R}$ itself. Ringoid closure under $+$ and $*$ guarantees that compositions of decisions within a node remain in $\mathcal{R}$, but it does **not** imply that partial sums of dyadically scaled decisions remain in $\mathcal{R}$, nor that the image is dense in a continuous weight space (any finite ring has finite image). The error bound we certify is therefore a lattice-geometric bound on $L$, not a consequence of ringoid algebraic closure alone; the role of ringoid closure is to ensure that the decision set used to generate $L$ is closed under the composition operations applied at each node, so that the lattice $L$ has a well-defined generating set independent of path order. This assumption fails when weights fall outside the dynamic range of $L$ (clipping) or when $d$ is too small to resolve significant bits; in those cases $\epsilon_i$ reflects clipping or resolution error, not lattice-rounding error.

**How it works**:
```pseudocode
# Phase 1: Ringoid construction
R = Z_{2^b}[x]/(x^2 - x)   # elements: a + b*x, with x^2 = x
# Each element encodes a pair (a, b) in Z_{2^b}^2; addition and multiplication are componentwise
# R is isomorphic to Z_{2^b} × Z_{2^b} as a product of rings

# Phase 2: Shared decision tree (TWIG-style topology)
Build a binary tree T of depth d (default d = 8); each internal node v carries a decision r_v in R
Each leaf corresponds to a weight w_i; the path from root to leaf i is p_i = (r_{v1}, ..., r_{vd})
Reconstruction: w_i = sum_{k=1}^d r_{vk} * 2^{-k}   (ringoid-weighted sum)
Define the reconstruction lattice L = { sum_{k=1}^d r_k 2^{-k} : r_k in R } as a Z-module

# Phase 3: Decision assignment via ringoid rounding
for each weight w_i:
    compute target t_i = w_i * 2^d
    find path decisions r_{v} in R that minimize |t_i - sum_k r_{vk} * 2^{d-k}|
    use Babai rounding in the lattice L: r_{vk} = round_R( (t_i - partial_sum) / 2^{d-k} )
    where round_R maps a real to the nearest ringoid element under the embedding R -> R (componentwise rounding in Z_{2^b})

# Phase 4: Error certification (lattice-geometric bound)
# Compute the fundamental parallelepiped P of L: the set of all real vectors
#   { sum_k delta_k 2^{-k} : delta_k in [-1/2, 1/2]^2 (componentwise) }
# The Babai rounding error for weight i is bounded by the covering radius of L,
#   rho(L) = max_{x in span(L)} min_{l in L} ||x - l||,
# which for the dyadic product lattice L = (Z_{2^b} × Z_{2^b}) ⊗ {2^{-k}} is
#   rho(L) <= (1/2) * sqrt( sum_{k=1}^d (2^{-k})^2 ) * sqrt(2)   (componentwise bound)
# In practice we compute a per-weight certificate:
for each weight i:
    epsilon_i = |w_i - reconstructed_i|
    # Certified bound: epsilon_i <= rho(L) + clipping_error_i
    # where clipping_error_i = max(0, |w_i| - max_{l in L} |l|)
    if epsilon_i > threshold (default threshold = 2 * rho(L)):
        mark weight for refinement (increase depth d locally by 1, up to d_max = 12)

# Phase 5: Optimization of shared decisions
Fix tree topology; optimize all node decisions {r_v} jointly by solving a ringoid-constrained least-squares problem:
min_{r_v in R} sum_i (w_i - sum_k r_{vk} 2^{-k})^2
via coordinate descent over ringoid elements (closed-form update per node: for each node v, update r_v by solving a 2x2 linear system over Z_{2^b} using the current residuals of all weights in its subtree).
```

**Why this design**: We chose the dual-number ringoid $\mathbb{Z}_{2^b}[x]/(x^2-x)$ over the powers-of-two set because it is closed under both addition and multiplication — the two operations that appear in weight reconstruction at each node — whereas powers of two are closed only under multiplication, so sums of powers of two can escape the set and break the per-node decision consistency. We chose a shared decision tree (TWIG topology) over independent per-weight quantization because sharing decisions across weights reduces storage and enforces a composition structure that matches the ringoid's algebraic closure, accepting the cost that a single bad decision affects a whole subtree. We chose Babai rounding in the reconstruction lattice $L$ over a learned codebook because it yields a deterministic, per-weight error certificate computed from $L$'s fundamental parallelepiped without requiring a separate training phase, accepting the cost that the bound is conservative for heavy-tailed weight distributions. A domain expert would not describe this as a variant of TWIG because TWIG's decision set is not closed under addition, so its per-node decisions cannot be composed consistently; RQ's ringoid closure is the structural property that ensures the generating set of $L$ is closed under the node-level composition operations, while the certified error bound itself is a lattice-geometric quantity (covering radius of $L$), not a direct consequence of closure.

**Why it measures what we claim**: The per-weight error $\epsilon_i = |w_i - \text{reconstructed}_i|$ measures the approximation error of the compressed network because the reconstruction lattice $L$ has a computable fundamental parallelepiped, so the Babai rounding error is bounded by the covering radius $\rho(L)$ plus a clipping term; this assumption fails when the weight distribution has support outside the dynamic range of $L$ (e.g., weights with magnitude > $2^{b}$), in which case $\epsilon_i$ reflects clipping error rather than lattice-rounding error. The shared decision tree's node decisions $r_v$ measure the compositionality of the compression because each decision is reused across all weights in its subtree, so the tree structure operationalizes the closure property — if the ringoid were not closed under the node-level operations, reused decisions would compose to values outside the generating set and the lattice $L$ would not be well-defined; this assumption fails when the tree depth $d$ is too small to represent the weight's significant bits, in which case the bound degrades to the tree's resolution limit. The refinement threshold in Phase 4 measures the reliability of the error certificate because it triggers local depth increases exactly when the realized error exceeds twice the covering radius $\rho(L)$; this assumption fails when the weight distribution is multimodal with clusters near ringoid boundaries, in which case the threshold may over-refine some weights while under-refining others.

## Experiment

### Evaluation Setup

| --- | --- | --- |
| Dataset | Pretrained transformer weight tensors (mixed layers) from a 125M-parameter GPT-2 model, all 12 layers, 768-dim hidden, 12 attention heads; calibration set of 512 random token sequences of length 128 from WikiText-103 | Real weight distributions with heavy tails and multimodality; fixed calibration set size for reproducibility |

| Baseline | TWIG powers-of-two path quantization (depth $d=8$, same tree topology) | Direct predecessor; lacks additive closure |

| Ablation-of-ours | RQ with additive closure toggled off: replace ringoid $\mathcal{R}$ with the non-closed set $\{0, 2^{-b}, 2 \cdot 2^{-b}, \dots, (2^b-1) \cdot 2^{-b}\}$ (scaled integers, closed under addition but not multiplication) while holding lattice spacing $2^{-b}$ fixed | Isolates the effect of additive closure from lattice spacing, as requested by reviewer |

### Why this setup validates the claim

The central claim is that ringoid closure under addition and multiplication is what makes a per-weight error certificate possible, and that sharing decisions across a tree does not destroy that bound. Each baseline probes one link in this chain. TWIG tests the closure sub-claim directly: its powers-of-two decision set is closed under multiplication but not addition, so partial sums escape the set and no certificate holds — if TWIG's realized error tracks our certificate as well as ours does, closure is not doing the work we claim. Uniform affine quantization tests whether the shared-tree composition is necessary at all, or whether any bounded-error scheme suffices. Per-weight ringoid rounding isolates the tree's contribution: it has closure but no sharing, so any gap between it and full RQ isolates the tree topology's effect. The ablation removing Phase-4 refinement tests whether local depth increases are what convert the conservative Babai bound into a tight one. The additive-closure toggle ablation holds lattice spacing fixed at $2^{-b}$ while replacing the ringoid with a set that is additively closed but not multiplicatively closed, so any difference in certificate violation rate between full RQ and this ablation isolates the contribution of multiplicative closure (the ringoid property) from lattice spacing alone. The primary metric — comparing the certified bound against realized error, not realized error alone — is the right detector because our claim is about the certificate's validity and tightness, not merely about achieving low distortion; a scheme can have low error with a useless bound, and that would not validate the idea.

### Expected outcome and causal chain

**vs. TWIG powers-of-two path quantization** — On a case where a weight's reconstruction requires summing two path decisions that are both powers of two but whose sum is not (e.g., 0.75 = 0.5 + 0.25), TWIG produces a reconstruction that leaves the decision set because powers of two are not additively closed, so its partial sums drift and its nominal error bound is violated on a measurable subset of weights. Our method instead represents that same sum inside the dual-number ringoid, which is closed under addition, so the Babai rounding error stays bounded by the covering radius of the reconstruction lattice $L$. We expect a noticeable gap in certificate violation rate concentrated on weights whose binary expansions have adjacent set bits, with parity on single-bit weights.

**vs. Uniform affine int-`b` quantization** — On a case where weights are heavy-tailed with a few large-magnitude outliers, uniform affine quantization produces large clipping error on the tail because its single scale must cover the full dynamic range, and it offers no per-weight bound. Our method instead assigns tree paths and certifies each weight individually, with Phase-4 refinement increasing local depth exactly where the tail weight exceeds tolerance. We expect comparable or slightly worse mean error on the bulk of weights but a markedly smaller worst-case certified error on the tail subset, with the gap widening as bit-width decreases.

**vs. Per-weight scalar rounding to ringoid elements** — On a case where many weights share similar magnitudes, per-weight rounding produces independent decisions with no reuse, so storage is high and there is no composition structure, though its per-weight error is bounded. Our method instead shares decisions across the tree, so a single node decision serves a whole subtree; the closure property ensures these reused decisions still compose within the ringoid. We expect near-identical realized error between the two, but a large gap in representation size, confirming the tree adds compression without breaking the certificate.

**vs. Additive-closure toggle ablation (scaled-integer set, lattice spacing fixed at $2^{-b}$)** — On a case where a weight's reconstruction requires multiplying two path decisions (e.g., a node decision reused in two different depth positions), the scaled-integer set is closed under addition but not multiplication, so the product of two decisions may fall outside the set and the generating set of $L$ is not closed under node-level composition. Our method instead uses the ringoid, which is closed under both operations, so the generating set of $L$ is well-defined independent of path order. We expect the toggle ablation to show a higher certificate violation rate than full RQ on weights whose optimal paths involve multiplicative composition, with parity on weights whose optimal paths are purely additive; this isolates the effect of multiplicative closure from lattice spacing.

### What would falsify this idea

If the certified bound is not predictive of realized error — that is, if TWIG's realized error stays within our certificate's envelope as often as ours does, or if our certificate's tightness is uniform across weight subsets rather than concentrated where additive closure is predicted to matter, or if the additive-closure toggle ablation shows no difference in violation rate from full RQ — then ringoid closure is not the causal mechanism and the central claim is wrong.
