# Modality-Stratified Routing Diagnostics for Multi-Encoder Mixture-of-Experts Language Models

## Motivation

Routing-specialization analysis was developed on single-stream text MoE models like OLMoE (E2), where expert co-activation, routing entropy, and specialization are measured over one homogeneous token distribution. Frontier multi-encoder MoE systems such as Sage S1.5 Flash (E5) route heterogeneous distributions — molecular graphs, biological sequences, spectra, text, and images — through one shared router, yet report only headline benchmark rankings. The structural reason existing analysis fails: OLMoE-style metrics assume a single token distribution, so when projectors emit distributions with different scales, dimensionalities, and covariance structures, pooled routing statistics conflate genuine expert specialization with projector-induced distribution shift, and no reported quantity distinguishes the two.

## Key Insight

Because each modality's projector output distribution is the sufficient conditioning variable for the router's behavior on that modality, stratifying routing statistics by projector identity — and contrasting them against a distribution-matched text control — separates expert specialization from projector-induced distribution shift that pooled metrics cannot.

## Method

**What it is.** We introduce MARSA (Modality-Stratified Routing Specialization Analysis), a diagnostic suite that takes a frozen multi-encoder MoE model and a labeled multi-modal probe set, and outputs per-modality routing profiles, modality-stratified specialization metrics, and a distribution-shift attribution score. Inputs: router logits at every MoE layer, expert assignments, and projector identity per token; outputs: a structured report with three metric families plus an attribution decomposition.

**How it works.**

```pseudocode
PHASE 1 — Probe construction and modality labeling
  Input: frozen model M with K MoE layers, P projectors (text, image, molecular graph,
         biological sequence, spectra), probe corpus D
  For each token t in D:
    record modality label m(t) = projector that emitted t
    record router logits z_l(t) for each MoE layer l, expert assignment a_l(t)
  Build distribution-matched text control: for each non-text modality m, sample a
    text subset D_text|m whose token-frequency profile matches the non-text token
    count per layer (stratified sampling, n=50k tokens per modality)

PHASE 2 — Per-modality routing profiles
  For each modality m and layer l:
    co-activation matrix C_l^m[i,j] = P(expert i and j both active | modality m)
    routing entropy H_l^m = -sum_i p_l^m(i) log p_l^m(i), where p_l^m(i) = mean
      softmax(z_l)[i] over tokens of modality m
    top-k expert set S_l^m = {i : p_l^m(i) in top-k}

PHASE 3 — Cross-modal overlap and specialization metrics
  Cross-modal expert overlap O_l(m,m') = |S_l^m ∩ S_l^m'| / |S_l^m ∪ S_l^m'|
  Specialization score Sigma_l^m = 1 - H_l^m / log(E_l), E_l = active expert count
  Modality selectivity Phi_l^m = KL(p_l^m || p_l^text)  (text as reference)

PHASE 4 — Distribution-shift attribution
  Train a linear probe g_m on projector output features (frozen projector, no gradient
    to backbone) to predict modality label; report probe accuracy A_m
  Attribution: for each metric X in {C, H, S, O, Sigma, Phi}, compute X on (a) real
    modality tokens and (b) structure-preserving synthetic tokens generated by
    resampling real projector outputs within modality (shuffle token order, or
    resample from a kernel density / cluster-preserving mixture fit rather than a
    single Gaussian). The gap Delta_X = X_real - X_synth is the projector-induced
    component; the residual is specialization. Additionally compute a Gaussian-matched
    gap Delta_X^Gauss (using per-dimension mean and covariance estimated from 10k
    projector outputs) and report it only as a lower bound on shift.
  Higher-order diagnostic: compute cluster-count divergence D_cluster between real and
    synthetic tokens (e.g., number of distinct k-means clusters at k=10, or higher-moment
    divergence) to flag when the Gaussian matching assumption fails.

PHASE 5 — Report
  Output per-layer, per-modality tables of all metrics, attribution gaps, and a
    specialization-vs-benchmark correlation across the 33 benchmark domains.
```

Hyperparameters: probe set size 50k tokens per modality; k = 8 for top-k expert sets; structure-preserving resampling uses kernel density estimation with bandwidth selected by Silverman's rule, or a Gaussian mixture with 10 components fit via EM; Gaussian matching uses per-dimension mean and covariance estimated from 10k projector outputs; linear probe trained with logistic regression, 80/20 split.

**Why this design.** We chose distribution-matched text controls over raw text baselines because raw text differs from scientific modalities in token frequency and sequence length, which would confound routing entropy with input length (accepting the cost that matching reduces sample size and may miss rare modality-specific patterns). We chose a structure-preserving synthetic-token attribution over retraining projectors because retraining changes the model and cannot be applied to a frozen frontier system (accepting the cost that resampling may not capture all higher-order structure, so some distributional differences are attributed to specialization rather than shift; we report the Gaussian-matched gap as a lower bound). We chose per-layer reporting over pooled reporting because MoE routers are known to specialize differently across depth in OLMoE (E2), so pooling would average away the layer-wise structure that is the object of study (accepting the cost of a larger report and multiple-comparison burden, which we handle by reporting per-layer metrics without family-wise correction and flagging this as exploratory). A domain expert would not describe MARSA as a variant of OLMoE's analysis because OLMoE measures specialization on a single homogeneous stream, whereas MARSA's core operation — the attribution decomposition in Phase 4 — has no counterpart in OLMoE and is what makes the metrics interpretable under heterogeneous projector distributions.

**Why it measures what we claim.** The specialization score Sigma_l^m measures per-modality expert specialization because we assume that routing entropy normalized by active expert count is monotonically decreasing in the concentration of expert usage within a modality; this assumption fails when a modality's tokens are themselves heterogeneous (e.g., spectra of different molecule classes), in which case Sigma reflects within-modality sub-population mixing rather than cross-modality specialization. The attribution gap Delta_X measures projector-induced distribution shift because we assume that structure-preserving synthetic tokens (resampled within modality) reproduce the router's response to distributional scale and covariance while breaking token-to-context pairing; this assumption fails when higher-order structure (e.g., discrete token clusters from molecular graphs) drives routing, in which case Delta_X under-attributes shift and over-attributes specialization; we flag this failure mode using the cluster-count divergence D_cluster. The cross-modal overlap O_l measures shared expert usage because we assume top-k expert sets are stable under the probe sample size; this assumption fails for low-frequency modalities where top-k sets are noisy, in which case overlap reflects sampling variance rather than genuine sharing.

## Experiment

### Evaluation Setup

| Role | Choice | Rationale |
| --- | --- | --- |
| Dataset | Sage S2.1 Flash multi-modal probe set (text, image, molecular graph, sequence, spectra) | Provides heterogeneous projector distributions the claim depends on |
| Primary metric | Attribution gap Δ_X between real and structure-preserving synthetic tokens | Directly tests whether routing is projector-induced vs. specialization |
| Baseline | OLMoE-style pooled specialization analysis | Tests the sub-claim that per-layer, per-modality attribution is necessary |
| Baseline | Raw-text control routing comparison | Tests the sub-claim that distribution-matched controls remove length/frequency confounds |
| Baseline | Modality-agnostic pooled routing entropy | Tests the sub-claim that pooling averages away layer-wise modality structure |
| Ablation-of-ours | MARSA without Phase 4 attribution (metrics only) | Isolates whether attribution decomposition drives interpretability gains |
| Ablation-of-ours | MARSA with Gaussian-matched synthetic tokens (instead of structure-preserving) | Tests whether higher-order structure matters for attribution |

### Why this setup validates the claim

The central claim is that MARSA's attribution decomposition separates projector-induced routing shift from genuine cross-modality expert specialization, and that this separation is what makes per-modality routing metrics interpretable. The dataset choice matters because Sage S2.1 Flash is a 320B-parameter MoE with five distinct projectors (E5), so it supplies exactly the heterogeneous distributional regimes the attribution is meant to disentangle. The primary metric Δ_X is the right one because it is a within-metric contrast: if routing differences were purely projector-induced, Δ_X would absorb nearly all cross-modal variation and the residual specialization signal would vanish. Each baseline tests a different sub-claim. OLMoE-style pooled analysis tests whether per-layer, per-modality reporting is necessary; raw-text controls test whether distribution matching removes confounds; modality-agnostic pooled entropy tests whether pooling destroys the structure. The ablation (MARSA without Phase 4) is the critical control: if removing attribution does not change the interpretation of which experts are modality-specialized, then the attribution machinery is decorative rather than load-bearing. The Gaussian-matched ablation tests whether the structure-preserving null is necessary to avoid inverting the attribution.

### Expected outcome and causal chain

**vs. OLMoE-style pooled specialization analysis** — On a case where molecular-graph tokens route through a different expert subset than text tokens at layer 12, pooled analysis averages the two distributions and reports moderate entropy with no layer-specific signal, because it treats all tokens as one homogeneous stream. Our method instead reports per-layer, per-modality entropy and cross-modal overlap, because Phase 2 and Phase 3 stratify by projector identity. We expect a large layer-wise spread in Sigma_l^m for non-text modalities but near-uniform Sigma across layers for text, with the gap concentrated at middle layers.

**vs. Raw-text control routing comparison** — On a case where spectra tokens are much shorter than text sequences, raw-text comparison shows higher routing entropy for spectra and falsely suggests lower specialization, because sequence length and token frequency differ. Our method instead matches text controls to non-text token counts per layer, because Phase 1 builds distribution-matched D_text|m. We expect the raw-text baseline to show a spurious entropy gap that shrinks substantially under distribution matching, with the residual gap attributable to genuine modality effects.

**vs. Modality-agnostic pooled routing entropy** — On a case where image tokens activate a concentrated expert set at layer 6 but a diffuse set at layer 18, pooled entropy reports a single intermediate value that hides the depth reversal, because pooling collapses layer-wise structure. Our method instead reports H_l^m per layer, because Phase 2 computes entropy at every MoE layer. We expect to observe a sign reversal in the specialization ordering between early and late layers that the pooled baseline cannot express, with the reversal visible as a crossing of per-layer Sigma curves.

**vs. MARSA with Gaussian-matched synthetic tokens** — On a case where molecular-graph tokens form discrete clusters that drive routing, Gaussian matching destroys cluster structure and attributes cluster-driven specialization to shift, inverting the intended attribution. Our method instead uses structure-preserving resampling, because Phase 4 constructs synthetic tokens by resampling real projector outputs within modality. We expect the Gaussian-matched gap to be larger than the structure-preserving gap for clustered modalities, with the difference flagged by high cluster-count divergence D_cluster.

### What would falsify this idea

If the attribution gap Δ_X is uniform across modalities and layers — that is, if the residual specialization signal after subtracting projector-induced shift is no larger than sampling noise — then the central claim that attribution makes specialization interpretable is wrong. Equally, if MARSA without Phase 4 produces the same modality-specialization rankings as full MARSA on every layer, the attribution decomposition is not doing the work we claim.
