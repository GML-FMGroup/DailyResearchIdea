# Stationary Conditioning Kernels for Horizon-Generalized Autoregressive Video Rollout

## Motivation

Streaming autoregressive video generators such as MovieRoll train and distill inside a finite temporal window (WinTF chunks plus a HieraKV sink-recent buffer) and then extrapolate at inference, implicitly assuming that a fixed finite context is a sufficient statistic for future frames at any rollout depth. This assumption is structurally false: the conditioning kernel's output distribution drifts with rollout index t because the buffer statistics (sink/recent composition, cache age distribution, residual-stream scale) at depth t are not the statistics seen during training, so compounding error and memory incoherence are symptoms of a horizon-dependent kernel rather than of insufficient capacity. The same finite-window, unbounded-depth gap recurs across the tree (NOVA's frame-by-frame causal modeling, VideoMAR's curriculum learning and progressive temperature, MAGI's teacher-forcing transition), which indicates a shared structural property that no current method establishes.

## Key Insight

If the windowed attention kernel is constrained to be rollout-index-invariant — its output distribution a fixed point of the depth-indexed conditioning map — then a finite context becomes a sufficient statistic at arbitrary depth, so horizon generalization follows from kernel stationarity rather than from longer training windows.

## Method

**What it is.** We introduce SIRK (Stationary Index-invariant Rolling Kernel), a windowed attention mechanism for autoregressive video rollout whose output distribution is regularized to be invariant to rollout index t. Inputs: a stream of frame chunks x_{1..T} generated by a windowed causal-attention video transformer, with a HieraKV-style buffer of sink and recent keys/values. Outputs: next-chunk latents whose conditioning statistics do not depend on how many chunks have already been rolled out.

**Load-bearing assumption (stated explicitly).** SIRK assumes that the drift of the conditioning kernel across rollout depth is a multiplicative rescaling of the attention output mean, so that dividing by per-depth EMA means (A_norm = A * mu_H/mu_idx) plus a KL between depth-t and depth-H output distributions makes the kernel's output distribution depth-invariant and the finite window a sufficient statistic at arbitrary depth. This assumption is load-bearing and is tested directly by the calibration and verification steps below; if it fails, the stationarity claim is dropped and the contribution reduces to a depth-conditioned normalization heuristic.

**How it works.**

```pseudocode
# Phase 1: base training with SIRK (replaces MovieRoll WinTF attention)
for each training window of W chunks at training horizon H=W:
    for chunk c in window:
        q = W_q * h_c                       # query from current chunk hidden state
        K_buf = [K_sink ; K_recent ; K_window]   # HieraKV buffer, size B
        A = softmax(q K_buf^T / sqrt(d))     # standard windowed attention
        # SIRK: rollout-index-invariant normalization
        idx = rollout_index(c)               # 0..H-1 within training window
        mu_idx = EMA_stats[idx]              # running mean of A's per-head output, indexed by depth
        A_norm = A * (mu_H / (mu_idx + eps)) # rescale to horizon-H statistics
        out = A_norm V_buf

# Phase 2: horizon-invariance loss (HIL)
L_HIL = sum_t  D_KL( p(out | depth=t) || p(out | depth=H) )
# estimated by paired forward passes: same content, two depths
# (a training-horizon pass and a truncated-depth pass sharing identical inputs)
# CONSTRUCTION: both passes replay the SAME teacher-forced buffer content
# (identical K_sink, K_recent, K_window) so the KL isolates kernel drift from content mismatch.
L = L_diffusion + lambda_HIL * L_HIL        # lambda_HIL = 0.1, annealed 0.5 -> 0.1

# Phase 3: long-rollout distillation (replaces CuLT-DMD's fixed window)
for each long self-rollout of length L >> H:
    for depth t in 1..L:
        enforce mu_idx[t] <- mu_H via EMA update   # kernel anchored to horizon stats
        accumulate local gradients over temporal positions
    average gradients; single update step

# Phase 4: inference
for t = 1..L:
    compute A with SIRK normalization using stored mu_H
    sample next chunk; update HieraKV buffer
```

Hyperparameters: window W matched to MovieRoll's WinTF chunk count; sink size and recent size per HieraKV; EMA decay 0.99; lambda_HIL annealed 0.5→0.1 over training; paired-depth sampling stride 4. Phase 3 is scoped to a fixed small set of depths t in {H, 2H, 4H} for the reduced-budget validation, reusing the base MovieRoll checkpoint for Phase 1 rather than retraining from scratch.

**Why this design.** We chose a rollout-index-conditioned normalization of attention output statistics over simply extending the training window because extending W does not change the structural fact that inference depth exceeds W, accepting the cost that we must maintain per-depth EMA statistics and a paired-depth forward pass. We chose a KL-based horizon-invariance loss over a distribution-matching distillation loss (as in CuLT-DMD) because CuLT-DMD matches the student to a teacher at the same depth, whereas we need to match depth t to depth H; the trade-off is that our loss requires constructing paired passes with identical content at two depths, which doubles per-step forward cost but gives a direct gradient on the drift we care about. We chose to anchor statistics to the training horizon H rather than to a running inference-time statistic because anchoring to H makes the finite window a sufficient statistic by construction, accepting that if H is badly chosen the anchor is wrong. We chose to keep HieraKV's layer-wise sink/recent split rather than replace the buffer because the invariance target is the kernel's output distribution, not the buffer contents; the trade-off is that buffer compression can still remove information, and we handle that by including buffer composition in the paired-depth construction. A domain expert would not describe SIRK as a variant of MovieRoll's WinTF: WinTF is a teacher-forcing schedule over a fixed window, whereas SIRK is a stationarity constraint on the attention kernel itself, and the paired-depth HIL objective has no counterpart in WinTF, HieraKV, or CuLT-DMD.

**Why it measures what we claim.** The quantity `L_HIL = KL(p(out|depth=t) || p(out|depth=H))` measures rollout-index invariance of the conditioning kernel because we assume that paired forward passes with identical content at depths t and H isolate depth as the only varying factor; this assumption fails when the HieraKV buffer at depth t contains self-generated content that differs from the teacher-forced content at depth H, in which case L_HIL reflects content mismatch rather than kernel drift. To control this, the paired-depth construction replays the same teacher-forced buffer at both depths, and a control run holds buffer content fixed across depths to isolate kernel drift. The quantity `mu_idx` (per-depth EMA of attention output statistics) measures the horizon-dependent bias of the kernel because we assume that attention output mean is a sufficient summary of the kernel's conditioning distribution; this assumption fails when higher moments (variance, head-wise covariance) drift while the mean is stable, in which case mu_idx under-reports drift. We therefore measure and report the drift of each moment (mean, variance, per-head covariance) as a function of depth, and add an ablation comparing mean-only vs. mean+covariance normalization. The quantity `A_norm = A * (mu_H / mu_idx)` operationalizes horizon-invariant conditioning because we assume that rescaling by the ratio of horizon statistics makes the output distribution depth-invariant; this assumption fails when the drift is not multiplicative (e.g., a shift in attention entropy), in which case normalization corrects scale but not shape. The gradient-averaging step in Phase 3 measures long-rollout credit because we assume local gradients at different depths share a common optimum under stationarity; this assumption fails when depth-dependent drift makes the per-depth optima inconsistent, in which case averaging produces a compromise kernel.

**Diagnostic decomposition (D).** To ground the drift metric against confounds, we decompose long-rollout error into (a) kernel output-statistic drift, (b) HieraKV buffer information loss, and (c) model capacity, by measuring each independently on the same rollouts. (a) is measured by the per-depth moment drift of attention outputs under fixed buffer content; (b) is measured by comparing rollouts with full vs. compressed HieraKV buffers at matched depths; (c) is measured by comparing model sizes at matched training budget. The significance claim holds only if (a) dominates.

## Experiment

### Evaluation Setup

| Role | Choice | Rationale |
| --- | --- | --- |
| Dataset | Long-form benchmark beyond training horizon (e.g., VBench long-video subset) | Tests rollout depths exceeding training window H |
| Primary metric | Temporal drift of conditioning statistics vs. depth (mean, variance, per-head covariance) | Directly measures the invariance SIRK claims and grounds the sufficiency assumption |
| Secondary metric | Decomposed long-rollout error: (a) kernel output-statistic drift, (b) HieraKV buffer information loss, (c) model capacity | Tests whether (a) dominates, as required for the significance claim |
| Baseline | MovieRoll (WinTF + HieraKV + CuLT-DMD) | Strongest streaming rollout pipeline to beat |
| Baseline | NOVA (non-quantized autoregressive) | Tests whether quantization-free AR already solves drift |
| Baseline | InfinityStar (unified spacetime AR) | Tests against high-fidelity discrete AR generator |
| Ablation-of-ours | SIRK without HIL (Phase 1 + 3 only) | Isolates whether the paired-depth loss matters |
| Ablation-of-ours | SIRK with mean-only vs. mean+covariance normalization | Shows which moments actually drift and whether covariance matching is necessary |
| Control | Fixed-buffer-content paired-depth passes | Isolates kernel drift from content mismatch in L_HIL |

### Why this setup validates the claim

The central claim is that SIRK's rollout-index-invariant kernel keeps conditioning statistics stationary as depth exceeds the training horizon, so long-rollout quality degrades slower than baselines. The dataset must therefore contain rollouts substantially longer than H, otherwise the failure mode we target never triggers and every method looks equal. The primary metric — measured drift of attention-output statistics (mean, variance, per-head covariance) as a function of rollout depth — is the right one because it detects the exact quantity SIRK constrains; a generic FVD/VBench score could improve for unrelated reasons (better base model, more data) and would not falsify the mechanism. The secondary decomposition metric is necessary because the significance claim requires that kernel output-statistic drift (a) dominates over buffer information loss (b) and capacity (c); if (b) or (c) dominates, the invariance story is not the main driver. MovieRoll tests the sub-claim that WinTF's fixed teacher-forcing window leaves depth-dependent drift uncorrected; NOVA tests whether avoiding quantization already removes the drift, which would make SIRK redundant; InfinityStar tests whether a strong discrete AR generator's fidelity already masks the drift. The ablation (SIRK without HIL) is the decisive control: if the normalization alone drives gains, HIL is unnecessary and the paired-depth machinery is unjustified. The mean-only vs. mean+covariance ablation grounds the sufficiency assumption by showing which moments drift. The fixed-buffer-content control isolates kernel drift from content mismatch in L_HIL. Together these form a falsifiable test because the predicted gain must be concentrated at large depths and vanish at shallow depths, and must shrink when HIL is removed.

### Expected outcome and causal chain

**vs. MovieRoll (WinTF + HieraKV + CuLT-DMD)** — On a case where rollouts extend well past the training window (e.g., several times H chunks), MovieRoll's WinTF kernel sees teacher-forced statistics at depth ≤ H but self-generated, drifted statistics at larger depths, so its attention output mean shifts with depth and errors compound. Our method rescales attention output by mu_H / mu_idx, anchoring the kernel to horizon statistics at every depth, so we expect a noticeably smaller drift slope at large depths but near-parity at depths within H. The decomposition is expected to show that kernel output-statistic drift (a) dominates buffer information loss (b) and capacity (c) on these rollouts.

**vs. NOVA** — On a case where frame-by-frame spatial-set prediction accumulates small per-frame distribution shifts, NOVA's non-quantized AR still has no mechanism tying depth-t statistics to depth-H statistics, so its conditioning drifts despite avoiding quantization artifacts. Our method adds the explicit stationarity constraint on the kernel, so we expect NOVA to show comparable drift to MovieRoll on long rollouts while SIRK's drift stays flat, isolating invariance rather than quantization as the cause.

**vs. InfinityStar** — On a case where a high-fidelity discrete AR generator is rolled out beyond its training duration, InfinityStar's per-frame quality is strong but its temporal statistics still depend on how many frames have been generated, so late-chunk consistency degrades relative to early chunks. Our method's depth-indexed normalization keeps the kernel's output distribution fixed, so we expect InfinityStar to win on short-clip fidelity while SIRK closes or reverses the gap specifically on late-chunk consistency metrics.

### What would falsify this idea

If the SIRK gain over MovieRoll is uniform across all rollout depths — including depths within the training horizon — rather than concentrated at depths exceeding H, then the drift mechanism we claim to fix is not what drives the improvement, and the invariance story is wrong. Likewise, if removing HIL leaves the primary drift metric unchanged, the paired-depth objective is not doing the work we attribute to it; and if the decomposition shows buffer information loss (b) or capacity (c) dominates kernel drift (a), the stationarity claim must be dropped and the contribution reduced to a depth-conditioned normalization heuristic.
