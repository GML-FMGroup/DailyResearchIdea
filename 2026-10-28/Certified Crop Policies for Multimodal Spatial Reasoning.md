# Certified Crop Policies for Multimodal Spatial Reasoning

## Motivation

Existing methods either learn a crop policy without certifying evidence sufficiency (e.g., EvidenceConnect in Zooming without Zooming v2 discards questions that survive region ablation, but the trained model still cannot decide at inference when a crop set is sufficient) or use training-free attention-based zooming (HiDe, ZoomEye) that lacks any certificate of necessity and sufficiency. The root cause is that answer correctness does not certify evidence sufficiency: a model can answer correctly from a single region even when the question requires connecting multiple regions, so RL on answer likelihood learns a policy that stops cropping prematurely. This structural gap recurs across paper-trees: the field removed the operation policy rather than learning a certified decision rule.

## Key Insight

A crop set is certified as necessary and sufficient exactly when a contrastive region-ablation test shows that removing any region changes the answer and adding any region does not, and this test can be computed on a synthesized multi-region QA distribution where ground-truth region sets are known, yielding a training signal that is monotone in evidence sufficiency rather than in answer likelihood.

## Method

**What it is** — We introduce **CertiCrop**, an inference-time crop policy that emits a set of regions only when a learned certificate head proves the set is both necessary and sufficient for the answer. Inputs: an image, a question, and a base VLM. Output: either a certified crop set (with the answer) or an abstention flag indicating insufficient evidence.

**How it works** — CertiCrop has three components trained jointly on an offline multi-region QA synthesis distribution (generated by EvidenceConnect, where ground-truth region sets R* are known):

```pseudocode
# Training on offline synthesized distribution D = {(I, q, R*, a*)}
# Policy π_θ: (I, q) -> crop set R
# Certificate head C_φ: (I, q, R) -> {certified, uncertified}
# Ablation scores estimated with N=5 stochastic VLM samples per query (temperature=0.7)
# Certificate trained on both R* and policy-emitted sets via online counterfactual rollout

for each (I, q, R*, a*) in D:
    R = π_θ(I, q)                      # sample crop set (top-k regions by score)
    # Contrastive region-ablation test on R with N=5 samples:
    necessity_score = min_{r in R} [1 - mean_{n=1..5} acc(VLM(I, q, R \ {r}))]   # drop-one accuracy drop
    sufficiency_score = 1 - max_{r not in R} [mean_{n=1..5} acc(VLM(I, q, R ∪ {r}))]  # add-one accuracy gain
    # Confidence intervals via bootstrap (B=100 resamples) over the N=5 samples:
    necessity_ci = bootstrap_ci(necessity_score, B=100, alpha=0.05)
    sufficiency_ci = bootstrap_ci(sufficiency_score, B=100, alpha=0.05)
    # Certificate target: 1 iff lower confidence bounds exceed thresholds (no R==R* conjunct)
    cert_target = 1[ (necessity_ci.lower > τ_n) and (sufficiency_ci.lower > τ_s) ]
    # Joint loss:
    L_policy = -log π_θ(R* | I, q)      # imitation of ground-truth region set
    L_cert = BCE(C_φ(I, q, R), cert_target)
    L = L_policy + λ * L_cert            # λ = 1.0

# Online counterfactual rollout (every 10 training steps):
# Sample R' ~ π_θ(I, q) for 512 examples, compute ablation scores as above,
# add (I, q, R', cert_target') to certificate training buffer.

# Inference:
R = π_θ(I, q)
if C_φ(I, q, R) == certified:
    return VLM(I, q, R)   # answer using certified crops
else:
    return abstain         # or fall back to full image
```

Hyperparameters: τ_n = 0.9, τ_s = 0.9, λ = 1.0, top-k = 5 (max crop set size), N=5 VLM samples, B=100 bootstrap resamples, α=0.05, online rollout buffer size=512, rollout frequency=10 steps.

**Why this design** — We chose a contrastive region-ablation test over answer-likelihood RL because ablation directly operationalizes necessity and sufficiency, while answer likelihood conflates correctness with evidence sufficiency (a model can answer correctly from a single region even when the question requires multiple regions). We chose a certificate head trained jointly with the policy over a separate post-hoc verifier because joint training ensures the policy learns to emit sets that the certificate can prove, avoiding the mismatch where a policy optimizes for answer correctness but the certificate rejects its outputs. We chose to train on the offline synthesized distribution with known R* rather than online RL because the ground-truth region sets provide a dense supervision signal for both the policy (imitation) and the certificate (exact necessity/sufficiency labels), which online RL cannot provide without expensive counterfactual rollouts. We chose a binary certificate head with a threshold over a continuous score because the contrastive test yields a hard label, and a calibrated probability is not needed—only a decision rule that is monotone in evidence sufficiency. This design is not a variant of ZoomEye or HiDe: those methods use attention or tree search to select regions but have no certificate of necessity and sufficiency, and they cannot abstain when evidence is insufficient. It is also not a variant of EvidenceConnect's RLVR: that method trains on filtered data but does not learn an inference-time policy with a certificate.

**Why this measures what we claim** — The necessity_score measures the necessity of each region in R because the drop-one accuracy drop is equivalent to the region being causally required for the answer, under the assumption that the VLM's answer is deterministic given the crop set; this assumption fails when the VLM is stochastic or when multiple regions are redundant (removing one does not change the answer because another region suffices), in which case necessity_score reflects redundancy rather than necessity. The sufficiency_score measures the sufficiency of R because the add-one accuracy gain is zero exactly when no additional region improves the answer, under the assumption that the VLM's accuracy is monotone in evidence; this assumption fails when adding a region introduces distractors that hurt accuracy, in which case sufficiency_score reflects distractor sensitivity rather than sufficiency. The cert_target measures the joint condition that both confidence intervals exceed thresholds, which is equivalent to R being both necessary and sufficient, under the assumption that the synthesized distribution's R* is the unique minimal sufficient set; this assumption fails when multiple minimal sufficient sets exist, in which case cert_target may reject a valid alternative set. (D) The load-bearing assumption is that the contrastive region-ablation scores computed with the base VLM are a faithful, monotone proxy for true evidence necessity and sufficiency, so that a certificate head trained on these scores transfers to certify crop sets at inference on unseen questions. This assumption fails when the VLM is stochastic or features are redundant, as ablation-based attribution is known to be unreliable in those regimes; we mitigate by estimating scores with N=5 stochastic samples, reporting bootstrap confidence intervals, and gating abstention on the lower confidence bound exceeding τ, and by training the certificate on policy-emitted sets via online counterfactual rollout so it is calibrated in the distribution it will actually see at inference.

## Experiment

### Evaluation Setup

| Role | Choice | Rationale (≤12 words) |
| --- | --- | --- |
| Dataset | Multi-region spatial QA with known R* (EvidenceConnect-style) | Provides ground-truth region sets for necessity/sufficiency labels |
| Dataset | Real multi-region spatial VQA benchmark with human-annotated minimal evidence regions (e.g., a spatial-reasoning VQA set) | Tests transfer beyond synthesis distribution |
| Primary metric | Certified-accuracy on multi-region subset | Directly tests joint necessity+sufficiency claim |
| Secondary metric | Abstention rate on uncertifiable sets | Measures recoverable errors vs silent errors |
| Baseline | Base VLM (no crop policy) | Tests whether inference-time cropping is needed at all |
| Baseline | Zooming-without-Zooming (RLVR-trained zoomer) | Tests whether certificate adds value beyond region selection |
| Baseline | HiDe (hierarchical decoupling zoom-in) | Tests robustness to distractor-heavy high-res inputs |
| Baseline | Post-hoc verifier trained on same ablation labels (no joint training) | Isolates joint-training contribution |
| Ablation-of-ours | CertiCrop w/o certificate head (policy-only, no abstain) | Isolates contribution of the certificate mechanism |
| Ablation-of-ours | CertiCrop with R==R* conjunct in cert_target | Tests whether pure ablation label adds value beyond imitation |

### Why this setup validates the claim

The central claim is that a certified crop set is both necessary and sufficient, and that abstention on uncertifiable sets converts silent errors into recoverable ones. This requires a dataset where the ground-truth minimal sufficient region set is known, so that "necessary and sufficient" is checkable rather than assumed — hence the EvidenceConnect-style multi-region QA distribution with known R*. To test transfer beyond synthesis, we add a real multi-region spatial VQA benchmark with human-annotated minimal evidence regions. The base VLM baseline isolates whether cropping is needed at all; the RLVR zoomer (Zooming-without-Zooming) isolates whether an explicit certificate adds anything beyond a policy that was trained to select regions; HiDe isolates whether our certificate handles distractor-heavy high-resolution inputs where decoupling-based zooming tends to over-include regions. The post-hoc verifier baseline isolates whether joint training of policy and certificate is necessary versus training a verifier on the same ablation labels after the fact. The ablation — policy-only without the certificate head — is the decisive comparison: if the certificate is doing real work, removing it should shift errors from abstentions into confident wrong answers, degrading certified-accuracy specifically on the multi-region subset. The R==R* ablation tests whether the pure ablation-based label (without the equality conjunct) adds value beyond imitation of ground-truth region sets. Certified-accuracy is the right metric because it counts an answer as correct only when the emitted set is certified, so a method that answers correctly from a redundant or distractor-laden set cannot inflate the score; the metric is monotone in the property we claim to establish.

### Expected outcome and causal chain

**vs. Base VLM (no crop policy)** — On a case where the answer requires two spatially separated regions (e.g., comparing an object on the left shelf to one on the right), the base VLM attends to the full image, dilutes resolution across both, and answers from the more salient region alone, producing a single-region answer that happens to be wrong on the relational question. Our method instead emits both regions because the policy was imitated on R* and the certificate rejects any set whose drop-one ablation changes the answer, so we expect a clear accuracy gap on the multi-region relational subset and near-parity on single-region questions.

**vs. Zooming-without-Zooming (RLVR zoomer)** — On a case where a single high-salience region is sufficient to answer a simpler sub-question but the full question needs a second region, the RLVR zoomer is rewarded for answer correctness and settles on the one-region crop that already yields the right answer, so it under-selects and fails the multi-region question while appearing confident. Our method instead keeps adding regions until the add-one sufficiency test shows no further gain, and the certificate targets the lower confidence bound exceeding τ, so we expect the gap to concentrate on questions whose R* has size ≥ 2, with the RLVR zoomer roughly matching us on size-1 R*.

**vs. HiDe (hierarchical decoupling zoom-in)** — On a high-resolution case where a distractor region (e.g., a similar-looking object) sits near the target, HiDe's decoupling-based zoom-in tends to include the distractor because decoupling selects by hierarchical salience rather than causal relevance, and the added region flips the answer. Our method instead drops the distractor because including it does not improve the add-one sufficiency score, and the certificate flags the set as uncertified if it does, so we expect a noticeable gap on distractor-dense high-resolution subsets and parity on clean subsets.

**vs. Post-hoc verifier (trained on same ablation labels, no joint training)** — The post-hoc verifier is trained after the policy is fixed, so it sees only the policy's final crop sets and cannot influence the policy to emit certifiable sets. We expect the joint-trained certificate to achieve higher certified-accuracy on multi-region subsets, especially when the policy's initial sets are uncertifiable, because joint training shapes the policy toward sets the certificate can prove.

**vs. CertiCrop w/o certificate head (policy-only, no abstain)** — Without the certificate, the policy emits top-k sets and always answers, so errors on redundant or distractor-laden sets become confident wrong answers. We expect the policy-only ablation to have lower certified-accuracy on the multi-region subset and zero abstention rate, while our method trades some coverage for higher certified-accuracy via abstention on uncertifiable sets.

**vs. CertiCrop with R==R* conjunct** — Adding the R==R* conjunct to cert_target ties the certificate to imitation of ground-truth region sets, so it may reject valid alternative minimal sufficient sets. We expect the pure ablation-based label (without R==R*) to yield higher certified-accuracy on the real benchmark where R* may not be unique, and to show that the certificate adds value beyond imitation.

### What would falsify this idea

If removing the certificate head leaves certified-accuracy essentially unchanged on the multi-region subset — i.e., the policy-only ablation already emits necessary-and-sufficient sets and abstains at the same rate — then the certificate is not doing the work we claim and the central mechanism is wrong. Likewise, if our gain over the RLVR zoomer is uniform across R*-size subsets rather than concentrated on size ≥ 2, the predicted under-selection failure mode is not what we are fixing.
